# 《蛊真人》游戏设计设定提取

来源：本地文本 `蛊真人.txt`。本文只做设定归纳和游戏化转译，不搬运原文段落。

> **状态：设计阅读摘要，不是原著事实的实施权威。**
> Wave 0.5 集成后，涉及人物、地点、势力和蛊虫的硬规则必须以
> `systems/canon/curated/` 中带证据坐标的资料为准；本文只用于快速理解和后续选题。

## 1. 世界观核心

### 1.1 基础命题

- 人是万物之灵，蛊是天地真精。
- 世界运行逻辑不是善恶，而是资源、利益、境界、寿命、机缘、天意和布局。
- 个人成长靠“修行 + 蛊虫 + 资源 + 传承 + 机缘 + 算计”共同推动。
- 正道和魔道不是单纯善恶阵营，更像不同组织规则：正道重名分、秩序、家族和门派利益；魔道重个人生存、抢夺、交易和临时结盟。
- 关键叙事张力来自“已知未来的人”与“世界原本剧本”的冲突。

### 1.2 可转游戏支柱

- 资源稀缺：元石、蛊材、寿命、情报、身份、传承名额都可以成为玩法资源。
- 风险收益：越界偷取、炼蛊、探索传承、参与正魔冲突，都应有高收益和高后果。
- 身份伪装：真实身份、公开身份、伪装身份、势力立场可以分层记录。
- 剧本抢夺：玩家知道原著机缘，可提前布局，但会改变方源警觉、天意偏移和势力反应。
- 系统残酷：失败不只扣血，还会导致蛊虫死亡、身份暴露、仇家追杀、传承锁死、境界停滞。

## 2. 蛊师与修行体系

### 2.1 境界

蛊师境界可以作为主等级：

- 一转：学堂、开窍、基础真元、第一只本命蛊。
- 二转：能参与家族任务，有初步战斗组合。
- 三转：家老级，拥有稳定战斗流派和势力话语权。
- 四转：地方强者，能影响一城一山一族格局。
- 五转：凡人巅峰，能参与大型传承、商家城、三王传承等高阶事件。
- 六转：蛊仙起点，拥有仙窍，玩法从个人战斗转向经营、灾劫、仙蛊和天地资源。
- 七转：区域级蛊仙，参与超级势力博弈。
- 八转：大势力核心战力，可决定一域格局。
- 九转：尊者层级，接近版本终局或资料片级存在。

### 2.2 资质与空窍

可设计为角色成长底盘：

- 资质等级：甲、乙、丙、丁影响真元容量、恢复速度、突破效率。
- 空窍：角色的修行核心槽位，承载真元、境界和蛊虫温养。
- 真元：战斗和炼蛊消耗资源，可按境界分颜色或品阶。
- 元石：通用货币，同时可恢复真元、购买蛊虫、支付情报、打点关系。
- 十绝体：高天赋高风险模板，拥有极强成长和失控代价。

### 2.3 蛊仙扩展

进入蛊仙后，玩法从“角色养成”扩展为“个人世界经营”：

- 仙窍 / 福地 / 洞天：基地、资源田、人口、生态、灾劫和传承空间。
- 灾劫：周期性考验，逼迫玩家筹备资源、防御、盟友和杀招。
- 仙元：蛊仙行动的高级能源。
- 道痕：构筑流派强度的长期积累，影响杀招、环境和克制。
- 地灵 / 天灵：传承空间或福地管理者，可作为特殊 NPC 和规则守门人。

## 3. 蛊虫设定

### 3.1 蛊虫通用属性

建议每只蛊用以下字段建模：

- 名称
- 品阶：一转至九转，凡蛊或仙蛊
- 流派：力道、智道、宙道、血道、魂道、奴道、变化道、偷道、信道等
- 类型：攻击、防御、移动、侦察、治疗、辅助、资源、炼蛊、身份、运道
- 消耗：真元、仙元、寿命、蛊材、情绪、魂魄或特殊条件
- 使用限制：境界、资质、环境、身份、道痕、前置蛊
- 反噬：失败、喂养不足、过载、被克制时的后果
- 组合：可参与哪些杀招、配方或流派套装

### 3.2 代表性蛊虫

| 蛊虫 | 设计定位 | 可游戏化用途 |
| --- | --- | --- |
| 春秋蝉 | 宙道、重生、逆转时间 | 存档/回溯机制，但应付出气运、天意关注或剧本偏移代价 |
| 酒虫 | 早期修行加速 | 青茅山 MVP 的核心机缘，可强化真元效率 |
| 月光蛊 | 古月一族基础战斗蛊 | 新手战斗技能，适合做低阶攻击模板 |
| 白豕蛊 / 黑豕蛊 | 力量增幅 | 永久属性成长或力道入门 |
| 玉皮蛊 / 白玉蛊 | 防御强化 | 低阶防御套装，和肉身流派绑定 |
| 血颅蛊 | 血道、资质改造 | 高风险禁术，可换资质但引发道德、追杀和血道污染 |
| 骨肉团圆蛊 | 双人协作、血缘/骨道 | 可设计为双角色绑定、资源共享或剧情锁 |
| 第二空窍蛊 | 改变修行结构 | 重大版本机缘，开启副职业/双流派 |
| 定仙游 | 移动仙蛊 | 大地图传送、逃生、远征和偷袭 |
| 智慧蛊 | 智道核心 | 推演、配方破解、剧情预判，但需严苛条件 |
| 宿命蛊 | 天庭核心秩序 | 世界规则级目标，不适合早期可持有，可作为主线压迫 |
| 态度蛊 | 伪装与社交 | 身份欺骗、阵营潜入、谈判检定 |
| 胆识蛊 | 魂道资源 | 魂魄成长、技能升级材料 |
| 鸿运齐天蛊 | 运道顶级资源 | 改变随机事件权重，容易引来争夺 |
| 至尊仙胎蛊 | 身体与身份重构 | 终局级转生/重塑机制，不建议早期开放 |

### 3.3 蛊虫玩法分类

- 战斗蛊：直接造成伤害、控制、防御、移动。
- 经营蛊：生产资源、提升福地生态、改善喂养链。
- 信息蛊：侦察、传信、监控、记忆、推演。
- 身份蛊：伪装、变形、气息遮掩、阵营渗透。
- 成长蛊：提升资质、力量、魂魄、真元质量。
- 剧情蛊：牵引主线，如春秋蝉、宿命蛊、第二空窍蛊。
- 禁忌蛊：血道、魂道、杀人炼蛊等，高收益但改变阵营声望和追杀等级。

## 4. 流派与战斗风格

| 流派 | 主题 | 游戏设计方向 |
| --- | --- | --- |
| 力道 | 肉身、力量、近战爆发 | 简单直接，适合新手和低阶战斗 |
| 智道 | 推演、算计、念头 | 增强事件预判、配方破解、策略选项 |
| 宙道 | 时间、回溯、寿命 | 存档回滚、行动顺序、冷却操控 |
| 血道 | 资质、杀戮、禁忌成长 | 高收益邪道路线，强追杀和声望惩罚 |
| 魂道 | 魂魄、奴役、精神 | 召唤、控制、魂魄资源池 |
| 奴道 | 控兽、军团 | 群体战斗、资源消耗和统御上限 |
| 变化道 | 形态切换 | 多职业姿态、伪装、环境适应 |
| 信道 | 情报、契约、传信 | 谍报系统、任务链、誓约和追踪 |
| 运道 | 概率、气运 | 随机事件权重、掉落、逆境爆发 |
| 偷道 | 盗取、伪装、侵入 | 玩家主修时，可偷物、偷情报、偷身份、偷机缘 |
| 炼道 | 配方、材料、炼制 | 制造系统核心，失败会损材甚至炸炉 |
| 阵道 | 布阵、地形、节点 | 据点防御、传承解谜、战场改造 |

## 5. 地域与阶段地图

### 5.1 青茅山

早期新手沙盒，适合 MVP。

- 古月山寨：学堂、蛊室、家族库房、议事堂、酒馆。
- 白家寨、熊家寨：三寨竞争和区域冲突来源。
- 野外：山林、洞穴、商队路线、狼潮战场。
- 核心事件：开窍、学堂、酒虫、花酒行者遗藏、三寨摩擦、狼潮、青茅山毁灭。

### 5.2 商家城 / 南疆

中期城市玩法。

- 商家：贸易、斗场、少主竞争、身份交易。
- 百家、铁家：追捕、调查、正道压力。
- 三叉山、三王传承：多人争夺型副本。

### 5.3 北原

大型战争与运道线。

- 王庭之争：部族联盟、战功、奴道和军团战。
- 八十八角真阳楼：巨阳仙尊遗留的核心传承副本。
- 黑家、马家、东方家等：部族势力竞争。

### 5.4 中洲

门派、天庭和宿命主线。

- 十大古派：门派制度、资源垄断、正道秩序。
- 天庭：最高秩序势力，宿命蛊、星宿布局、尊者遗产。
- 中洲炼蛊大会：炼道玩法和世界级事件入口。

### 5.5 东海、西漠、南疆后期

- 东海：散修、商贸、海域资源、僵盟。
- 西漠：沙漠资源、房家、盗天遗产、阵道和偷道空间。
- 南疆后期：超级家族、梦境、义天山、影宗布局。

## 8. 游戏系统转译建议

### 8.1 资源系统

- 元石：基础货币和修炼燃料。
- 蛊材：炼蛊材料，按流派、品阶、地域分布。
- 寿命：高阶战略资源，可被消耗、交易、争夺。
- 情报：解锁隐藏选项、降低风险、预测方源行动。
- 身份：进入地点、交易、避开追捕、加入势力。
- 机缘：一次性高价值节点，被玩家、方源和 NPC 竞争。

### 8.2 风险系统

- 方源警觉：玩家截胡越多，方源越会调查、试探、反制。
- 势力通缉：铁家、商家、天庭等按行为生成追捕。
- 天意偏移：玩家改动关键剧情后，随机事件更倾向纠偏。
- 身份破绽：伪装身份长期使用会积累破绽。
- 蛊虫饥饿：蛊不是装备，必须喂养，否则衰弱、反噬或死亡。

### 8.3 事件结构

每个事件建议包含：

- 原著机缘
- 当前持有人
- 方源预计行动
- 玩家可截胡方式
- 失败后果
- 势力反应
- 后续剧本偏移

示例事件类型：

- 偷蛊：偷取蛊室、商队、敌人身上蛊虫。
- 偷情报：提前知道传承入口、蛊方、追捕路线。
- 偷身份：冒充商队成员、家族子弟、散修、门派弟子。
- 偷机缘：酒虫、遗藏、传承名额、仙蛊线索。
- 偷关系：让 NPC 信任玩家而非原剧情对象。

## 9. MVP 内容建议

如果当前项目第一版仍聚焦青茅山，建议优先抽取这些内容：

- 地点：学堂、蛊室、酒馆、山寨库房、商队营地、野外洞穴、狼潮战场。
- NPC：方源、方正、古月长老、学堂家老、商队管事、白凝冰、白家/熊家代表。
- 蛊虫：希望蛊、月光蛊、酒虫、小光蛊、玉皮蛊、白豕蛊、血颅蛊、春秋蝉。
- 系统：开窍资质、每日行动点、元石收支、偷盗检定、方源警觉、身份暴露、蛊虫喂养。
- 主线闭环：开窍 -> 学堂 -> 酒虫 -> 商队 -> 三寨冲突 -> 白凝冰线 -> 狼潮 -> 离开青茅山。

## 10. IP 使用提醒

如果这是商业游戏，不能直接使用《蛊真人》的角色名、蛊名、势力名和剧情结构。可保留“蛊虫修行、资源争夺、预知截胡、身份伪装、残酷修仙社会”等抽象设计，再重命名和重构世界观。
