# 可选机缘生产剧本（二）：Q04 至 Q05

版本：`2.0`

两条机缘都只做一次直接选择与一次可能发生的战斗。它们不改变主线章节，也不改变最终离山按钮。

## 生产约束

- Q04 与 Q05 使用统一机缘状态：`inactive`、`available`、`contested`、
  `resolved`、`gone`。
- 场景结算后立刻更新任务 UI 的当前、下一和完成显示。
- 玩家离开入口等同于主动跳过，不生成新的强制步骤。
- 已经取得的物品在战斗失败或撤退后仍保留。
- 战斗修为按统一战斗表结算，每个实例只发放一次。
- 偷盗成功后的物品直接进入普通行囊。
- 偷盗失败只播放本场反应并结束本次交互。
- 青书的生还或死亡是公开世界事实。
- 青书不在场时不生成替代人物继续他的个人机缘。
- 两个关卡都复用现有地图、棋盘、敌人和技能资源。

| 机缘 | 地图复用 | 战斗复用 | 最多新表现 |
| --- | --- | --- | --- |
| Q04 | 药堂后院 | 普通叶蛾 `1v1` | 九叶生机草地图物件 |
| Q05 | 北坡白石沟 | 精壮电狼 `1v2` | 青书受伤短演出 |

## Q04《九叶生机草》

开放锚点：`D18-S01`

### Q04-S01 药圃绿影

- 场景 ID：`Q04-S01`
- 地点：古月药堂后院药圃
- 角色：玩家、药圃管事
- 当前目标：在药圃中选择取得九叶生机草的方式。
- 简短对白：
  - 药圃管事：“叶蛾钻进苗床，今晚会啃坏幼株。”
  - 玩家：“中间那株已经长成草蛊。”
  - 药圃管事：“帮我清虫，可以分你一株新苗。”
- 选项：
  1. 靠近管事并打开偷盗列表。
  2. 接受清理叶蛾。
  3. 离开药圃。
- 地图/旅行/8×6 战斗交互：第一项使用地图偷盗流程；列表只显示当前可取物，玩家选择九叶生机草后进行一次成功或失败判定；第二项进入苗床战斗；第三项直接结算。
- 即时奖励：偷盗成功时九叶生机草直接进入普通行囊并将 Q04 设为 `resolved`；偷盗失败时播放管事生气立绘、物品不移动并结束本次机缘；离开时 Q04 设为 `resolved`。
- 下一场景：清理叶蛾进入 `Q04-S02` 苗床护草；其他结果返回药堂地图。

### Q04-S02 苗床护草

- 场景 ID：`Q04-S02`
- 地点：古月药堂后院苗床
- 角色：玩家、叶蛾、药圃管事
- 当前目标：击退叶蛾。
- 简短对白：
  - 药圃管事：“叶蛾就在中央苗格后面。”
  - 玩家：“我把它逼到石槽边。”
  - 药圃管事：“打不住就先退，别倒在药圃里。”
- 选项：
  1. 从苗床正面进入战斗。
  2. 从水槽侧面进入战斗。
  3. 放弃清理并离开。
- 地图/旅行/8×6 战斗交互：普通 `1v1`；`battleId=B-Q04-01`，玩家默认 `(1,3)`，叶蛾 `(6,3)`，中央幼株只作为不可进入的背景格 `(4,3)`，石槽障碍 `(3,1)`、`(3,5)`；第二项让玩家出生 `(1,1)`；叶蛾完全使用统一敌方 AI，只攻击玩家。
- 即时奖励：战斗胜利获得九叶生机草幼株、修为进度 `+8`；失败或撤退获得修为进度 `+2`，不获得幼株；Q04 设为 `resolved`。
- 下一场景：`返回药堂地图`

## Q05《青书命运》

开放锚点：`D25-S01`

若古月青书在进入本机缘前已经死亡或离山，Q05 直接设为 `gone`，北坡只保留一个空地图标记。

### Q05-S01 北坡断路

- 场景 ID：`Q05-S01`
- 地点：北坡白石沟
- 角色：玩家、古月青书、白凝冰
- 当前目标：找到被狼群截断退路的青书。
- 简短对白：
  - 青书：“巡山队已经退走，我被两只狼缠住。”
  - 白凝冰：“他的战斗结束了，你还要接着打？”
  - 玩家：“人还站着，结果就没定。”
- 选项：
  1. 进入白石沟救援。
  2. 让青书向边缘撤，自己引开狼群。
  3. 离开白石沟。
- 地图/旅行/8×6 战斗交互：前两个选项沿方向旅行进入救援棋盘；第二项让玩家从另一侧出生；第三项立即离开。
- 即时奖励：进入救援时青书公开状态设为受伤；离开时青书公开状态设为死亡，Q05 设为 `resolved`。
- 下一场景：救援进入 `Q05-S02` 两狼夹路；离开返回北坡地图。

### Q05-S02 两狼夹路

- 场景 ID：`Q05-S02`
- 地点：北坡白石沟战场
- 角色：玩家、古月青书、两只精壮电狼
- 当前目标：击退两只电狼并打开青书的退路。
- 简短对白：
  - 青书：“我还能挡住左边一回合。”
  - 玩家：“你只管往出口走。”
  - 青书：“好，活着回山寨。”
- 选项：
  1. 从正面救援。
  2. 从侧坡救援。
  3. 撤出白石沟。
- 地图/旅行/8×6 战斗交互：精英 `1v2`；`battleId=B-Q05-01`，玩家默认 `(1,3)`，电狼 `(6,3)`、`(6,1)`；青书只出现在战前与战后演出，不进入棋盘；第二项让玩家出生 `(1,1)`；两只电狼完全使用统一敌方 AI，只攻击玩家。
- 即时奖励：胜利获得修为进度 `+12`，青书公开状态改为受伤并进入下一场景；失败或撤退获得修为进度 `+2`，青书公开状态设为死亡，Q05 设为 `resolved`。
- 下一场景：胜利进入 `Q05-S03` 青藤归路；其他结果返回北坡地图。

### Q05-S03 青藤归路

- 场景 ID：`Q05-S03`
- 地点：北坡出口
- 角色：玩家、古月青书
- 当前目标：决定如何把受伤的青书送回安全区域。
- 简短对白：
  - 青书：“腿还能走，只是快不起来。”
  - 玩家：“山寨和巡山哨都能落脚。”
  - 青书：“你选近的，不必陪我走远。”
- 选项：
  1. 护送青书回山寨。
  2. 送青书到巡山哨。
  3. 指明方向后先行离开。
- 地图/旅行/8×6 战斗交互：前两个选项播放短距离方向旅行；第三项直接返回北坡出口，不再生成战斗。
- 即时奖励：青书公开状态设为受伤；护送回山寨获得青藤护符 `1`，送到巡山哨获得疗伤药 `2`，先行离开无物品奖励；Q05 设为 `resolved`。
- 下一场景：`返回当前地图`
