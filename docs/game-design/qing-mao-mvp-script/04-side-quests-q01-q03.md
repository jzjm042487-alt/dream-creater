# 可选机缘生产剧本（一）：Q01 至 Q03

版本：`2.0`

三条机缘都可跳过。进入后只在本条机缘内推进，结算后返回玩家进入机缘前的地图。

## Q01《月下酒虫》

开放锚点：`D05-S01`

### Q01-S01 酒香指路

- 场景 ID：`Q01-S01`
- 地点：古月山寨酒坊
- 角色：玩家、酒坊伙计、古月方源（缺席时由同届竞争者替代）
- 当前目标：确认甜酒香飘来的野外方向。
- 简短对白：
  - 酒坊伙计：“最浓的一次，在南坡月兰花开的时候。”
  - 方源：“风从西面来，香味却从北边绕回。”
  - 玩家：“那不是酒坛，是会移动的东西。”
- 选项：
  1. 记住月兰花与逆风方向。
  2. 领取一小包花瓣作饵。
  3. 放弃这条机缘。
- 地图/旅行/8×6 战斗交互：前两个选项在南坡入口添加“淡酒香”事件槽；第三个选项立即结算。
- 即时奖励：选项一获得气味提示；选项二获得月兰花瓣 `1`；放弃时 Q01 设为 `resolved`。
- 下一场景：前两个选项进入 `Q01-S02` 三段香痕；放弃返回当前地图。

### Q01-S02 三段香痕

- 场景 ID：`Q01-S02`
- 地点：南坡竹林
- 角色：玩家、古月方源（缺席时由无名寻宝者替代）
- 当前目标：连续找出三段最浓的酒香。
- 简短对白：
  - 玩家：“风会散，叶尖的甜露不会。”
  - 方源：“你走你的，我走我的。”
  - 玩家：“谁先找到，谁先动手。”
- 选项：
  1. 开始追踪。
  2. 先撒月兰花瓣再追踪。
  3. 让当前竞争者继续追，自己离开。
- 地图/旅行/8×6 战斗交互：气味追踪小游戏共三轮；每轮显示三个方向线索，最浓线索同时具有甜露与白色粉屑；选中后用对应相对方向移动；撒花瓣可让第一轮正确线索持续高亮。
- 即时奖励：完成三轮发现月兰花丛；离开时当前竞争者取得酒虫，Q01 设为 `resolved`。
- 下一场景：完成追踪进入 `Q01-S03` 花丛捕捉；离开返回当前地图。

### Q01-S03 花丛捕捉

- 场景 ID：`Q01-S03`
- 地点：月兰花丛
- 角色：玩家、酒虫、古月方源（缺席时由无名寻宝者替代）
- 当前目标：从花丛中找出酒虫所在格。
- 简短对白：
  - 玩家：“香气在这一片打转。”
  - 方源：“只够一个人先下手。”
  - 玩家：“那就看谁读得准。”
- 选项：
  1. 放下花瓣并开始捕捉。
  2. 把位置让给当前竞争者。
  3. 惊散花丛，谁也不取。
- 地图/旅行/8×6 战斗交互：捕捉小游戏使用 `3×3` 花格；一次香气脉冲显示酒虫所在行，一次露珠晃动显示所在列；玩家选择交点格一次；选对即捕捉，选错则酒虫逃走。
- 即时奖励：捕捉成功获得酒虫并将 Q01 设为 `resolved`；选错时只保留月兰花瓣；让出时当前竞争者取得酒虫；惊散时酒虫离开本图。
- 下一场景：`返回当前地图`

## Q02《花酒遗藏》

开放锚点：`D14-S01`

### Q02-S01 山缝旧痕

- 场景 ID：`Q02-S01`
- 地点：南坡野外入口、南坡山缝
- 角色：玩家、古月方源（缺席时由无名寻宝者替代）
- 当前目标：沿旧脚印抵达山缝内层。
- 简短对白：
  - 玩家：“脚印很旧，边缘却有新擦痕。”
  - 方源：“有人来过，不代表拿走了全部。”
  - 玩家：“先进去再说。”
- 选项：
  1. 沿脚印前进。
  2. 沿石壁风声前进。
  3. 放弃进入。
- 地图/旅行/8×6 战斗交互：调用隐藏路径；前两个选项使用不同首个方向提示，最终都抵达内层影壁；放弃直接结算。
- 即时奖励：抵达后发现花酒遗藏外层；放弃时 Q02 设为 `resolved`。
- 下一场景：抵达进入 `Q02-S02` 影壁与地花；放弃返回当前地图。

### Q02-S02 影壁与地花

- 场景 ID：`Q02-S02`
- 地点：花酒遗藏外层石室
- 角色：玩家
- 当前目标：在影壁与地花之间选择一种开启方式。
- 简短对白：
  - 玩家：“影壁记录旧战，地花封着石门。”
  - 玩家：“两处都能动，先碰哪一处会改变入口。”
- 选项：
  1. 观察影壁招式后开门。
  2. 采下地花粉后开门。
  3. 取走散落蛊材并离开。
- 地图/旅行/8×6 战斗交互：第一项播放三段短影像并标记守卫射程；第二项完成三次节奏采粉；第三项关闭内门并结算。
- 即时奖励：观察影壁获得下一战首回合 `buff_danger_sense`；采粉获得地花粉 `2`；离开获得石屑蛊材 `2` 并将 Q02 设为 `resolved`。
- 下一场景：前两项进入 `Q02-S03` 石室守卫；离开返回当前地图。

### Q02-S03 石室守卫

- 场景 ID：`Q02-S03`
- 地点：花酒遗藏内层石室
- 角色：玩家、石皮傀儡、古月方源（缺席时由无名寻宝者替代）
- 当前目标：击败石皮傀儡并取得内层遗物。
- 简短对白：
  - 玩家：“门后的东西还在。”
  - 方源：“傀儡醒了，先活下来。”
  - 玩家：“胜的人拿蛊，退的人拿路。”
- 选项：
  1. 进入战斗。
  2. 让当前竞争者先动后进入战斗。
  3. 从石室边缘撤离。
- 地图/旅行/8×6 战斗交互：精英 `1v1`；`battleId=B-Q02-01`，玩家 `(1,3)`，石皮傀儡 `(6,3)`，障碍 `(3,2)`、`(4,4)`；第二项让傀儡首回合结束后玩家再行动；第三项直接撤退。
- 即时奖励：胜利获得白豕蛊、元石 `5`、修为进度 `+12`；失败或撤退获得修为进度 `+2`，并保留本条已拾取蛊材；当前竞争者取得未拿走的显眼遗物；Q02 设为 `resolved`。
- 下一场景：`返回当前地图`

## Q03《商队山货》

开放锚点：`D11-S01`

### Q03-S01 短途护送

- 场景 ID：`Q03-S01`
- 地点：商队营地、南坡野外入口
- 角色：玩家、贾金生（缺席时由商队伙计替代）、商队护卫
- 当前目标：决定是否护送一箱山货到南坡交接点。
- 简短对白：
  - 贾金生：“一箱低阶山货，送到坡下就结钱。”
  - 商队护卫：“路上若有人拦，货和人先保一个。”
  - 玩家：“报酬先说清楚。”
- 选项：
  1. 接受护送。
  2. 接受并把货箱绑在拖架上。
  3. 拒绝这次机会。
- 地图/旅行/8×6 战斗交互：前两个选项启动方向旅行；拖架让战斗中的货箱固定在玩家出生点后方；拒绝直接结算。
- 即时奖励：接受时获得临时货箱；拒绝时 Q03 设为 `resolved`。
- 下一场景：接受进入 `Q03-S02` 山路劫货；拒绝返回商队营地。

### Q03-S02 山路劫货

- 场景 ID：`Q03-S02`
- 地点：南坡交接点
- 角色：玩家、劫货蛊师、商队护卫
- 当前目标：完成交货、击退劫货者或撤离。
- 简短对白：
  - 劫货蛊师：“箱子留下，人可以走。”
  - 商队护卫：“交接点就在他身后。”
  - 玩家：“那就从棋盘上过去。”
- 选项：
  1. 守着货箱迎战。
  2. 放下货箱，从侧面迎战。
  3. 撤离并放弃护送。
- 地图/旅行/8×6 战斗交互：普通 `1v1`；`battleId=B-Q03-01`，玩家 `(1,3)`，劫货蛊师 `(6,3)`，货箱 `(1,4)`，障碍 `(3,2)`、`(4,4)`；第二项让玩家出生 `(1,1)`；第三项直接从边缘撤退。
- 即时奖励：胜利获得修为进度 `+8`、元石 `6`、低阶疗伤配方 `1`；失败或撤退获得修为进度 `+2`，不获得货物报酬；Q03 设为 `resolved`。
- 下一场景：`返回商队营地`
