# 主线生产剧本（一）：Day 0 至 Day 10

版本：`2.0`

章节标签只表示顺序。玩家探索、休息、训练或处理可选机缘时，当前章节保持不变。

## D00-S01 世界载入

- 场景 ID：`D00-S01`
- 地点：角色创建界面、古月旁支竹楼
- 角色：玩家、生成器
- 当前目标：确认角色并进入青茅山。
- 简短对白：
  - 生成器：“青茅山资料已经载入。”
  - 生成器：“原著可供查询，当前世界由行动决定。”
  - 玩家：“先从古月山寨开始。”
- 选项：
  1. 确认角色。
  2. 查看一次原著资料后确认。
- 地图/旅行/8×6 战斗交互：打开角色卡；第二个选项临时打开资料查询，关闭后回到确认按钮。
- 即时奖励：初始行囊加入元石 `5`、疗伤药 `1`；建立普通存档；主线设为 `active`。
- 下一场景：`D01-S01` 竹楼醒来
