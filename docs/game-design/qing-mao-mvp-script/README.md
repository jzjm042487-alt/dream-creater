## 1. 包目标

本包只承担青茅山 MVP 的可制作剧情内容。

玩家在古月山寨开窍、学习蛊师基础、进入野外、争夺五条可选机缘、经历狼潮，并在最后一步直接选择离山方向。

主线固定向前。

玩家可以随时自由探索、训练、休息、整理空窍或查看原著资料。

这些活动不会让当前章节失效，也不会让下一章节消失。

## 3. 章节标签

`Day 0` 到 `Day 30` 是章节标签。

它们不是游戏内倒计时，也不代表玩家只能做一天的事。

章节只在当前主线场景完成后切换。

休息、夜间修炼、地图闲逛和可选机缘都不推进标签。

玩家跳过任何可选机缘，主线仍按原顺序继续。

## 4. 场景格式

每个场景只使用下列字段：

```text
场景 ID
地点
角色
当前目标
简短对白
选项
地图/旅行/8×6 战斗交互
即时奖励
下一场景
```

对白使用原创短句。

每个场景最多三个选项。

没有选择时写“无”。

所有选项必须在同一场景内给出即时结果。

选择可以改变所得物品、角色是否在场、角色存亡或一个公开世界事实。

选择不能阻止主线进入下一场景。

## 5. 主线制作规则

每个章节只制作一个主场景。

主场景完成后，任务 UI 立即显示：

- 当前步骤已完成；
- 下一步骤的场景标题；
- 整条主线是否完成。

主线战斗允许胜利、失败或撤退。

三种结果都结束当前场景并进入下一章节。

胜利获得对应战斗奖励。

失败或撤退按生存结算获得少量修为，玩家返回场景入口并继续剧情。

## 6. 地图与旅行

山寨地图使用靠近角色后的直接交互。

野外旅行只显示：

- 前；
- 后；
- 左；
- 右。

旅行途中可以进入普通战斗、危险探索、追踪小游戏、捕捉小游戏或一次性机缘。

玩家不通过点击地点完成远距离传送。

野外返回、连续后退和第 20 步保底均由隐藏路径规则处理，本包只引用结果。

## 7. 战斗

所有战斗使用 `8×6` 棋盘。

玩家回合先移动一次，再执行一个动作。

动作可以是肉搏、蛊虫技能、杀招、防御、道具或撤退。

命中只取决于是否合法位于技能射程。

主线以 `1v1` 为主，只有明确标注的场景使用 `1v2`。

剧本文本不创建额外战斗规则。

## 8. 可选机缘

MVP 只制作五条：

| 编号 | 名称 | 核心玩法 | 主线影响 |
| --- | --- | --- | --- |
| Q01 | 月下酒虫 | 气味追踪与捕捉 | 无 |
| Q02 | 花酒遗藏 | 隐藏路线与洞窟战斗 | 无 |
| Q03 | 商队山货 | 护送或格子战斗 | 无 |
| Q04 | 九叶生机草 | 地图交互、偷盗或护草战斗 | 无 |
| Q05 | 青书命运 | 一次救援战斗 | 无 |

每条机缘统一记录 `inactive`、`available`、`contested`、`resolved` 或
`gone`。简单场景通常只经过 `inactive -> available -> resolved/gone`；
只有实际出现两名争夺者时才进入 `contested`。

`resolved` 只说明这条内容已经结算。

这些值来自机缘枚举，不复用任务状态，不使用 `open` 或 `unknown`。

机缘不会生成新的强制任务。

## 9. 方源缺席替代

方源使用普通角色规则。

他可以受伤、失败、离开或死亡。

任何需要方源提供信息、竞争位置或一句反应的场景，都在角色字段中写明通用替代：

- 同届竞争者；
- 无名寻宝者；
- 巡山蛊师；
- 商队伙计。

替代角色只承担当前场景功能，不继承方源台词习惯，也不把他带回世界。

## 10. 制作边界

场景背景只写可见地点。

角色只写实际出镜者。

奖励在场景结束时一次结算。

物品取得后进入普通行囊。

偷盗只进行一次成功或失败判定，结果在地图交互层显示。

成人角色可使用服装与情绪立绘标签。

地图 Q 版角色不切换这些标签。

原著资料查询只提供资料，不改变当前世界。

## 11. 交付检查

- `D00-S01` 到 `D30-S01` 连续可达。
- 每个主场景都有明确的下一场景。
- 每个场景最多三个选项。
- 每次战斗都标明敌方、初始位置和三种结束结果。
- 五条机缘都能独立完成或跳过。
- 方源出场场景都有通用缺席替代。
- 离山选择不读取其他任务结果。
- 所有对白均为本项目原创短句。
- 没有长篇复述原著文本。
