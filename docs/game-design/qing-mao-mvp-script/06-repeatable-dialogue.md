# 可重复短对白

版本：`2.0`

本文件只提供常驻地图交谈。重复播放不发放元石、修为、物品或角色数值。

角色公开状态为死亡、失踪或离山时，从地图移除对应入口。

## 1. 古月方源

### R-FY-01 山寨碰面

- 场景 ID：`R-FY-01`
- 地点：古月山寨公共区域
- 角色：玩家、古月方源（缺席时由同届竞争者替代）
- 当前目标：与方源进行一次短交谈。
- 简短对白：
  - 方源：“有事？”
  - 玩家：“只看你准备往哪走。”
  - 方源：“路在地图上，目的不在。”
- 选项：
  1. 问最近的野外入口。
  2. 问最近公开战绩。
  3. 结束交谈。
- 地图/旅行/8×6 战斗交互：第一项打开野外地图，第二项打开天骄名册，第三项关闭对话。
- 即时奖励：无。
- 下一场景：`返回当前地图`

### R-FY-02 机缘碰面

- 场景 ID：`R-FY-02`
- 地点：任一开放机缘入口
- 角色：玩家、古月方源（缺席时由同届竞争者替代）
- 当前目标：确认当前地点是否还有可取物。
- 简短对白：
  - 玩家：“你来得不慢。”
  - 方源：“快慢只看最后拿走什么。”
  - 玩家：“各走各的。”
- 选项：
  1. 进入当前机缘。
  2. 查看资料查询。
  3. 离开入口。
- 地图/旅行/8×6 战斗交互：打开当前机缘、资料查询或地图；不生成额外事件。
- 即时奖励：无。
- 下一场景：`返回当前地图`
