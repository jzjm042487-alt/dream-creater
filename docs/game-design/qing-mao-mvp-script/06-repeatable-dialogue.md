# 可重复与状态对白

版本：`1.0-rc1`

本文件用于主线与支线场景之外的角色交谈、状态反馈和日终提醒。它不提供无限关系收益。

## 0. 调用规则

- 每名 NPC 每个关键日第一次普通交谈不消耗 AP；同日再次交谈只返回短句。
- 有明确任务、训练、交易或调查效果的对话按对应场景消耗 AP。
- 同一主题首次获得关系或旗标，重复选择只播放变体，不重复奖励。
- NPC 因核心动机拒绝时，UI 显示原因文本，不伪装成单纯关系数值不足。
- 方源没有敌意条；重复对白读取 `认知 + 警觉 + 当前目标 + 是否目标冲突`。
