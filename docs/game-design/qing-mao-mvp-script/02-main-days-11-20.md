# 主线生产剧本（二）：Day 11 至 Day 20

版本：`2.0`

本段把玩家从学堂引向商队与野外。三条可选机缘只在地图上开放，不改变主线顺序。

## D11-S01 商队入寨

- 场景 ID：`D11-S01`
- 地点：古月山寨南门、商队营地
- 角色：玩家、贾金生、贾富、古月方源（缺席时由商队伙计替代）
- 当前目标：穿过南门并进入商队营地。
- 简短对白：
  - 贾金生：“山货、蛊材、旧器，先看再买。”
  - 贾富：“营地里不准动手，出山另说。”
  - 玩家：“我先认清摊位。”
- 选项：
  1. 先看山货摊。
  2. 先看护送告示。
  3. 直接进入营地。
- 地图/旅行/8×6 战斗交互：南门靠近交谈；三个选项分别高亮对应地图点，随后都开放营地自由移动。
- 即时奖励：发现商队营地；Q03《商队山货》设为 `available`；商店入口开放。
- 下一场景：`D12-S01` 石摊辨货

## D12-S01 石摊辨货

- 场景 ID：`D12-S01`
- 地点：商队山货摊
- 角色：玩家、山货摊主、古月方源（缺席时由商队伙计替代）
- 当前目标：从三件普通山货中领取一件样品。
- 简短对白：
  - 山货摊主：“都是低阶材料，拿一件试手。”
  - 方源：“材料的用法，比摊主的故事值钱。”
  - 玩家：“我只选现在用得上的。”
- 选项：
  1. 领取月兰花瓣。
  2. 领取山猪牙。
  3. 领取青玉苔。
- 地图/旅行/8×6 战斗交互：地图摊位交互；选择后展示物品说明并关闭样品列表。
- 即时奖励：获得所选蛊材 `2` 份；其他两项保持商店可购买。
- 下一场景：`D13-S01` 山货委托

## D13-S01 山货委托

- 场景 ID：`D13-S01`
- 地点：商队外圈、古月山寨南门
- 角色：玩家、贾金生
- 当前目标：把一只封好的货箱送到南门守卫处。
- 简短对白：
  - 贾金生：“不用出山，只送到门边。”
  - 玩家：“箱子里是什么？”
  - 贾金生：“普通药材，守卫会当面验。”
- 选项：
  1. 接过货箱。
  2. 让他先开箱再搬。
  3. 拒绝搬运并自行去南门。
- 地图/旅行/8×6 战斗交互：前两个选项进入短距离搬运；第三个选项直接跟随路标；三条路径都以抵达南门结束。
- 即时奖励：完成搬运获得元石 `3`；查看货箱额外获得常见药材图鉴；拒绝则无物品奖励。
- 下一场景：`D14-S01` 竹林岔路

## D14-S01 竹林岔路

- 场景 ID：`D14-S01`
- 地点：南坡野外入口、竹林岔路
- 角色：玩家、巡山蛊师
- 当前目标：使用方向旅行找到山缝路标。
- 简短对白：
  - 巡山蛊师：“雨后石壁会回声，别把它当兽叫。”
  - 玩家：“回声最重的方向就是山缝。”
  - 巡山蛊师：“记好入口，想回去就连续后退。”
- 选项：
  1. 从南坡入口出发。
  2. 整理空窍后出发。
- 地图/旅行/8×6 战斗交互：启动隐藏路径地图；抵达竹林岔路后播放三次方向提示，玩家自行选择前、后、左、右找到山缝。
- 即时奖励：发现南坡山缝；Q02《花酒遗藏》设为 `available`。
- 下一场景：`D15-S01` 雨夜归寨

## D15-S01 雨夜归寨

- 场景 ID：`D15-S01`
- 地点：古月旁支竹楼
- 角色：玩家
- 当前目标：选择休息、修炼或整理装备。
- 简短对白：
  - 玩家：“雨把山路压静了。”
  - 玩家：“今晚做什么，都不耽误明日的路。”
- 选项：
  1. 休息。
  2. 夜间修炼。
  3. 整理装备后休息。
- 地图/旅行/8×6 战斗交互：打开对应角色界面；选择完成后回到竹楼场景。
- 即时奖励：休息恢复生命与真元并清除 `untilRest` 效果；夜间修炼恢复真元并获得修为进度 `+2`；整理不额外发物品。
- 下一场景：`D16-S01` 山缝回声

- 场景 ID：`D16-S01`

- 角色：玩家
- 当前目标：找到回声背后的空洞。
- 简短对白：

  - 玩家：“地上的旧痕一直通向石缝。”

- 地图/旅行/8×6 战斗交互：危险探索；前两个选项完成三点观察小游戏，第三个选项直接结束场景。
- 即时奖励：完成小游戏获得首次危险探索修为进度 `+4` 并发现外层石室；返回选择只发现外层石室。
- 下一场景：`D17-S01` 地花石门

## D17-S01 地花石门

- 场景 ID：`D17-S01`
- 地点：山缝外层石室
- 角色：玩家
- 当前目标：清理堵在石门前的地甲虫。
- 简短对白：
  - 玩家：“石门没锁，是虫群把缝隙封住了。”
  - 玩家：“先引开大的一只。”
- 选项：
  1. 进入战斗。
  2. 查看蛊虫配置后进入战斗。
- 地图/旅行/8×6 战斗交互：普通 `1v1`；`battleId=B-D17-01`，玩家 `(1,3)`，地甲虫 `(6,3)`，障碍 `(3,1)`、`(4,4)`；敌人使用近战；胜、负或撤退均返回石门外。
- 即时奖励：胜利修为进度 `+8`、地花粉 `2`；失败或撤退修为进度 `+2`、地花粉 `1`。
- 下一场景：`D18-S01` 药堂见闻
