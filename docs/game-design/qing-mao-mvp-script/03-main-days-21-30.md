## D21-S01 小兽潮

- 场景 ID：`D21-S01`

- 角色：玩家、巡山蛊师

  2. 查看空窍后进入战斗。

- 即时奖励：胜利修为进度 `+8`、狼皮 `1`；失败或撤退修为进度 `+2`。
