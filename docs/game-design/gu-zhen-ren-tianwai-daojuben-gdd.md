# 《蛊真人：天外盗剧本》完整游戏策划案

## 1. 游戏概述

### 1.1 游戏类型

文字剧情驱动的开放世界 RPG 原型。

核心形式为：

- 大地图地点选择。
- 文字事件推进。
- 分支任务和剧情选择。
- 回合制或半回合制战斗。
- 数值成长。
- 盗道技能检定。
- 方源动态对抗。
- NPC 缘线和势力关系变化。

第一版不追求 3D 开放世界，而是采用“地图节点 + 文本事件 + 数值系统”的方式做出青茅山篇沙盒感。

### 1.2 核心卖点

玩家不是方源，而是读过原著的天外之魔，主修盗道，目标是在方源之前夺取机缘、身份、记忆、缘线和剧情归属。

一句话：

玩家偷的不是东西，而是方源的剧本。

### 1.3 第一版范围

第一版只做青茅山篇：

- 开窍。
- 学堂。
- 酒虫机缘。
- 商队。
- 三寨冲突。
- 白凝冰线。
- 狼潮。
- 离开青茅山。

第一版目标不是内容巨大，而是跑通一条完整闭环：

玩家成长、偷盗、截胡、被方源警觉、与 NPC 建立或夺取缘线，最后在狼潮中结算命运。

## 2. 目标体验

### 2.1 玩家幻想

玩家应该感觉自己像一个熟读原著、极度危险的盗道穿越者：

- 知道别人不知道的未来。
- 能提前布局截胡机缘。
- 能偷资源、偷情报、偷身份、偷缘线。
- 能和方源抢同一个剧本。
- 每次成功都很爽，但每次成功都可能留下后患。

### 2.2 情绪节奏

游戏节奏应分为四种状态循环：

1. 安静谋划
   - 查看原著记忆。
   - 调查地点。
   - 分析方源行动。
   - 准备偷盗目标。

2. 高风险执行
   - 潜入、偷盗、交易、救人、栽赃、截胡。
   - 通过技能检定和选择结算。

3. 后果发酵
   - 方源警觉变化。
   - NPC 关系变化。
   - 势力开始追查。
   - 新任务或危机出现。

4. 阶段爆发
   - 学堂考核。
   - 商队到来。
   - 三寨冲突。
   - 狼潮。
   - 青茅山结局。

## 3. 游戏结构

### 3.1 章节结构

第一版青茅山篇分为 6 章。

#### 第 1 章：开窍之前

目标：

- 建立身份。
- 认识方源、方正、学堂、古月山寨。
- 获得第一批原著记忆提示。

关键事件：

- 玩家穿越。
- 开窍大典倒计时。
- 初次观察方源。
- 第一次小偷盗教学。

章节结算：

- 玩家资质确定。
- 初始蛊虫或初始盗道天赋确定。
- 方源警觉初始值确定。

#### 第 2 章：学堂暗线

目标：

- 进入学堂体系。
- 争夺元石和修炼资源。
- 尝试接触酒虫线索。

关键事件：

- 学堂课程。
- 同窗冲突。
- 方正资源倾斜。
- 偷元石、偷情报、偷排班。
- 方源开始压榨方正。

章节结算：

- 玩家修炼速度。
- 方源是否开始关注玩家。
- 酒虫线是否开启。

#### 第 3 章：酒虫截胡

目标：

- 争夺第一卷关键机缘。
- 决定玩家和方源的第一次正面剧本冲突。

可选路线：

- 原著记忆调查路线。
- 偷听方源路线。
- 跟踪商贩路线。
- 交易购买路线。
- 设局让别人先踩雷路线。

章节结算：

- 酒虫归属。
- 方源警觉大幅变化。
- 玩家修炼速度变化。
- 后续方源备用计划开启。

#### 第 4 章：商队与身份

目标：

- 接触外部世界。
- 开启身份盗取和商队缘线。
- 获得离开青茅山的可能。

关键事件：

- 商队到来。
- 账册、货物、令牌、贵客身份。
- 商队成年女角色缘线。
- 方源交易或谋算商队。

章节结算：

- 玩家是否获得外部身份。
- 是否有逃离青茅山路线。
- 商队对玩家态度。

#### 第 5 章：三寨与白凝冰

目标：

- 扩大地图和冲突。
- 引入白家寨、熊家寨、白凝冰相关变化。
- 让方源与玩家进入更明显竞争。

关键事件：

- 三寨摩擦。
- 白凝冰传闻。
- 野外伏击。
- 家族资源紧张。
- 玩家可挑拨、合作或避开。

章节结算：

- 三寨关系。
- 白凝冰线是否偏移。
- 方源是否将玩家列为主要变量。

#### 第 6 章：狼潮与离山

目标：

- 结算整个青茅山篇。
- 玩家带着所得进入下一篇章。

关键事件：

- 狼潮爆发。
- 山寨守卫。
- 暗中转移资源。
- 逃离路线选择。
- 方源最终行动。

章节结算：

- 玩家生还状态。
- 方源状态。
- 青茅山毁灭程度。
- 玩家带走的蛊虫、资源、身份、缘线。
- 下一篇章开局。

## 4. 核心玩法系统

### 4.1 时间系统

游戏以“日”为基础单位。

每一天分为：

- 清晨。
- 白天。
- 傍晚。
- 夜晚。

玩家每天有有限行动点：

- 普通行动消耗 1 点。
- 高风险行动消耗 2 点。
- 夜间行动增加偷盗收益，但也提高暴露和疲劳风险。

推荐初始每日行动点：3。

### 4.2 地点系统

每个地点有：

- 开放时间。
- 可遇到 NPC。
- 可触发事件。
- 可偷盗目标。
- 守卫强度。
- 方源出现概率。
- 风险等级。

示例地点：

- 学堂：课程、同窗、方正、排班情报。
- 蛊室：蛊虫、守卫、令牌、登记册。
- 酒馆：传闻、酒虫线、商旅消息。
- 商队营地：货物、账册、身份、交易。
- 野外：采集、战斗、伏击、隐藏机缘。
- 家族库房：高价值资源，高守卫。

### 4.3 事件系统

事件是游戏主要内容载体。

每个事件包含：

- 标题。
- 描述。
- 触发条件。
- 参与角色。
- 可选行动。
- 技能检定。
- 奖励。
- 失败后果。
- 后续事件。
- 是否影响方源警觉。
- 是否影响缘线。

事件设计原则：

- 每个关键事件至少 3 个解决方式。
- 失败后应产生新分支，而不是直接结束。
- 选择应影响世界状态。
- 文本要写出蛊界的冷酷、利益和算计。

## 5. 剧本设计

### 5.1 剧本核心

剧本不是线性剧情，而是事件网络。

第一版主剧本有三条线交织：

1. 玩家成长线
   - 开窍、修炼、获得蛊虫、提升盗道。

2. 方源竞争线
   - 方源按原著路线行动，玩家截胡后他改线。

3. 青茅山毁灭线
   - 狼潮和三寨局势逐步逼近，不因玩家停滞而停止。

### 5.2 剧本节点分类

- 必然节点：开窍、商队到来、狼潮。
- 可抢节点：酒虫、商队身份、关键蛊虫、传承线索。
- 可变节点：NPC 生死、缘线归属、三寨关系。
- 隐藏节点：方源计划、成年女角色秘密、传承入口。
- 崩坏节点：方源警觉 100 后，原著路线大幅偏移。

### 5.3 剧本写法模板

每个事件建议按以下格式写：

```text
事件名：
发生地点：
触发条件：
当前局势：
玩家已知信息：
原著记忆提示：
可选行动 A：
  检定：
  成功：
  失败：
可选行动 B：
  检定：
  成功：
  失败：
可选行动 C：
  检定：
  成功：
  失败：
方源介入条件：
后续影响：
```

### 5.4 示例事件：酒虫线索

事件名：酒肆中的异香

地点：古月山寨酒馆。

触发条件：

- 第 2 章后。
- 玩家拥有“酒虫相关原著记忆”。
- 夜晚或傍晚前往酒馆。

可选行动：

1. 调查酒肆老板
   - 检定：洞察 + 原著记忆。
   - 成功：获得酒虫线索。
   - 失败：只获得普通传闻。

2. 跟踪方源
   - 检定：潜行 + 匿息蛊。
   - 成功：发现方源也在调查酒虫。
   - 失败：方源警觉 +10。

3. 偷听酒客
   - 检定：听壁蛊 + 信息盗取。
   - 成功：获得隐藏购买窗口。
   - 失败：被酒客怀疑，名声 -1。

4. 直接设局
   - 检定：盗道等级 + 元石投入。
   - 成功：提前锁定酒虫归属。
   - 失败：方源获得半条线索，警觉 +15。

后续：

- 酒虫争夺事件开启。
- 方源行动优先级提高。

## 6. 数值设计

### 6.1 角色基础属性

推荐基础属性：

- 体魄：生命、负重、近战承受。
- 真元：技能和蛊虫消耗。
- 神魂：记忆偷取、概念盗取、精神反噬抗性。
- 敏捷：潜行、先手、逃跑。
- 洞察：识破阴谋、发现线索、看穿伪装。
- 魅力：交涉、缘线、欺骗。
- 狠辣：威胁、魔道行为、处决、承受恶名。
- 谨慎：降低暴露、降低追查、提升准备收益。

### 6.2 派生属性

- 生命 = 体魄 * 10 + 境界加成。
- 真元上限 = 境界基础值 * 资质倍率。
- 潜行 = 敏捷 + 盗道等级 + 蛊虫加成。
- 盗取 = 盗道等级 * 2 + 敏捷 + 洞察 + 工具加成。
- 识破 = 洞察 + 神魂 + 经验。
- 交涉 = 魅力 + 名声修正 + 利益筹码。
- 反噬抗性 = 神魂 + 境界 + 对应蛊虫。

### 6.3 资质设计

资质影响真元恢复和修炼速度。

推荐：

- 丁等：修炼倍率 0.7，真元恢复 0.8。
- 丙等：修炼倍率 1.0，真元恢复 1.0。
- 乙等：修炼倍率 1.3，真元恢复 1.2。
- 甲等：修炼倍率 1.6，真元恢复 1.5。
- 特殊体质：高成长，高风险。

玩家资质不必固定强。低资质可以通过盗道偷资源、偷修炼成果、偷机缘补足。

### 6.4 境界设计

第一版开放一转到三转。

每转分四阶：

- 初阶。
- 中阶。
- 高阶。
- 巅峰。

突破需要：

- 修炼进度达到 100。
- 对应资源。
- 安全环境。
- 可能需要蛊虫或事件。

突破失败后果：

- 真元损伤。
- 修炼进度下降。
- 短期虚弱。
- 被方源或敌人抓住窗口。

### 6.5 盗道等级

盗道等级分 5 阶：

1. 梁上手。
2. 暗线贼。
3. 窃名客。
4. 夺缘人。
5. 盗剧本者。

每阶有熟练度，但突破必须完成试炼。

示例：

- 梁上手突破暗线贼：成功偷取学堂排班或低级令牌，并处理掉追查。
- 暗线贼突破窃名客：成功盗取商队身份或古月内部权限。
- 窃名客突破夺缘人：成功夺取一条成年角色缘线或关键机缘归属。
- 夺缘人突破盗剧本者：成功偷取方源记忆片段或关键剧情身份。

### 6.6 检定公式

推荐使用简单可控公式：

```text
成功值 = 主属性 + 技能等级 * 2 + 蛊虫加成 + 情报加成 + 准备加成 - 目标防备 - 环境难度
```

结果分四档：

- 大成功：成功并获得额外收益。
- 成功：达成目标。
- 部分成功：达成目标但留下后患。
- 失败：未达成目标并触发后果。

建议阈值：

- 成功值 >= 15：大成功。
- 成功值 >= 8：成功。
- 成功值 >= 3：部分成功。
- 成功值 < 3：失败。

### 6.7 方源警觉数值

方源警觉范围 0-100。

增长示例：

- 普通异常表现：+2 到 +5。
- 偷取方源普通资源：+5。
- 截胡方源小机缘：+10。
- 截胡酒虫：+20。
- 偷听方源计划失败：+10。
- 偷方源念头成功：+15。
- 偷方源记忆片段：+25。
- 夺取方源关键缘线：+20 到 +30。
- 公开表现出原著级先知：+30。

降低方式：

- 伪装成巧合：-3 到 -8。
- 栽赃他人：-5 到 -10。
- 主动给方源错误判断：-5 到 -15。
- 与方源交易并让利：短期降低敌意，但不一定降低怀疑。

警觉不应轻易清零。玩家做过的大事会成为长期记录。

## 7. 盗道详细设计

### 7.1 盗道定位

盗道是主技能，但不是万能技能。

盗道能绕过规则，所以必须付出：

- 信息准备。
- 行动点。
- 蛊虫消耗。
- 暴露风险。
- 名声代价。
- 因果污染。
- 方源警觉。
- 后续追查。

### 7.2 偷盗目标分类

- 低价值：元石、小物品、普通消息。
- 中价值：令牌、蛊材、账册、低级蛊虫。
- 高价值：家族权限、商队身份、方源计划、关键蛊虫。
- 剧情价值：机缘归属、缘线、身份、记忆、时间窗口。

越高价值，越少靠随机数，越依赖前置任务和后果承担。

### 7.3 盗道负反馈池

每次偷盗根据风险抽取或指定后果：

- 留下气息。
- 被目击。
- 赃物有标记。
- 苦主设局。
- 方源察觉异常。
- NPC 信任下降。
- 阵营名声下降。
- 目标提高戒备。
- 获得假情报。
- 因果污点增加。
- 精神反噬。

### 7.4 反制设计

重要目标不应被无限偷。

目标可获得反制：

- 换岗。
- 封库。
- 设置假货。
- 布置追踪蛊。
- 安排诱饵。
- 公开悬赏。
- 私下谈判。
- 借刀杀人。

方源的反制优先级最高。

## 8. 缘线与成人关系设计

### 8.1 缘线不是好感条

缘线代表角色与事件、人物、势力之间的剧情连接。

每个重要成年女角色包含：

- 欲望。
- 戒备。
- 利益诉求。
- 秘密。
- 所属势力。
- 原本缘分归属。
- 可被盗取的剧情位置。
- 反制能力。

### 8.2 成人关系定位

成人关系是缘线推进后的结果之一，不是唯一奖励。

它可以带来：

- 情报。
- 庇护。
- 资源。
- 身份掩护。
- 背叛风险。
- 方源警觉。
- 新任务。

它不能成为主线必要条件。

### 8.3 缘线数值

推荐每个角色有以下数值：

- 信任：是否愿意合作。
- 戒备：是否怀疑玩家。
- 欲望：是否被玩家路线吸引。
- 利益绑定：是否与玩家有共同收益。
- 恐惧：是否害怕玩家。
- 反感：是否厌恶玩家。
- 缘线归属：无、原势力、方源、玩家、混乱。

成人事件触发不只看欲望，还要看：

- 成年确认。
- 信任或利益绑定。
- 戒备不过高。
- 当前环境安全。
- 玩家没有严重伤害她的核心利益。

### 8.4 三个样板角色

#### 家族执事线

身份：

- 古月山寨成年女执事。
- 掌握蛊室排班和低级资源调拨。

核心欲望：

- 安全。
- 地位。
- 摆脱上级压制。

可偷内容：

- 排班。
- 令牌。
- 信任。
- 上级把柄。
- 家族内部身份。

玩法：

- 低烈度高频互动。
- 适合早期偷名分和偷信任。

#### 商队女管事线

身份：

- 商队成年女管事。
- 掌握账册、货物、外部通行和离山机会。

核心欲望：

- 利润。
- 安全通行。
- 摆脱商队内斗。

可偷内容：

- 账册。
- 贵客身份。
- 交易渠道。
- 离山路线。
- 商队内部秘密。

玩法：

- 交易、身份、情报。
- 时间窗口短，商队离开后路线关闭。

#### 魔道原创线

身份：

- 隐藏在青茅山附近的成年魔道女蛊师。
- 与某个传承或狼潮秘密有关。

核心欲望：

- 复仇。
- 恢复实力。
- 夺取传承。
- 利用玩家。

可偷内容：

- 传承线索。
- 魔道身份。
- 高风险蛊虫。
- 成人关系。
- 背叛或共谋机会。

玩法：

- 高收益高风险。
- 双方都可能利用和背叛对方。

## 9. 方源系统详细设计

### 9.1 方源状态

方源应有独立状态：

- 境界。
- 资源。
- 蛊虫。
- 当前目标。
- 备用计划。
- 对玩家判断。
- 警觉值。
- 敌意值。
- 合作意愿。

警觉是怀疑程度，敌意是处理玩家的倾向。两者相关但不同。

### 9.2 方源每日行动

方源每天执行 1-2 个行动：

- 修炼。
- 压榨资源。
- 调查机缘。
- 跟踪目标。
- 设局。
- 交易。
- 清理风险。
- 转移路线。

玩家不在场时，方源也推进。

### 9.3 方源备用计划

当玩家截胡时，方源不会停滞。

例子：

- 酒虫被玩家拿走：方源转向压榨方正、偷其他资源、设局确认玩家异常。
- 商队身份被玩家偷走：方源改用交易、威胁或嫁祸方式进入商队线。
- 女角色缘线被玩家夺取：方源判断该线价值，选择放弃、利用、破坏或反夺。

## 10. 任务设计

### 10.1 任务原则

- 每个重要任务至少三个解法。
- 失败后有后续，不直接断线。
- 奖励不只给物品，也给情报、身份、缘线和时间优势。
- 方源可能竞争同一目标。

### 10.2 任务奖励类型

- 元石。
- 蛊虫。
- 蛊材。
- 情报。
- 身份权限。
- 缘线变化。
- 方源警觉变化。
- 时间优势。
- 名声变化。
- 新地点。

### 10.3 样板任务：偷取蛊室令牌

目标：

- 获得进入蛊室的机会。

解法：

1. 偷执事令牌。
2. 帮执事处理把柄，换取临时权限。
3. 伪造商队交易证明。
4. 跟踪方源，利用他制造的混乱进入。
5. 贿赂低级守卫。

失败后果：

- 被罚。
- 守卫加强。
- 执事戒备上升。
- 方源发现玩家也盯上蛊室。

## 15. 平衡目标

### 15.1 玩家成长速度

玩家应该可以比方源快，但不能无脑快。

合理目标：

- 普通路线：略慢于方源。
- 熟悉原著但少偷盗：接近方源。
- 高风险盗道路线：可阶段性超过方源。
- 过度暴露路线：短期超过方源，但被方源强力反制。

### 15.2 盗道收益

盗道应提供最高上限，但也提供最高不确定性。

每次高价值偷盗应让玩家思考：

- 值不值得？
- 会不会被方源发现？
- 赃物怎么处理？
- 会不会影响后续缘线？
- 是否有替代方案？

### 15.3 不不卡关

即使玩家：

- 没拿到酒虫。
- 得罪商队。
- 被方源识破。
- 错过某个女角色缘线。
- 狼潮中损失资源。

也应能进入下一阶段，只是开局条件变差。

## 17. 总结

本游戏第一版应优先做好三件事：

1. 剧本事件网络。
2. 盗道数值和负反馈。
3. 方源动态对抗。

画面、演出和大地图都可以后置。只要文字事件、数值成长和方源反制足够好，即使是纯文字界面也能玩出“我在和方源抢剧本”的爽感。
