# 《蛊真人：天外盗剧本》青茅山精简 MVP GDD

## 1. 产品范围

### 1.1 文档地位

本文解释青茅山精简 MVP 的整体体验、系统协作方式和内容边界。
`docs/superpowers/specs/2026-07-27-qing-mao-simplified-mvp-design.md`
是唯一产品规则源；本文与其冲突时，以总契约为准。

### 1.2 一句话体验

玩家作为天外之人在依据原著初始化的青茅山自由行动，通过前、后、左、右
的方向旅行寻找机缘，收集并搭配三转以下蛊虫，在 `8 x 6` 格子战场争夺
资源，同时依靠独立于蛊虫的偷盗技能取得物品。

### 1.3 类型与体验支柱

- 单人自由世界角色扮演。
- 有限地图中的方向探索与隐藏路线。
- 原著人物共同参与的机缘竞争。
- 低阶蛊虫收集、空窍构筑与简化炼制。
- `1v1` 为主、少量 `1v2` 的格子战斗。
- 地图内一次选择、一次判定的偷盗。
- 低压力成长；自由探索不会让主线过期。

### 1.4 活动玩家状态

MVP 只运行以下玩家状态：

- 生命。
- 真元。
- 元石。
- 境界。
- 修为进度。
- 力量、身法、感知、运气、意志、盗道熟练。
- 有名称、可见效果和明确持续期的 Buff/Debuff。

Buff/Debuff 的持续期只允许 `turn`、`scene`、`untilRest`。不创建跨章节的
隐藏压力状态。

### 1.5 第一版内容量

- 一条青茅山主线章节流程。
- 一张支持隐藏路线的有限野图。
- 最多五条可选机缘。
- 六只首批基础蛊与少量二转结果。
- 三转以下的玩家境界、空窍和蛊虫内容。
- 以 `1v1` 为主、少量 `1v2` 的战斗。
- 偷盗技能树前三层。
- 天骄名册、原著资料查询、普通存档与读档。

## 2. 核心循环

1. 查看当前任务步骤、下一步骤、附近角色和可查询资料。
2. 在据点地图移动、对话、训练、交易、偷盗或进入野外。
3. 在野外选择前、后、左、右，触发环境提示、捕捉小游戏、机缘或战斗。
4. 获得蛊虫、蛊材、装备、元石和修为进度。
5. 在非战斗状态调整空窍负载、装备、被动效果和杀招组合。
6. 完成当前剧情步骤，进入下一步骤；也可继续自由探索。

任何休息、绕路或错过可选机缘都不会使主线失败。章节中的日期只用于表达
先后顺序，不是倒计时。

## 3. 世界与原著

### 3.1 原著只负责初始化与查询

原著资料用于初始化：

- 人物与势力。
- 地点与公开路线。
- 血脉关系与亲朋关系。
- 主要修行方向与公开能力。
- 原著时间、物品和机缘记录。

原著资料查询支持人物、时间段、地点、蛊虫或物品、机缘五类过滤。结果只
显示摘要、原著位置、已知时间窗与关联对象，并标记为“原著资料”或“当前
世界已确认”。

查询不消耗资源，不生成强制任务，也不改变任何世界数值。

### 3.2 游戏开始后的世界

新游戏完成初始化后，世界只服从已经发生的游戏行为。人物可以死亡，机缘
可以被不同角色取得，势力和地点状态可以改变。系统不会强迫后续事件回到
原著结果。

### 3.3 方源与天骄名册

方源、方正、漠北、赤城、白凝冰等人都使用普通角色规则，并共同进入天骄
名册。名册只展示玩家已经知道的：

- 境界。
- 公开蛊虫。
- 最近公开战绩。
- 活跃、受伤、失踪、离山或死亡状态。

方源没有专属保护。合理的致命战斗可以让其提前死亡；后续内容使用通用
缺席替代，不复活、不强制修正世界。

## 4. 地图旅行

### 4.1 据点地图

玩家通过地图角色和场景入口直接交互，不通过地点清单传送。靠近角色后可
对话、交易或偷盗；靠近出口后可进入野外、商店、训练点或剧情场景。

### 4.2 方向旅行

进入野外后只提供四个方向：

- 前。
- 后。
- 左。
- 右。

绝对方位、初始朝向、相对方向换算、可逆历史栈、连续后退、时间收费、
普通目的地、隐藏地点、第 20 步保底、战斗返回、事件生命周期、确定性随机
与存档迁移，以
`docs/superpowers/specs/2026-07-26-wilderness-hidden-route-design.md`
为准。

远征历史、随机游标和事件记录只服务于当前方向旅行，不改变人物关系、
任务资格或额外世界压力。

### 4.3 途中内容

野外节点只承载可立即理解的内容：

- 环境提示。
- 低阶蛊虫追踪或捕捉小游戏。
- 危险探索。
- 普通战斗。
- 一次性机缘。
- 已发现地点的入口。

玩家不能点击未走到的地点直接抵达。已发现隐藏地点依照旅行契约决定是否
进入直达列表。

## 5. 机缘争夺

### 5.1 竞争原则

机缘是世界中的有限机会，不是专为方源或玩家保留的奖励。玩家、天骄和
其他角色可以先后接触同一机会，最终归属由当前世界中的行动决定。

### 5.2 结算方式

每个机缘只定义：

- 可出现的地点与时间段。
- 当前世界是否仍可用。
- 进入场景的明确触发。
- 对话、小游戏或战斗。
- 一次性即时结果。

机缘可以改变物品归属、角色存亡或地点事实，但不创建长期压力条。可选
机缘允许错过，不阻断主线，也不生成补救任务。

### 5.3 战斗取得边界

普通资源、蛊材和无主低阶蛊可以通过已创作的战斗后场景取得。有主蛊与
高阶蛊不进入普通战斗掉落表。高阶蛊未来只能把“战斗压制完成”作为复杂
获取条件之一，不能由胜利直接加入行囊。

## 6. 玩家成长

### 6.1 属性

| 属性 | MVP 用途 |
| --- | --- |
| 力量 | 物理攻击、部分炼体效果与负重 |
| 身法 | 移动与部分技能 |
| 感知 | 探索与目标观察 |
| 运气 | 偷盗与机缘结果 |
| 意志 | 控制、毒与精神类抗性 |
| 盗道熟练 | 偷盗成功率与技能树条件 |

所有属性为 `0..100` 整数。

### 6.2 修为进度

修为进度为 `0..100`。战斗是主要来源，其他来源只做补充：

| 来源 | 基础修为 |
| --- | ---: |
| 普通战斗胜利 | `+8` |
| 精英或首领战斗胜利 | `+12` |
| 战斗失败或撤退但存活 | `+2` |
| 首次完成危险探索 | `+4` |
| 完成一次训练 | `+3` |
| 选择夜间修炼 | `+2` |

同一战斗实例只结算一次；同一危险探索节点只给一次首次奖励；训练每个剧情
步骤最多结算一次。夜间修炼完全可选，跳过不影响主线和突破资格。

```text
raw = cultivationProgress + gain
cultivationProgress = min(100, raw)
storedOverflow = max(0, raw - 100)
```

`storedOverflow` 上限为 `20`，只等待本次突破，不作为货币。

### 6.3 突破

当 `cultivationProgress === 100` 时，突破按钮立即可用并确定成功：

1. 确认当前境界尚未达到三转上限。
2. 境界提升一级。
3. `cultivationProgress = storedOverflow`。
4. `storedOverflow = 0`。
5. 生命与真元恢复到最大值。
6. 写入唯一突破记录并保存。

突破不要求安全地点、特定时间、元石储备或额外剧情条件。达到三转后不能
进入四转。

### 6.4 行囊、装备与炼制

行囊保留普通道具、蛊材、蛊虫储备、武器、防具、法器和配方。取得物品后
只有普通持有状态，可以使用、出售、炼制或交付。

低阶配方只声明输入、数量、输出与即时成本。材料不足时按钮不可用；结算
成功后原子扣除输入并生成结果。新配方和新资源以后通过数据扩展，不增加
第二套炼制流程。

## 7. 空窍与蛊虫构筑

### 7.1 三种位置

- `aperture`：已炼化并装入空窍，主动技能和被动效果可用。
- `reserve`：已拥有但未装入，只能查看、喂养、炼制或换装。
- `material`：蛊材与配方材料，不是可催动蛊虫。

战斗开始后不能在 `aperture` 与 `reserve` 之间换装。

### 7.2 负载

| 境界 | 基础空窍容量 |
| --- | ---: |
| 一转 | `6` |
| 二转 | `10` |
| 三转 | `15` |

| 蛊虫阶位 | 负载 |
| --- | ---: |
| 一转 | `1` |
| 二转 | `2` |
| 三转 | `4` |

容量强化最多 `+3`。装入后的总负载若超过容量，整个换装操作失败，不部分
写入。重复蛊和升炼素材可以留在 `reserve`，不占出战负载。

### 7.3 单蛊能力

每只低阶蛊最多包含：

- 一个标志性主动技能。
- 至多一个被动效果或探索功能。
- 若干配方标签。

纯被动蛊可以没有主动技能。多段能力通过杀招形成，不给单只低阶蛊增加
多排按钮。

### 7.4 独立叠加规则

每只蛊必须独立声明一种 `stackRule`：

- `unique`：同 ID 只生效一只。
- `highestInstance`：同 ID 只取数值最高的一只。
- `additiveCapped`：允许相加，但必须声明硬上限。
- `recipeComponent`：不提供重复数值，只作为炼制或杀招组件。

不同蛊若修改同一效果组，该效果组也必须声明硬上限。未声明时默认
`unique`，不使用全局递减叠加公式。

### 7.5 杀招

杀招采用固定组合：

```text
1 个核心蛊 + 0..2 个必需辅助蛊 + 0..1 个兼容可选修饰
```

每个杀招必须声明核心蛊、必需辅助、可选修饰标签、真元消耗、格子射程、
目标模板、伤害或状态效果，以及是否占用动作。缺少核心或任一必需辅助时
不显示按钮；可选修饰只改变一个已声明参数。

## 8. `8 x 6` 格子战斗

### 8.1 战场

- 宽 `8` 格，高 `6` 格。
- 左上角 `(0, 0)`，右下角 `(7, 5)`。
- 默认 `1v1`，少量事件允许 `1v2`。
- 单位不能重叠。
- 移动只走上下左右。
- 距离统一使用曼哈顿距离。

### 8.2 玩家回合

1. 可移动一次，最多移动角色的 `move` 格，也可以不移动。
2. 执行一个动作：普通攻击、蛊虫主动技能、杀招、防御、使用道具或撤退。
3. 结算回合末 Buff/Debuff。
4. 敌方单位按固定顺序行动。

移动与动作不使用行动点池。战斗中断条件已删除；没有反应动作或待机反击。

### 8.3 射程

| 模板 | 规则 |
| --- | --- |
| `melee` | 曼哈顿距离 `1` |
| `rangeN` | 曼哈顿距离 `1..N` |
| `lineN` | 同行或同列、距离 `1..N`，被单位或障碍阻挡 |
| `radius1` | 目标格及其上下左右四格 |
| `self` | 仅自己 |

### 8.4 普通攻击与伤害

玩家始终拥有不依赖蛊虫的普通肉搏：

- 射程 `melee`。
- 基础伤害 `6 + floor(strength / 20)`。
- 真元消耗 `0`。

合法射程内的攻击确定命中：

```text
physicalDamage = max(1, basePower + floor(strength / 20) - targetPhysicalDefense)
guDamage = max(1, basePower + floor(perception / 25) - targetGuDefense)
```

技能若声明固定伤害，不再叠加属性。所有取整向下。

### 8.5 防御、撤退与敌方行动

- 防御占用动作；下一次受到的伤害减半，向下取整且最低为 `1`。
- 玩家位于边缘格时可撤退；撤退占用动作并立即结束战斗。
- 敌人优先使用当前射程内最高优先级技能，否则沿最短路径接近并攻击。
- 等长路径按上、左、右、下决定，保证读档结果一致。

胜利条件是所有敌人生命归零；失败条件是玩家生命归零。失败后回到入口，
恢复最大生命的 `30%`，保留物品、蛊虫、元石和修为，并获得持续到休息的
`debuff_wounded`。

## 9. 偷盗

### 9.1 定位与流程

偷盗独立于蛊虫，只读取运气、盗道熟练、双方境界与所选物品类别。

1. 靠近地图角色。
2. 选择“偷盗”。
3. 查看当前可偷清单。
4. 选择一件物品。
5. 进行一次判定并在地图交互层显示结果。

每名目标每次地图访问只能尝试一次；重新进入地图后恢复。该限制只属于
地图会话。

### 9.2 可偷内容

清单可包含普通道具、元石袋、蛊材、装备、外衣，以及成年角色的贴身物品。
未成年角色不得配置贴身物品条目。内容不得表现裸体或具体隐私物品。

### 9.3 成功率

境界序号：凡人 `0`、一转 `1`、二转 `2`、三转 `3`。

```text
rankGap = targetRankIndex - playerRankIndex
luckBonus = round((luck - 50) * 0.20)
masteryBonus = round((theftMastery - 50) * 0.35)
rankModifier =
  rankGap > 0 ? -10 * rankGap
              : 5 * min(-rankGap, 2)

itemPenalty:
  ordinary = 0
  equipment = 5
  outerwear = 8
  closeWorn = 10
  secured = 15

rawChance = 65 + luckBonus + masteryBonus + rankModifier - itemPenalty
finalChance = clamp(15, 95, rawChance)
```

所有运算使用整数。`round` 为四舍五入。

同境界、运气 `50`、盗道熟练 `50`、普通物品为 `65%`；任何合法目标最低
仍有 `15%`。

### 9.4 结果

成功时，所选条目立即从目标清单移除并作为普通物品加入玩家行囊，然后显示
结果并保存，事件结束。失败时不转移物品，只播放当前场景即时反应并保存。
场景可以明确声明失败立即进入普通战斗，但不创建跨场景状态。

成年角色的外衣或贴身物品被取走后，可立即切换
`portrait_outerwear_missing` 或 `portrait_close_worn_missing`，并附加一个
作者指定的 `embarrassed`、`angry` 或 `guarded` 标签。没有数值心情条；
地图 Q 版角色不换图。

完整技能树、确定性随机和原子结算见 `systems/theft-system-design.md`。

## 10. 任务流程

任务实例只保存：

- `status`：`inactive`、`active` 或 `completed`。
- `currentStepId`。
- `nextStepId`，完成后为空。

UI 只显示当前步骤、下一步骤和是否完成。每一步只有一个明确
`completionTrigger`：

1. 结算场景即时奖励。
2. 标记当前步骤完成。
3. 切换到下一步骤。
4. 更新新的下一步骤。
5. 保存。

不使用百分比、门槛列表或补救路线。到达最终步骤后直接显示离山路线选择。

## 11. 人物关系

关系是无数值图谱。每条边只有起点角色、终点角色、关系类别和可选说明。
关系类别包括血亲、配偶、远亲、朋友、师徒、竞争者和熟人。

关系图用于展示人物谱、帮助玩家理解人物，以及记录明确发生的身份变化。
它不提供检定加成，不阻挡任务，也不决定 NPC 是否相信玩家。

## 12. 对话

对话界面只包含：

- 场景背景。
- 当前角色立绘。
- 角色名与台词框。
- 最多三个简短选项。

选项只能进入下一对白、结束对话、触发一个即时事件增量，或进入地图、
战斗、商店。选项不显示行动点、概率公式、风险、锁形图标或二次确认。

## 13. UI

MVP 只保留以下面板：

1. 地图与常驻 HUD。
2. 对话。
3. 角色、属性与空窍。
4. 行囊、装备与炼制。
5. 当前任务。
6. 天骄名册。
7. 原著资料查询。
8. `8 x 6` 战斗。
9. 暂停、存档与读档。
10. 地图交互结果覆盖层。

常驻 HUD 只显示生命、真元、元石、境界、Buff/Debuff 摘要和当前任务
步骤。偷盗结果直接回到地图交互层，不打开独立判定页面。

## 14. 存档与读档

### 14.1 存档 Key

读取顺序：

1. `tianwai-daojuren-save-v3`。
2. `tianwai-daojuren-save-v2`。

迁移成功后写入 v3 key，不删除 v2 key。

### 14.2 活动分支

新存档只运行精简系统所需字段。旧存档迁移完整保留原 payload，再添加精简
活动分支和缺失默认值；保留的旧字段不会被活动系统读取、显示、更新或用于
分支判断。

### 14.3 确定性

存档必须保留：

- 野外 `expeditionSeed` 与 `randomCursor`。
- 偷盗 `theftSeed` 与 `theftRandomCursor`。
- 当前战斗状态与固定 AI 顺序。
- 已结算战斗、探索、炼制和突破的唯一记录。

读档不重复奖励、不重复结算，也不改变下一次随机结果。

## 15. MVP 内容

### 15.1 首批地点与人物

地点以古月山寨、学堂、商铺、客栈、野外入口、首张野图及其隐藏地点为
核心。人物至少覆盖玩家、方源、方正、漠北、赤城、白凝冰，以及主线所需
师长、商人和家族角色。

### 15.2 首批蛊虫

### 15.3 内容原则

- 每只低阶蛊只有一个清晰定位。

## 16. 不做范围

以下内容在本 MVP 已删除或明确不做：

- 已删除好感、信任、怀疑、警觉、杠杆与功绩数值。
- 已删除证据、可信度、时间线、矛盾和破案任务。
- 已删除赃物、原主人、非法占有和所有权追踪。
- 已删除失主线索、追查、热度、嫁祸与洗白。
- 已删除原轨同步率、偏移值、纠偏惩罚和回溯修正。
- 已删除方源专属观察、认知权重与剧情保护。
- 已删除任务百分比、补救路线和复杂状态矩阵。
- 已删除战斗中断条件、反应窗口和多队伍战术。
- 不做四转及以上蛊虫的完整获取。
- 不做序列 4 半神及以上偷盗能力。
- 不做复杂 NPC 日程模拟。
- 不做运行时代码改造。

## 17. 验收标准

- 玩家可以自由探索、休息和错过可选机缘而不使主线失败。
- 玩家可以不进行夜间修炼完成主线。
- 修为满后立即突破，三转封顶，无额外门槛或失败率。
- 野外通过前、后、左、右旅行，不点击未到达地点传送。
- 空窍按境界和蛊虫品阶计算负载，超载换装原子失败。
- 每只蛊最多一个标志主动和一个被动或探索功能。
- 每只蛊有独立 `stackRule`，杀招使用固定核心组合。
- 战斗固定使用 `8 x 6` 棋盘，每回合移动一次并执行一个动作。
- 玩家始终可以使用普通肉搏。
- 偷盗严格执行靠近、查看、选择一件、一次判定。
- 偷盗成功后物品立即进入普通行囊，保存后事件结束。
- 任意合法偷盗目标的成功率不低于 `15%`。
- 成年角色衣物表现只使用直接立绘与情绪标签，不使用心情数值。
- 任务只显示当前步骤、下一步骤和完成状态。
- 关系图不含数值，也不作为任务或对话门槛。
- 原著查询不消耗资源，不改变世界数值。
- 方源可以通过普通战斗死亡，后续流程仍能继续。
- 读档不重掷、不重复奖励、不重复结算。
