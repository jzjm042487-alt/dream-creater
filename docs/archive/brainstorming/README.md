# 历史设计可视稿

本目录保存原先只存在于本机 `.superpowers/brainstorm/` 中、换设备后会丢失的有效资料。
这些文件是设计讨论时使用的 HTML 片段和生成图片，不是当前游戏设计权威。

## 目录

- `wave0-core/`
  保存核心循环、地图结构和三种酒馆画风的比较稿。玩家最终选择的复古像素参考原图已经在
  `assets/concepts/retro-pixel-tavern-reference.png` 中，因此这里不重复保存；
  `tavern-modern-pixel.png` 与 `tavern-painted.png` 是未选但唯一的备选原图。
- `gu-system/`
  保存低阶蛊、捕获炼化、养护进阶、酒虫追踪和图鉴结构的可视化讨论稿。
- `combat-system/`
  保存空窍战斗、回合与射程、蛊虫联动和杀招结构的可视化讨论稿。

HTML 文件是视觉讨论容器的内容片段，单独打开时可能缺少宿主样式或选择脚本。
其文字决策若与正式规格冲突，以
`docs/superpowers/specs/2026-07-28-wave05-integration-contract.md` 及其权威层级为准。

未归档内容包括服务器日志、停止标记、等待页面和会话状态，因为这些不包含产品决策。
