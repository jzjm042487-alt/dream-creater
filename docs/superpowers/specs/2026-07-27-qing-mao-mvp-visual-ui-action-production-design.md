# 《蛊真人：天外盗剧本》青茅山 MVP 视觉、UI 与主角动作生产规格

版本：`0.1-review`

状态：依据最新完整剧本提取，待玩家确认后进入批量出图和页面实现。

## 1. 来源与决策

本规格读取并约束以下内容：

- 最新生产剧本目录：`docs/game-design/qing-mao-mvp-script/`
- 完整剧本：`docs/superpowers/specs/2026-07-26-qing-mao-mvp-complete-script-design.md`
- 总体 GDD：`docs/game-design/gu-zhen-ren-tianwai-daojuben-gdd.md`
- 成人角色状态规范：`docs/superpowers/specs/2026-07-26-character-state-portrait-ui-design.md`

生产剧本目录当前为 `1.0-draft`。截至本次读取，实际存在 `README.md` 和 `01-main-days-00-10.md`；后者已经把序章至第 10 日展开到逐镜头、逐动作、逐句对白。目录中声明的第 11-30 日、五条支线和重复对白文件尚未落盘。

内容优先级：

1. 序章至第 10 日的镜头、动作和演员以最新生产剧本为准。
2. 第 11-30 日、五条支线、数值和状态仍以 `1.0-review` 完整剧本为准。
3. 后续生产剧本文件落盘后，应再次执行相同的镜头和动作覆盖检查。

完整剧本包含 30 个关键日、5 条支线、6 幕、6 条离山路线和第 29 日回溯。其 18.2 节原本要求首轮实现复用现有资源，不新增整套美术；玩家最新要求明确扩大制作范围，因此本规格取代该项资产限制，但不改变剧情、状态和玩法边界。

已锁定表现规则：

- 玩家固定男性形象，不捏脸。
- 玩家有固定半身立绘和可动作的 Q 版地图角色。
- 玩家立绘至少有常态、警觉、轻伤、重伤四态。
- 主角 Q 版必须有奔跑动作，并覆盖探索、偷盗、炼化和战斗的核心动作。
- 普通 NPC 的 Q 版为单张静态正常形象，不跟随服装、情绪或关系状态切图。
- NPC 的戒备、受伤和剧情变化由半身立绘、特效层、对白和 UI 表达。
- 已确认的成年女性三态立绘系统继续独立运行，不把服装失窃状态带入地图 Q 版。

## 4. UI 与状态面板

### 4.1 常驻 HUD

常驻 HUD 只显示需要高频决策的数据：

| 区域 | 字段 | 视觉规则 |
| --- | --- | --- |
| 左上 | 玩家小头像、生命、伤势 | 轻伤黄、重伤赤、濒死闪烁；不靠文字单独表达 |
| 上中 | 第几幕、第几关键日、当前阶段、地点 | 幕间跳转必须明确显示世界内时间跨度 |
| 上中下层 | 行动点 0-3 | 三枚固定宽度行动印记，消耗后不引发布局移动 |
| 右上 | 真元/容量、修为、小境界、元石 | 真元不足时相关操作同步置灰 |
| 右侧风险 | 疲惫、公开暴露、原文同步率 | 达到阈值才强化，不把方源警觉混入这里 |
| 左侧任务 | 当前主线、追踪支线、截止日 | 幕间前高亮即将过期任务 |
| 场景底部 | 交互目标、AP 成本、风险、快捷键 | 选择前显示真实缺失条件 |

### 4.3 原文查询外挂补全

完整剧本只定义 `generator.source_sync` 和 `generator.query_depth`，尚未完整实现 GDD 已确认的“未来三年”界面。本规格补回以下结构：

```text
时间：今年 / 未来一年 / 未来三年 / 自定义章节
筛选：人物 / 地点 / 蛊虫与物品 / 势力 / 机缘类型
结果：原归属者、时间窗、地点、前置线索、原结果、截胡可行性、
      截胡方法、预计收益、方源警觉、势力追查、同步率影响
证据标签：原作记录 / 已验证事实 / 当前推演 / 已因偏移失效
```

青茅山 MVP 中，30 日内节点可以转为可追踪任务。超出青茅山范围的未来一年或三年结果只作为只读索引和下一篇章伏笔，不开放不可到达地图，也不直接发放任务。

### 5.4 NPC 静态 Q 版演出

生产剧本中的 NPC 有推门、转身、让路、递物、拦路和离场等可见动作，但 NPC Q 版仍不制作逐帧状态：

- 地图移动使用静态 Q 图沿路径平移、水平翻转和最多 2 px 的待机起伏。
- 转身、让路和停步使用 120-200 ms 的位移、缩放或角度缓动。
- 递物、按住账册、握手腕等近景动作切入半身立绘和道具层，不要求地图 Q 图演出手指动作。
- 受伤、戒备、兴趣和杀意不替换 Q 图，由半身立绘、边框、冰雾、木纹或其他覆盖层表达。
- 同一 NPC 的静态 Q 图始终保持完整正常着装。

### 9.2 奔跑动作

奔跑是地图默认移动动作，不额外制作普通行走。潜行使用独立慢速动作。

| 参数 | 正常 | 重伤 |
| --- | ---: | ---: |
| 帧数 | 8 | 8 |
| 帧率 | 12 fps | 9 fps |
| 当前原型速度 | 190 px/s | 130 px/s |
| 身体前倾 | 8-12° | 4-8°，躯干更僵硬 |
| 头部上下幅度 | 最多 2 px | 最多 1 px |
| 脚底接触帧 | 1、4、5、8 | 1、5，左右不均匀 |

八帧内容：

1. 支撑脚落地，身体压低，腰带尾端落后。
2. 前脚推离，后脚收起，肩部开始反摆。
3. 第一次腾空，衣摆和发尾达到最大延迟。
4. 对侧脚落地，头部回到基线。
5. 第二次压缩，左右动作反转。
6. 第二次推离，工具袋产生一帧反向摆动。
7. 第二次腾空，暗红腰带形成清晰速度轮廓。
8. 回落并接回第 1 帧。

验收要求：

- 缩到 80-96 px 显示高度时仍能看清双脚交替。
- 发束、腰带和工具袋有次级运动，但不能改变碰撞盒。
- 正面与背面奔跑不出现侧滑。
- 左右翻转后工具袋允许换侧，任务物不得依赖其屏幕侧别。
- 松开输入后 100 ms 内进入待机，不在落地帧产生角色位置跳动。

### 9.7 动作与状态边界

- 服装失窃、NPC 情绪和关系变化不生成主角 Q 版动作。
- 警觉主要由半身立绘和 UI 表达，不单独制作警觉跑步。
- 轻伤可以复用正常奔跑并增加短促受击反馈；重伤必须使用独立不对称奔跑。
- 战斗中的冰冻、木魅和血道效果使用覆盖层，不把每种 Buff 烘焙成一套主角帧。
- 携带货箱和拖拽青书改变动作时，使用独立剧情序列，不改变基础角色服装。
