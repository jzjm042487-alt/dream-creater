# 《蛊真人：天外盗剧本》青茅山精简 MVP 视觉、UI 与动作生产规格

版本：`1.0-simplified`

状态：Wave B / Task 4 实施契约。

## 1. 文档地位
本规格只定义青茅山精简 MVP 的活动界面、视觉反馈与动作接入。唯一规则源为：

- `docs/superpowers/specs/2026-07-27-qing-mao-simplified-mvp-design.md`

实施计划为：

- `docs/superpowers/plans/2026-07-27-simplified-qing-mao-mvp.md`

成年角色三态细节由 `2026-07-26-character-state-portrait-ui-design.md` 补充。发生冲突时，先服从唯一规则源，再服从本规格。

本轮边界：

- 继续复用仓库中的场景、角色、蛊虫、道具、图标与动作资产。
- 不创建、重绘、重命名或移动图片。
- 不修改运行时代码。
- 缺少专用图片时使用既有中性占位资源，不扩大美术生产范围。

## 2. 表现目标
第一屏就是可操作地图。玩家查看必要资源，靠近角色或物体，进行对话、偷盗、训练、交易、方向旅行与战斗，再回到地图整理所得和推进当前步骤。

界面只回答：

1. 玩家现在在哪里。
2. 玩家现在能做什么。
3. 玩家刚才获得、消耗或改变了什么。
4. 当前剧情步骤是什么。

界面不承担世界压力或复杂社会状态模拟。

### 2.1 明确删除
以下内容只作为删除记录，不得进入活动导航、HUD、弹窗或数据绑定：

- 独立判定页 `UI12` 已删除。
- 证据页 `UI14` 及其可信度、时间线、矛盾展示已删除。
- 回溯修正页 `UI16` 已删除。
- 警觉值、关系数值、行动点、任务百分比和补救路线不显示。
- 疲惫、身份暴露、旧债、血污、同步率和偏移值不显示。
- 赃物、原主人、所有权、失主线索和后续追查不显示。
- 战斗反应窗口、待机反击和中断提示不制作。

旧资源可以留在仓库中，但活动 MVP 不加载旧界面结构。

## 4. 全局导航与布局
地图状态允许直接打开角色空窍、行囊炼制、当前任务、天骄名册、原著查询和暂停页。

对话与战斗期间：

- 不允许打开会修改空窍、装备或炼制结果的功能页。
- 允许打开暂停页。
- 允许查看只读角色摘要、技能说明和状态说明。
- 关闭暂停页后回到原场景与原焦点。

视觉层级从后到前为：

1. 场景背景或地图。
2. 地图角色、障碍和交互物。
3. 常驻 HUD。
4. 当前交互层或全屏功能层。
5. 工具说明与系统错误。
6. 暂停层。

同一时刻只有一个主要功能层获取输入焦点。

控件规则：

- 移动、攻击、背包、保存等命令优先使用既有图标配短标签。
- 前、后、左、右同时显示方向图标与文字。
- 生命和真元使用稳定宽度条，数值变化不推动相邻元素。
- Buff/Debuff 使用图标、名称和剩余持续期。
- 禁用按钮显示一个简短原因，不展示门槛清单。
- 关闭、返回、暂停和保存使用熟悉图标。

## 5. 地图与常驻 HUD
地图是默认活动界面，必须表现玩家位置与朝向、碰撞边界、附近角色和交互物、可进入的建筑与野外入口、已发现地点名，以及野外的前后左右选择。

地图不提供点击地点传送。玩家移动到交互距离内才显示操作。

地图 Q 版角色只使用正常着装的固定资源，不读取成人立绘或情绪标签。

### 5.1 HUD 唯一字段
| 区域 | 字段 | 表现 |
| --- | --- | --- |
| 左上 | 生命 | 当前值、最大值、稳定宽度条 |
| 左上 | 真元 | 当前值、最大值、稳定宽度条 |
| 右上 | 元石 | 图标和整数 |
| 右上 | 境界 | 当前转数与小境界短名 |
| 状态区 | Buff/Debuff 摘要 | 最多三个图标，超出显示数量 |
| 任务区 | 当前任务步骤 | 一行短文本，可打开任务页 |

HUD 不显示修为进度、下一任务步骤或任务完成状态。修为进度在角色空窍页显示，任务详情在任务页显示。

状态摘要展开后显示名称、实际效果、`turns`、`scene` 或 `untilRest`
持续期，以及 `turns` 状态的剩余回合。

### 5.2 地图交互
靠近对象时只显示当前可执行命令，例如对话、偷盗、交易、训练、调查或进入。提示不显示行动消耗、社会影响或隐藏后果。

进入野外后，方向控件固定在同一位置。连续后退不得让按钮重新排布。

## 6. 对话
对话界面只包含：

1. 场景背景。
2. 当前成年角色半身立绘，或无立绘角色的既有头像。
3. 角色名与台词框。
4. 最多三个简短选项。

布局规则：

- 背景全屏铺设并保持主要环境信息可见。
- 立绘位于台词框之后，不放入装饰卡片。
- 台词框位于底部安全区，不能遮住角色面部。
- 选项使用固定宽度列表，长文本换行。
- 1366 x 768 下三个选项同时可见，无需滚动。

选项只允许进入下一对白、结束对话、触发一个即时增量，或进入地图、商店与战斗。

选项不得显示 AP、成功概率、风险公式、锁形图标、不可选剧情答案或二次确认。没有选项时，继续键进入下一句。

对话节点直接读取一个 `portraitTag` 和零个或一个 `emotionTag`。立绘切换使用 120-180 ms 淡入，不播放数值条动画。

## 7. 角色、属性与空窍
该页使用玩家状态、空窍构筑和蛊虫说明三个页签。

### 7.1 玩家状态
显示：

- 生命、真元和元石。
- 境界与修为进度 `0..100`。
- 力量、身法、感知、运气、意志和盗道熟练。
- 当前 Buff 与 Debuff。

修为进度到 `100` 时直接显示可用的突破按钮，不展示地点、元石、时间或任务前置项。达到三转时显示“当前版本上限”，不显示四转入口。

### 7.2 空窍构筑
必须同时显示当前容量、已用负载、剩余负载，以及 `aperture`、`reserve` 和 `material` 三类内容。

换装前显示蛊虫负载。超过容量时整次操作失败并保持原状态。战斗开始后换装控件不可用，只显示“战斗中不可换装”。

### 7.3 蛊虫条目
每只蛊只展示名称、阶位、图标、负载、一个主动技能、一个被动或探索效果、真元消耗、射程模板、`stackRule` 和配方标签。没有主动技能时不显示空按钮。

杀招显示核心蛊、必需辅助蛊、一个可选修饰位和最终效果。缺少核心或必需辅助蛊时不显示可用按钮。

## 8. 行囊、装备与炼制
该页使用行囊、装备和炼制三个页签。

行囊分类只包含普通道具、蛊材、蛊虫储备、武器、防具、法器和配方。条目显示名称、数量、简短用途与可用操作，所有所得物品使用同一种普通持有表现。

装备页显示当前武器、防具和法器槽。替换时只预览直接数值与技能变化，一次点击确认。

炼制条目显示输入材料与数量、当前持有量、输出物和炼制按钮。材料不足时按钮禁用并高亮缺少项。完成后使用 `UI18` 显示消耗与产出。

## 9. 当前任务
任务页只显示一个当前主线实例，必须同时展示：

| 字段 | 规则 |
| --- | --- |
| 当前步骤 | 玩家此刻应完成的一个明确动作 |
| 下一步骤 | 当前步骤完成后出现的下一动作 |
| 完成状态 | `未开始`、`进行中` 或 `已完成` |

任务页不显示数值进度比例、截止倒计时、门槛列表或补救路线。“第 0 日”到“第 30 日”只作为章节序号，不使用倒计时视觉。

任务完成时保留最后完成内容，下一步骤显示“无”，完成状态显示“已完成”，HUD 显示“本章步骤已完成”。可选机缘不进入主线完成条件。

## 10. 天骄名册
`UI10` 的唯一含义是天骄名册。首批至少包含方源、方正、古月漠北、古月赤城和白凝冰。

每个条目只显示玩家已知的姓名与既有头像、境界、公开蛊虫、最近公开战绩，以及活跃、受伤、失踪、离山或死亡状态。

未知字段显示“未知”，不推演隐藏意图。方源与其他角色使用相同模板、字段和死亡表现。角色死亡后条目保留并标记死亡，不显示复活或世界纠正提示。

## 11. 原著资料查询
查询页提供人物、时间段、地点、蛊虫或物品、机缘五类筛选。

每条结果只显示：

- 资料摘要。
- 原著位置。
- 已知时间窗。
- 关联对象。
- “原著资料”或“当前世界已确认”标签。

查询不消耗生命、真元、元石或其他资源，不自动追踪任务，不保证机缘仍存在，也不改变世界状态。结果只用摘要和定位信息，不复制长段原文。

## 12. `8 x 6` 格子战斗
### 12.1 战场
- 棋盘固定宽 `8` 格、高 `6` 格。
- 左上角为 `(0, 0)`，右下角为 `(7, 5)`。
- 默认 `1v1`，少量事件允许 `1v2`。
- 单位不能重叠。
- 移动只走上下左右。
- 射程与路径使用曼哈顿距离。

棋盘必须完整出现在首屏，不通过滚动查看边缘格。

### 12.2 战斗 HUD
战斗界面显示玩家与敌人生命、玩家真元、当前回合单位、当前 Buff/Debuff、移动范围、技能合法目标格，以及普通攻击、蛊虫技能、杀招、防御、道具和撤退。

技能按钮显示名称、真元消耗和射程模板。合法目标使用稳定色块描边，障碍、占用格和不可达格使用不同纹理。

### 12.3 回合
每回合固定流程：

1. 移动一次，也可以跳过。
2. 执行一个动作。
3. 结算回合末状态。
4. 敌方按固定顺序行动。

界面不显示行动点池。移动确认前可以取消路径，动作结算后不能撤销本回合。战斗没有反应按钮、抢先按钮或插入式操作。

### 12.4 射程
| 模板 | 棋盘高亮 |
| --- | --- |
| `melee` | 曼哈顿距离 `1` |
| `rangeN` | 曼哈顿距离 `1..N` |
| `lineN` | 同行或同列 `1..N`，遇阻挡停止 |
| `radius1` | 目标格与上下左右四格 |
| `self` | 玩家所在格 |

进入合法射程即确定命中，不显示命中随机数。

### 12.5 结束
胜利、失败或撤退后，战斗内结算层显示结果、生命与真元变化、修为进度、普通物品与资源，以及新增或清除的 Buff/Debuff。

失败显示返回战斗入口、生命恢复到上限 `30%` 和 `debuff_wounded`。撤退只在玩家位于边缘格时启用。确认结算后返回对应地图节点。

## 13. 暂停、存档与读档
暂停页只提供继续、保存、读取、设置和返回标题。存档条目显示地点、境界、当前任务步骤和保存时间。

读取使用一次明确确认以避免丢失未保存进度，该确认不属于剧情选择。保存与读取不显示世界修正、偏移评价或惩罚。

读取后恢复地图、对话或战斗状态，以及确定性随机游标。

## 14. 地图交互结果覆盖层
`UI18` 始终覆盖在地图上，不跳转到独立结果页。通用结构只有操作名称、成功或失败、取得或消耗项目，以及一个继续按钮。训练、采集、危险探索和野外小游戏复用该结构。

### 14.1 偷盗选择
靠近角色并选择偷盗后，覆盖层显示可偷清单。每个条目只显示物品名称、类别、一句用途和本次最终成功率。

界面不展开运气、盗道熟练、境界差和物品惩罚的逐项公式。选择物品后立即判定，不再弹出确认框。

### 14.2 成功
成功覆盖层显示：

- “偷盗成功”。
- 获得物品及其普通行囊位置。
- 可选的角色立绘变化。
- 可选的当前场景或下一场战斗 Debuff。

角色表现直接使用 `portrait_normal`、`portrait_outerwear_missing` 或 `portrait_close_worn_missing`。保存后事件立即结束，不显示失物归属、嫌疑或事后处理入口。

### 14.3 失败
失败覆盖层显示“偷盗失败”、物品未取得，以及本次地图访问内该角色不可再次尝试。关闭后直接返回地图。

只有内容明确声明失败后开战时，才无缝进入普通格子战斗。失败不产生跨场景隐藏状态。

## 15. 资产复用
### 15.1 角色
以下既有成年角色继续复用三态资源：

- 家族成年女执事。
- 商队成年女管事。
- 成年魔道女蛊师。
- 成年药堂女医师。
- 成年酒馆老板娘。

方源、方正、漠北、赤城、白凝冰、学堂家老、古月青书、贾金生和贾富继续复用既有头像、半身立绘和静态 Q 版。

受伤或死亡优先使用既有差分、色调层和短文本。缺少差分时使用既有正常立绘加通用状态图标，不发起图片生产。

### 15.2 场景
优先复用旁支竹楼、山寨街区、希望花海、学堂、酒肆、青矛竹林、野外山路、商队集市、药堂、山缝石室、狼潮和离山路线。

昼夜、雨、冬季、商队、狼潮、冰场和火灾继续使用既有效果层。旧的逆向复原效果不在活动 MVP 调用，资源文件保持不变。

### 15.3 蛊虫与物品
月光蛊、酒虫、白豕蛊、玉皮蛊、隐石蛊、九叶生机草及现有装备、元石和蛊材图标继续复用。缺少卡面时使用现有物品图标，不新增概念图。

## 16. 主角 Q 版动作
### 16.1 技术基线
| 项目 | 规格 |
| --- | --- |
| 运行时单帧 | `128 x 128` 透明 PNG |
| 头身比 | 约 `1:2.5` |
| 锚点 | 脚底中心 `(0.5, 0.88)` |
| 地面碰撞盒 | 约 `24 x 18` |
| 方向 | 正、背、侧，另一侧水平翻转 |
| 缩放 | 最近邻 |
| 位移 | 由地图或棋盘逻辑驱动 |

地图 NPC 不进入玩家动作状态机。

### 16.2 地图动作
| 动作 ID | 用途 | 缺失资源降级 |
| --- | --- | --- |
| `idle` | 地图待机 | 固定首帧 |
| `run` | 常规移动 | `idle` 平移 |
| `interact` | 对话、开门、训练 | `idle` 加交互图标 |
| `inspect` | 查看环境、配方和蛊虫 | `interact` |
| `steal` | 地图偷盗 | `interact` 加手部闪光 |
| `pickup` | 采集、捕捉与领取 | `interact` |
| `refine` | 炼化与炼制 | `interact` 加真元环 |
| `use_item` | 药物或道具 | `interact` |

### 16.3 战斗动作
| 动作 ID | 用途 | 关键事件 |
| --- | --- | --- |
| `battle_idle` | 等待选择 | 无 |
| `grid_move` | 格子移动 | `footstep_frames` |
| `melee` | 普通肉搏 | `hit_frame` |
| `use_gu` | 蛊虫技能 | `gu_effect_frame` |
| `killer_move` | 杀招 | `gu_effect_frame` |
| `defend` | 防御 | `guard_apply_frame` |
| `battle_item` | 使用道具 | `item_consume_frame` |
| `battle_hit` | 受击 | 伤害数字独立显示 |
| `down` | 战败 | 停在最后一帧 |
| `retreat` | 边缘格撤退 | 复用 `run` |

动作只负责表现，伤害、命中、资源消耗和物品转移由规则结算。

单次事件键为：

```text
prop_attach_frame
prop_release_frame
inventory_transfer_frame
hit_frame
gu_effect_frame
guard_apply_frame
item_consume_frame
animation_complete_event
```

物品只在 `inventory_transfer_frame` 取得一次。动画重播不得重复获得物品、修为或资源。

## 17. 响应式与可读性
目标分辨率为 `1366 x 768`、`1920 x 1080` 和 `2560 x 1440`。

必须满足：

- 棋盘、HUD 和战斗按钮在首屏完整可见。
- 对话立绘、台词和三个选项不重叠。
- 最长任务步骤可以换行，不覆盖资源栏。
- 图标提供悬停或键盘焦点说明。
- 颜色不是唯一状态信号，同时使用图标、文字或纹理。
- 键盘焦点顺序与画面阅读顺序一致。
- 动态内容不改变按钮和棋盘尺寸。

## 18. 实施与验收
### 18.1 实施批次
| 批次 | 范围 | 验收出口 |
| --- | --- | --- |
| `U0` | 地图、HUD、对话和结果覆盖层 | 可完成靠近、对话与一次偷盗 |
| `U1` | 角色空窍、行囊炼制与任务 | 可完成构筑、配方和步骤推进 |
| `U2` | 天骄名册与原著查询 | 可查看竞争者和原著资料 |
| `U3` | `8 x 6` 战斗与结算 | 可完成移动、行动、胜败与撤退 |
| `U4` | 暂停、存读档与分辨率检查 | 可保存并恢复当前场景 |

每批只接入已有图片。

### 18.2 验收清单
- 活动导航只有注册表中的十项。
- `UI10` 是天骄名册，方源使用通用条目。
- HUD 只有生命、真元、元石、境界、状态摘要和当前步骤。
- 任务页同时显示当前步骤、下一步骤与完成状态。
- 对话最多三个选项，没有 AP、公式、锁定选项或剧情二次确认。
- 成人角色三态使用既有资源，地图 Q 版不切图。
- 棋盘固定 `8 x 6`，每回合最多移动一次并执行一个动作。
- 合法射程内确定命中，没有反应窗口或插入式操作。
- 偷盗选择与结果都在地图覆盖层。
- 偷盗成功后物品进入普通行囊并立即结束事件。
- 读档恢复当前面板、战斗状态和随机游标。
- 动画重播不重复发放奖励。
