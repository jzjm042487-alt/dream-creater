# 后山隐形路径探索设计

## 1. 设计结论

青茅山后山不再让玩家控制角色在一张缺少交互的地图上长距离行走。后山改为参考《金庸群侠传》迷宫体验的“隐形路径图”：

- 玩家只看见当前环境和“向前、向后、向左、向右”四个方向选择。
- 后台使用固定的有向路径图结算选择，但不向玩家展示完整拓扑。
- 奇遇、功法、野怪、线索和隐藏地点挂在路径节点或路径边上。
- 普通目的地既可以通过正确路径提前抵达，也有最多二十步的防迷路保底。
- 隐藏地点不进入保底列表，只能通过寻路、线索或能力发现。
- 隐藏地点首次发现后永久记录路线，后续允许直接抵达。
- 山寨、客栈、学堂和住处等任务密集场景继续使用自由行走。
- 战斗继续使用现有的八乘六格回合制战场。

目标不是增加点击次数，而是让每一次方向选择都有机会产生信息、风险或发现。

## 2. 目标与非目标

### 2.1 目标

1. 删除后山中“为了赶路而赶路”的无意义移动。
2. 保留迷路、试路和偶遇奇缘的武侠探索感。
3. 让读过原著的记忆、环境线索和盗道能力能够帮助寻路。
4. 普通目的地永不造成永久卡关。
5. 隐藏地点可以偶然撞见，也可以根据线索稳定推理。
6. 已经解决过的路线不要求玩家反复背诵。

### 2.2 非目标

- 不制作可旋转或可缩放的迷宫小地图。
- 不把路径选择做成纯随机抽奖。
- 不让每一步都播放长动画或弹出确认框。
- 不让随机野怪无限刷新并成为刷资源漏洞。
- 不取消山寨和室内任务场景的自由移动。

## 3. 场景分层

游戏地图分为三类：

| 类型 | 操作方式 | 示例 |
| --- | --- | --- |
| 野外路径场景 | 四方向隐形寻路 | 青茅山后山、竹林野路、山谷岔道 |
| 任务密集场景 | 自由移动并靠近互动 | 古月山寨、醉仙楼、学堂、弟子住处 |
| 战斗场景 | 八乘六格回合制移动 | 山豕战、截击方源 |

玩家从山寨出口进入后山时切换到野外路径场景。抵达山寨、猎场或其他目的地后，再切换到对应的任务场景或战斗场景。

## 4. 隐形路径图

### 4.1 数据模型

每张野图由固定节点与有向边组成。最低数据结构如下：

```text
WildernessMap
  id
  entryNodeByOrigin
  ordinaryDestinations
  hiddenDestinations
  nodes

RouteNode
  id
  description
  exits: forward | back | left | right -> nodeId
  eventSlots
  discoveryConditions
  destinationId
```

路径图在同一存档中保持稳定。重新进入、保存读取或刷新页面都不会重排方向，因此玩家获得的环境知识是真实有效的。

### 4.2 方向语义

- “前、左、右”按照玩家当前朝向解释。
- 选择一条边后，玩家朝向更新为该边的方向。
- “后”优先返回刚刚经过的上一节点。
- 如果剧情造成塌方、传送或追逐，可以明确标记为特殊节点并改变返回规则。
- 不允许“后退”随机传送到无关节点。

路径循环可以存在，但必须通过环境文字让玩家察觉，例如重复出现的断碑、同一棵雷击木或越来越近的水声。

## 5. 玩家反馈

每次选择方向后立即更新三类信息：

1. **环境描述**：一至两句短文本，例如“左侧风中带着淡淡酒香”。
2. **局势变化**：脚印、兽吼、雾气、追兵距离或方源留下的痕迹。
3. **可选方向**：只显示当前真实存在的方向；不显示死路按钮。

反馈必须允许玩家形成记忆或推理。没有环境差异的连续节点应当合并，避免将一次有意义的选择拆成多次点击。

方向按钮同时支持：

- 屏幕按钮。
- 键盘方向键。
- `WASD`。
- `Esc` 或界面命令用于打开已知出口，不等同于直接脱离。

## 6. 时间与防迷路

### 6.1 时间成本

- 进入一次野外探索至少消耗一个时段。
- 每完成四次有效路径选择，累计消耗一个时段。
- 计算公式为 `max(1, ceil(有效选择次数 / 4))`。
- 战斗、采集、修炼和特殊奇遇使用各自已有的额外时间成本。
- 时间在选择完成后按现有“玩家结果优先、再推进世界日程”的规则结算。

“有效选择”指实际沿边移动。打开界面、查看环境描述或选择不可用按钮不计数。

### 6.2 两种计数器

系统必须分开保存：

- `wanderCount`：本次探索的累计有效选择，用于二十步防迷路。只有抵达目的地或主动结束本次探索才清零。
- `routeSequence`：最近的方向序列，用于匹配隐藏路线。触发战斗、奇遇、传送或发现地点后可以清零。

随机战斗不得清除 `wanderCount`，否则玩家可能在第十九步遭遇敌人后重新迷路。

### 6.3 二十步保底

当 `wanderCount` 达到二十且玩家尚未抵达目的地时：

1. 当前节点出现“辨明方向”命令。
2. 命令列出该野图全部已开放的普通目的地。
3. 玩家自行选择其中一个目的地并立即抵达。
4. 不再收取额外路径时间。
5. 隐藏地点、未满足剧情条件的地点和移动秘境永不出现在该列表。

如果玩家在二十步前走到普通出口，则立即正常抵达，不必继续选择。

## 7. 普通与隐藏目的地

### 7.1 普通目的地

普通目的地是剧情推进所需、不会永久错过的地点，例如：

- 古月山寨。
- 竹林猎场。
- 后续开放的村镇或山道出口。

它们可以由正确路线提前抵达，也全部受到二十步保底保护。

### 7.2 隐藏目的地

隐藏地点满足至少一种发现方式：

1. 输入正确方向序列。
2. 到达特定路径节点并满足线索条件。
3. 使用盗道、侦察、追踪或原著记忆能力识破隐藏边。
4. 在特定日期、时段或天气进入节点。

没有线索时仍可以偶然走入部分隐藏地点，但核心奖励不得只依赖不可控概率。

首次发现后：

- 写入 `discoveredLocations`。
- 记录入口野图和路线知识。
- 后续进入该野图时，隐藏地点加入“已知目的地”，允许直接抵达。
- 首次发现奖励、宝箱和功法不会刷新。
- 会移动或周期关闭的秘境可以显式标记为例外，需要重新寻找。

## 8. 路径事件

### 8.1 固定事件

固定事件绑定到具体节点或边，并由条件决定是否触发：

- 原著奇遇。
- 功法或蛊虫线索。
- 一次性宝物。
- 方源行动痕迹。
- 可盗取的营地、尸体或行囊。

固定事件完成后记录唯一标记，不重复发放核心奖励。

### 8.2 随机事件

野怪、天气和普通采集可以使用带种子的随机池：

- 每次进入野图生成并保存一个 `expeditionSeed`。
- 保存读取不会重新抽取本次探索结果。
- 同一次探索中，同一随机战斗最多触发一次。
- 普通奖励设置每日冷却或递减收益。
- 接近二十步保底时降低随机战斗概率，确保防迷路体验不会被反复打断。

### 8.3 条件优先级

同一步同时满足多个事件时，按以下顺序处理：

1. 抵达目的地。
2. 发现隐藏地点。
3. 唯一奇遇或关键剧情。
4. 强制追逐或伏击。
5. 随机战斗。
6. 普通环境反馈。

一次选择最多进入一个阻断式事件，其余非阻断信息进入日志，避免连续弹窗。

## 9. 界面设计

后山继续使用已经生成的青茅山像素场景，但移除可自由移动的小人和远距离交互点。

主要界面结构：

- 中央：当前路径节点的环境画面或场景局部。
- 底部：前、后、左、右四个稳定尺寸的方向按钮。
- 左下：最近三条环境反馈。
- 右侧：当前时间、生命、真元、方源警觉和正在追踪的线索。
- 顶部：“已知出口”命令；二十步后变为醒目的“辨明方向”。
- 隐藏信息：不显示路径拓扑、节点编号、正确答案或隐藏地点占位符。

路径切换只使用约 `250-400ms` 的画面平移、淡入或路线声效，不播放不可跳过的长动画。

## 10. 状态与存档

存档新增：

```text
wilderness
  mapId
  currentNodeId
  previousNodeId
  facing
  wanderCount
  routeSequence
  expeditionSeed
  triggeredEventIds

discoveredLocations[]
knownRoutes[]
```

保存读取后必须恢复到同一节点、同一朝向、同一累计步数和同一事件种子。玩家不能通过反复读取改变下一步随机事件。

从旧版存档升级时：

- 位于 `world` 场景的角色迁移到青茅山后山入口节点。
- 已完成的酒虫、战斗和时间状态保持不变。
- 不凭空解锁隐藏地点。

## 11. 首版内容

首版后山路径图至少包含：

### 普通目的地

1. 古月山寨。
2. 竹林猎场。
3. 一处为后续内容预留的普通山道出口；未开放版本不进入出口列表。

### 隐藏内容

1. 一处需要环境线索才能稳定找到的隐蔽洞口。
2. 一次性盗道材料或元石藏匿点。
3. 一条方源经过后才出现的脚印支路。

### 路径事件

1. 一场每日最多一次的山豕战斗。
2. 一段不会阻断操作的环境线索。
3. 一个固定的一次性小奇遇。

首版不要求隐藏洞口内部拥有完整长任务，可以先提供发现、记录路线和一项小奖励，验证探索循环。

## 12. 防卡关与异常处理

- 当前节点没有可用方向属于内容配置错误，运行时必须提供“退回入口”并记录错误。
- 时间不足以继续探索时，允许玩家选择任一已知普通出口返回，不强制在野外过夜。
- 关键剧情需要某普通目的地时，该目的地必须进入保底出口列表。
- 隐藏奖励可以错过当前时段，但不能破坏主线继续执行。
- 玩家战败后按现有规则在住处醒来，终止本次探索。
- 路径图配置在构建测试中检查死节点、无入口目的地和不可满足的隐藏路线。

## 13. 验收标准

1. 青茅山后山不再出现自由移动角色。
2. 玩家可以通过四方向按钮或键盘选择路径。
3. “后退”能够稳定回到上一节点。
4. 环境文字会随节点变化并提供可辨识信息。
5. 正确路径可以在二十步前到达山寨和猎场。
6. 连续二十次有效选择后，可以选择任一已开放普通目的地。
7. 隐藏地点不会出现在二十步保底列表。
8. 正确路线或线索能够发现隐藏洞口。
9. 隐藏洞口首次发现后永久记录并允许直接抵达。
10. 随机战斗不会重置防迷路累计。
11. 保存读取不会重排路径或刷新下一随机事件。
12. 山寨、客栈、学堂和住处仍可自由移动。
13. 既有酒虫完整路线和方源时间推进测试继续通过。
