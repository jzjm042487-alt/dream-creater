# 《蛊真人：天外盗剧本》青茅山 MVP 条件对话剧本重构规格

日期：2026-07-27

状态：已获玩家批准，待实现

本规格取代 `2026-07-26-qing-mao-mvp-complete-script-design.md` 中的视觉小说式演出结构，
并指导 `docs/game-design/qing-mao-mvp-script/` 的完整重写。旧稿中的可用剧情事实、角色动机、
任务奖励和世界时间继续作为素材；镜头、动作、旁白、每日强制场景和围绕方源组织的主线全部废弃。

## 1. 目标

青茅山 MVP 使用常规 RPG 的状态驱动对话树：

1. 玩家前往地点。
2. 玩家找到在场 NPC 或可交互物。
3. 系统根据当前状态选出该对象可触发的对话节点。
4. NPC 说出当前台词，玩家选择一句完整回答。
5. NPC 作出对应回应，系统修改任务、关系、物品或时间状态。
6. 对话结束。
7. 后置对话在玩家下次于正确地点找到正确角色时出现。

正式剧本必须提供一条玩家主线、五条完整支线、关键 NPC 的状态对白和新手村限定奖励闭环。
玩家角色固定为男性古月旁支，可选择姓名，并保留已确定的属性、资质、天赋、缺陷与命格 Roll。

## 2. 明确取消的设计

以下内容不得进入新剧本：

- 视觉小说式连续场景。
- 镜头、视角、立绘调度、动作演出、音效指令和不可交互旁白。
- 每日开始时自动播放的强制主线。
- 由一个对话节点自动传送到新地点或自动完成调查、战斗、偷盗和移动。
- 为每一句普通回答建立独立永久旗标。
- 独立的方源敌意、警觉、每日计划和特殊反制系统。
- 要求玩家持续观察、追踪、竞争或改变方源的主线目标。
- 任何必须与方源交谈才能继续的主线阶段。
- 以“原作同步率”评价或惩罚玩家偏离原作。
- 方源对原作机缘、任务和世界资源的默认优先权。

## 3. 玩家与世界定位

玩家是本游戏唯一主角。原作文本提供世界规则、人物背景、已知事件和可利用的情报，不规定玩家必须
围绕原作主角行动。

主线关注玩家自己的经历：

```text
生成古月旁支身份
→ 完成开窍并在学堂立足
→ 建立自己的修炼构筑
→ 获取财富、身份或外部渠道
→ 为狼潮准备生存资源
→ 应对青茅山覆灭
→ 携带自己的任务结果永久离山
```

原作事件仍会按世界日历推进。玩家不介入时，NPC 可以取得资源、死亡、离场或完成自己的目标；
这属于普通世界结算，不是为方源保留剧情。

“新世界游戏生成器”只承担玩家 UI 工具：

- 区分原作记录、当前已验证事实和未验证推测。
- 提供玩家已查询到的原作情报。
- 报告世界状态变化与任务截止。
- 不在世界内参与 NPC 对话。
- 不评价玩家是否忠于原作，也不评价选择善恶。

## 4. 常规交互架构

### 4.1 世界出场系统

世界系统负责：

- 当前日期与时段。
- 当前地点。
- NPC 是否在场。
- NPC 因任务结果而离开、死亡或更换地点。
- 可交互物是否存在、已取走或已损坏。

角色出场规则不写进台词正文。对话节点只引用角色、地点和状态。

### 4.2 对话解析器

玩家与 NPC 交互时，解析器依次执行：

```text
查找该 NPC 的全部节点
→ 匹配当前地点
→ 匹配日期和时段
→ 检查任务阶段与世界状态
→ 检查所需物品、属性、天赋和关系
→ 排除已消费、已过期或被互斥结果关闭的节点
→ 选择优先级最高的有效节点
```

普通 NPC 直接进入当前最合适的节点，不先展示话题菜单。商人、导师等长期功能型 NPC 可以先显示
“交谈、交易、请教”等功能入口；任务对话仍由相同解析规则选择。

优先级只使用五档：

1. 当日即将过期的任务节点。
2. 当前主线的新节点。
3. 当前支线的新节点。
4. 已完成任务的状态回应。
5. 日常重复台词。

同一档出现多个有效任务节点时，才显示简短的话题选择，让玩家决定先谈哪一件事。

### 4.3 对话运行器

标准节点运行过程：

```text
NPC 开场
→ 玩家选择完整回答
→ 必要时执行一次对话判定
→ NPC 显示对应回应
→ 原子写入全部状态
→ 标记节点已访问或已消费
→ END
```

默认在一次选择后结束交谈。只有一句自然追问可以使用 `inline_next`；连续追问最多两层。
任务推进、地点变化和时间变化不得依靠 `inline_next` 自动完成。

查看 NPC 台词与选项不消耗时间。只有选项本身代表交易、说服、调查、委托或其他世界行动时，
才显式消耗行动点或推进时段。

## 5. 对话节点格式

### 5.1 必需字段

每个正式节点包含：

```text
节点 ID
所属主线或支线
角色
地点
日期或时间窗口
优先级
触发条件
排除条件
是否一次性
NPC 开场台词
玩家选项
每个选项的 NPC 回应
可选判定
状态修改
END 或 inline_next
过期与补救规则
```

节点 ID 全局唯一，格式为：

```text
<任务ID>_<角色ID>_<两位序号>
```

示例：`Q01_TAVERN_KEEPER_02`。

### 5.2 标准书写模板

```text
## Q01_TAVERN_KEEPER_02

角色：酒肆掌柜
地点：山脚酒肆
时间：第 5–8 日，午后或傍晚
条件：quest.q01.stage == "smell_found"
排除：visited(Q01_TAVERN_KEEPER_02)
优先级：支线新节点

[酒肆掌柜]
“又是你。后院那两坛酒我挪开了，你若还惦记，就先告诉我它们有什么问题。”

[选择 A]
[玩家]
“酒没有坏。是里面的东西在找酒气。”

[酒肆掌柜]
“听着不像酒客的话。你想查可以，出了事别说是我放你进去的。”

[写入]
quest.q01.stage = "back_room_open"

[结束]
END
```

节点中不允许出现：

- `[镜头]`
- `[动作]`
- `[旁白]`
- `[音效]`
- “进入某路线”而没有对应人物台词
- “玩家进行了合理解释”而没有写出玩家实际说法

### 5.3 选择与判定

玩家选项必须是角色真正说出口的完整句子。纯世界行动由地图、调查、战斗、交易或偷盗系统提供，
不伪装成对白选项。

普通回答不做判定。只有说服、欺骗、威胁、套话等对话行为可以声明判定：

```text
判定：魅力 + 对应天赋修正，对抗难度 60
成功回应：……
失败回应：……
```

判定结果写入一次并持久化。再次交谈只读取结果，不重复投掷。

## 6. 简化状态模型

### 6.1 默认状态

对话主要读取：

```text
world.day
world.period
world.flags
quest.<id>.stage
quest.<id>.route
quest.<id>.result
player.attributes
player.traits
player.inventory
player.knowledge
npc.<id>.relationship
item.unique.<item_id>.owner
visited(<node_id>)
choice(<node_id>)
```

常规任务推进优先使用 `quest.<id>.stage`。节点访问由系统自动记录。只有会长期改变后续内容的关键
决定才写入 `route`、`result` 或 `choice`；普通礼貌回答不建立永久变量。

### 6.2 方源状态

方源只保留普通 NPC 所需的事实：

```text
npc.fang_yuan.met_player
npc.fang_yuan.relationship
npc.fang_yuan.trade_history
npc.fang_yuan.direct_conflict
npc.fang_yuan.knowledge
```

没有独立警觉条、敌意条、原作主角 AI 或无条件反制。只有方源亲眼见过、从可信来源得知或与玩家
直接交易过的事实，才能改变他的后续台词。

所有方源节点均可跳过。任何任务如果允许从方源取得信息，也必须提供其他 NPC、现场痕迹、档案或
可交互物入口。

### 6.3 原子结算

玩家确认选项后，系统必须在一次结算中完成：

- 判定结果。
- NPC 回应选择。
- 任务阶段变化。
- 关系、物品、元石、行动点和时间变化。
- 节点访问记录。

其中任何一步无效时不得写入部分状态。唯一物品转移必须先移除原持有人，再写入新持有人。

## 7. 剧情结构

日期继续作为世界日历和截止条件，不再作为连续剧本章节。主线与五条支线统一采用：

```text
接触节点
→ 调查节点
→ 回报或回应节点
→ 关键决策节点
→ 结算节点
```

调查、战斗、移动、购买和偷盗由对应玩法完成。对话负责告知目标、回应结果、提供人物选择和结算
奖励。

### 7.1 主线《剧本之外》

主线只服务玩家成长：

1. 创建角色并确认姓名、属性、资质、天赋、缺陷与命格。
2. 在旧屋、族务堂和学堂完成旁支身份落地。
3. 参加开窍并取得基础蛊与修炼权限。
4. 通过学堂任务建立第一套可玩的修炼构筑。
5. 接触商队、家族或灰色渠道，准备离山身份。
6. 加入或避开外勤任务，为狼潮准备物资和路线。
7. 在青茅山覆灭时选择已解锁路线并永久离山。

主线可以使用学堂家老、族务执事、守卫、商队账房、青书副手和任务物件作为信息入口。
主线不得检查玩家是否见过方源。

### 7.2 Q01《月下酒虫》

```text
酒肆掌柜提供异香线索
→ 玩家调查酒坛、后院或购买记录
→ 玩家在正确地点寻找酒虫
→ 根据到达时间处理当前持有人或竞争者
→ 炼化、交易、夺取、放弃或错过
→ 掌柜与相关 NPC 提供结果对白
```

方源可以成为某一状态下的竞争者或持有人，但不是任务必见角色。

### 7.3 Q02《花酒遗藏》

```text
从酒虫、影壁痕迹、族史档案或现场调查获得入口
→ 分层探索遗藏
→ 处理家族、同伴或其他探索者的归属要求
→ 选择不同房间和资源
→ 在入口坍塌前完成最后一次取物
→ 结算蛊虫、密道图和知情者状态
```

Q02 的信息和进入方式不得只由方源提供。

### 7.4 Q03《贾金生遗案》

```text
接触贾金生或商队账房
→ 选择合法交易、私货、观察或拒绝
→ 案件发生后调查现场、证人和货物流向
→ 向贾富或铁家提交、隐瞒、伪造或出售证据
→ 锁定合法商路或灰色商路奖励
→ 在离山前接受最终案件后果
```

案件事实可以受 NPC 行动改变，但玩家不是方源案件的旁观者；玩家自己的交易、证据和选择是该线
叙事中心。

### 7.5 Q04《九叶生机草》

```text
通过遗产账目、药堂或舅父舅母得知九叶生机草
→ 调查所有权与保管地点
→ 选择合法主张、交易、偷取、委托保管或上缴
→ 处理药堂、江牙和家族的后续要求
→ 在截止前确定最终持有人
→ 结算持续经济或一次性保护奖励
```

### 7.6 Q05《青书的死局》

```text
由青书、青书副手或外勤任务开启
→ 收集至少两类危险证据
→ 完成至少两项撤退准备
→ 向青书或队伍提交可验证信息
→ 在任务地点执行救援、顶替、撤退或放弃
→ 结算青书命运、队伍伤亡与遗民关系
```

“知道原作结局”只能提供调查方向，不能代替证据、准备和人物动机。

## 8. 角色与台词标准

### 8.1 台词完整度

每个关键节点必须具备：

- NPC 开场 1–3 句。
- 玩家回答 2–4 项。
- 每项回答后的 NPC 回应 1–3 句。
- 判定存在时的成功与失败回应。
- 任务结束、失败和错过后的状态对白。

不得只写策划摘要。所有世界内选择必须让玩家知道自己实际说了什么。

### 8.2 玩家台词

现实玩家清楚自己正在玩根据小说生成的游戏。世界内角色不会直接对 NPC 说“你是小说人物”、
“原作中你会死”或“我读取了剧本”。玩家可以说出世界内合理的推断、警告、报价和谎言。

### 8.3 核心声音

| 角色 | 台词规则 |
| --- | --- |
| 方源 | 普通可选 NPC；短句，核算利益，只追问自己有理由知道的事实 |
| 方正 | 在认可、家族责任和兄长关系之间摇摆 |
| 学堂家老 | 以家族价值、纪律和资源回报评价弟子 |
| 青书 | 追问谁承担任务、谁负责撤退，不接受无证据预言 |
| 贾金生 | 用夸张报价和吹嘘遮掩对贾富的恐惧 |
| 贾富 | 只谈账目、损失、来源和可验证事实 |
| 白凝冰 | 直接讨论危险与生死，兴趣不等于好感 |
| 铁若男 | 核对时间线、来源和矛盾，不猜测内心 |
| 酒肆掌柜 | 关心生意、麻烦和酒肆责任，不主动卷入争斗 |
| 禾娘 | 精于小账，不白吃亏，也不替玩家承担大风险 |

关系变化只选用“陌生、正常、合作、冲突”等少量有意义的台词状态，不为每一点数值创建新版本。

## 9. 奖励与新手村限定物

### 9.1 五条支线核心奖励

| 来源 | 核心奖励 | 中期价值 | 最后窗口 |
| --- | --- | --- | --- |
| Q01 | 酒虫 | 提高一转真元质量，开启后续四味酒虫路线 | 第 10 日 |
| Q02 | 白豕蛊、玉皮蛊、隐石蛊、花酒密道图 | 力量、防御、藏匿、合炼与离山路线 | 第 25 日 |
| Q03 | 贾家通行商令，或袖囊蛊与黑市名册 | 合法商路或灰色商路；两类奖励互斥 | 第 27 日 |
| Q04 | 九叶生机草，或药堂功绩与保命药物 | 持续治疗经济，或低维护一次性保护 | 第 24 日 |
| Q05 | 青书信物、青藤护符 | 遗民接应与一次致命物理伤害保护 | 第 25 日 |

Q02 的奖励按探索深度发放：

- 正常完成稳定取得一只核心蛊。
- 准备充分可以取得两只。
- 深度探索并承担高成本，才可能取得三只与完整密道图。

### 9.2 隐藏限定物

| 物品 | 来源 | 作用 |
| --- | --- | --- |
| 癞土蛤蟆 | 商队紫金石 | 出售取得启动资金，或保留为后续炼道素材 |
| 赤铁舍利蛊 | 最后一次商队补给 | 推动一转修为；每存档一只 |
| 家族历史记录 | 花酒影壁特殊处置 | 改变家族与调查中的谈判条件 |
| 青书支援 | 青书救援准备 | 狼潮中自动完成一个战斗目标，使用后消失 |

限定物必须具有立即用途、中期用途和明确维持成本或路线代价。它们不能替代任务证据、人物动机和
必要准备。

### 9.3 永久离山

第 30 日确认离山时：

- 已发现但未取得的限定物显示名称和最后取得地点。
- 未发现的隐藏物只显示“仍有未确认的限定资源”。
- 玩家确认后写入 `world.village_closed = true`。
- 青茅山地点、商店、任务和原始奖励来源永久关闭。
- 后续可以取得升级材料，不能重新生成错过的基础蛊、信物和通行权。

## 10. 失败、错过与替代入口

### 10.1 主线

主线不得因漏掉一句台词而永久卡住。必要 NPC 缺席时使用：

- 同职能 NPC。
- 学堂或家族档案。
- 现场痕迹。
- 可交互任务物件。
- 更高成本的补救节点。

替代入口只保证主线信息与离山可达，不保证原 NPC 的关系奖励和专属信物。

### 10.2 支线

支线允许：

- 拒绝任务。
- 错过截止。
- 关键 NPC 死亡或离场。
- 奖励被其他 NPC 取得。
- 因互斥选择永久关闭一条路线。

支线失败后，玩家再次找到相关 NPC 时必须得到具体失败或事后台词，任务日志记录失败原因与最后窗口。
五条支线全部失败时，主线仍提供紧急流亡路线。

### 10.3 无可用节点

NPC 没有任务节点时：

- 有合适日常台词则播放一条 `fallback`。
- 没有可说内容则显示简短的当前状态回应并结束。
- 不弹出错误，不自动播放其他角色的节点。

- 物品与奖励。
- 日期和截止窗口。

所有镜头、动作、旁白、强制场次和以方源为中心的内容直接丢弃。

## 12. 数据错误处理

实现前的内容校验必须拒绝：

- 重复节点 ID。
- 引用不存在的 NPC、地点、物品或任务阶段。
- 未解析的模板变量。
- 没有 NPC 回应的玩家选项。
- 没有 `END` 或有效 `inline_next` 的分支。
- 超过两层的即时连续追问。
- 主线只能由方源提供的必需信息。
- 唯一物品同时拥有多个持有人。
- 截止后仍能领取已关闭奖励。

运行时在玩家确认选择前重新检查条件。条件失效时不结算，关闭旧选项并重新解析当前 NPC 节点。

## 13. 验证方案

### 13.1 静态校验

- 所有节点 ID 唯一。
- 所有任务阶段、状态键和跳转目标存在。
- 每个选项都有玩家台词、NPC 回应、状态结果和结束方式。
- 每条任务都有成功、失败、拒绝和错过终点。
- 所有新手村限定物都有唯一来源、最后窗口和永久错过结果。

### 13.2 流程校验

至少验证以下存档：

| 存档 | 必须成立 |
| --- | --- |
| 不接触方源 | 从创建角色到永久离山全程可完成 |
| 纯主线 | 五条支线全部忽略，主线仍可达紧急流亡 |
| Q01 成功/失败 | 酒虫所有权与后续台词正确 |
| Q02 一件/两件/全探索 | 奖励深度和入口截止正确 |
| Q03 合法/黑市 | 两类路线奖励互斥，案件后果不同 |
| Q04 自留/上缴/失去 | 最终持有人、收益与状态对白正确 |
| Q05 救援/顶替/死亡 | 青书命运、信物、护符与队伍后果正确 |
| 全限定收集 | 唯一物品不重复，离山携带正确 |
| 全部错过 | 离山前提示正确，确认后永久关闭 |
| 不同 Roll 角色 | 属性、天赋和背景只改变合法选项与判定，不阻断主线 |

### 13.3 台词验收

- 正文不存在镜头、动作和旁白标记。
- 玩家选项都是实际说出口的句子。
- NPC 不知道自己无法获知的玩家行为。
- 任务完成、失败和错过后，主要 NPC 均有状态回应。
- 方源所有对话都可跳过。
- 台词符合各角色稳定利益逻辑，不靠作者说明人物动机。

## 14. 完成定义

剧本重构完成必须同时满足：

1. 一条玩家主线与五条支线全部采用条件对话节点。
2. 所有关键节点具有完整 NPC 台词、玩家选项和逐项回应。
3. 所有推进来自玩家在正确地点主动找到角色或物件。
4. 日期只改变世界状态、角色出场和截止，不自动播放连续剧情。
5. 方源是普通、可完全跳过的配角。
6. 玩家不接触方源也能完成全部必需主线。
7. 新手村限定奖励具有中期价值，并在离山后永久关闭。
8. 全部静态校验与代表性流程校验通过。
