# 《蛊真人：天外盗剧本》青茅山开放世界设计

## 1. 文档定位

本文定义青茅山精简 MVP 的世界组织、地图交互、人物运行和机缘竞争。

唯一规则源为：

- `docs/superpowers/specs/2026-07-27-qing-mao-simplified-mvp-design.md`

本文不再定义方源专属系统、原轨维护、复杂关系数值、盗道负反馈或证据链。

## 2. 世界原则

### 2.1 依照原著初始化

首版地点、势力、人物、血脉、亲朋关系、主修方向、公开蛊虫和重要机缘尽量依据原著资料建立。

这样做的目的：

- 后续扩地图时有稳定地理和势力骨架。
- 角色能力与身份容易追溯。
- 新机缘可以判断发生地点、参与者和历史背景。
- 玩家查询原著时能得到统一资料。

### 2.2 开局后自由演化

游戏开始后，原著不再规定结果。

- 原本属于方源的机缘可以被玩家或其他角色取得。
- 原著中存活的人可以死亡。
- 原著中失败的人可以胜利。
- 势力可以因实际战斗和资源变化而改变。
- 已经改变的事实不会被系统纠正回原著。

### 2.3 只模拟玩家能感知的世界

MVP 不运行全地图 NPC 日程。

只更新：

- 当前地图中的角色。
- 当前主线步骤涉及的角色。
- 已激活机缘的参与者。
- 正在进行的战斗。
- 明确写入的世界事实。

离屏角色没有逐分钟行动、隐藏心理计量或资源流水。

## 3. 三层数据

### 3.1 原著资料层

只读数据，包括：

- 人物资料。
- 势力资料。
- 地点资料。
- 蛊虫资料。
- 关系谱。
- 机缘索引。
- 原著时间与事件摘要。

该层不因游戏结果被改写。

### 3.2 当前世界事实层

记录已经发生的结果：

- 角色存活、受伤、失踪、离山或死亡。
- 机缘当前是否存在、已解决或被谁取得。
- 地点是否开放、危险或毁坏。
- 势力当前公开状态。
- 当前主线步骤。

事实使用离散状态，不使用同步率、偏移值或世界压力。

### 3.3 玩家知识层

记录玩家已经知道的当前事实：

- 已见人物。
- 已发现地点。
- 已确认机缘结果。
- 已知公开蛊虫。
- 已读原著资料条目。

“玩家不知道”只影响 UI 是否显示，不为 NPC 增加警觉或怀疑数值。

## 4. 地理骨架

### 4.1 青茅山区域

MVP 采用以下区域：

1. 古月山寨。
2. 学堂。
3. 家族蛊室。
4. 酒肆与集市。
5. 居住区。
6. 山林入口。
7. 竹林猎场。
8. 青茅山野外。
9. 隐藏山洞。
10. 商队驻地。
11. 狼潮防线。
12. 离山出口。

### 4.2 地点状态

每个地点只需要：

- 地点 ID。
- 名称。
- 地图背景。
- 当前可进入状态。
- 当前角色列表。
- 当前交互列表。
- 相邻入口或野外 origin。

地点不会因为好感、功绩或证据数量解锁。主线步骤可以让地点在流程上出现，但不要求数值门槛。

### 4.3 旅行

寨内和场景地图使用角色靠近交互点的方式移动。

进入野外后使用前、后、左、右。玩家不点击目标地点传送。

野外旅行完整规则见：

- `docs/superpowers/specs/2026-07-26-wilderness-hidden-route-design.md`

已经发现的隐藏地点可以出现在当前远征的直接返回列表中；未发现地点永远不显示。

## 5. 势力

### 5.1 MVP 势力

- 古月一族。
- 白家寨。
- 熊家寨。
- 临时商队。
- 狼群与野兽。
- 独行蛊师和魔道角色。

### 5.2 势力数据

势力记录：

- 势力 ID。
- 名称。
- 核心地点。
- 公开目标。
- 主修方向。
- 主要角色。
- 与其他势力的公开关系类别。
- 当前世界状态。

势力关系只使用离散类别：

- 同盟。
- 中立。
- 竞争。
- 敌对。
- 停战。

MVP 不计算势力好感、声望点、外交热度或每日变化。

### 5.3 势力变化

只有明确事件可以改变关系类别。例如：

- 三寨共同抵御狼潮，临时进入停战。
- 一方公开袭击另一方，进入敌对。
- 商队离开，临时关系记录关闭。

变化写入当前世界事实，并立即反映在地图角色和公开对话中。

## 6. 人物

### 6.1 人物资料

人物资料至少包含：

- 姓名与身份。
- 所属势力。
- 血脉和亲朋关系。
- 境界。
- 公开蛊虫。
- 主修方向。
- 当前世界状态。
- 地图 Q 版资产。
- 成人对话立绘资产。

### 6.2 关系谱

人物关系使用无数值图谱：

- 血亲。
- 配偶。
- 远亲。
- 朋友。
- 师徒。
- 竞争者。
- 熟人。

关系谱用于查阅和理解人物，不提供检定加成，不解锁任务。

### 6.3 天骄名册

名册首批角色：

- 方源。
- 方正。
- 漠北。
- 赤城。
- 白凝冰。

可以追加青书等公开重要人物。

名册展示境界、公开蛊虫、公开战绩和存活状态。它不是排名分数，也没有专属观察系统。

### 6.4 普通规则

所有人物遵守同一套规则：

- 使用当前装备、蛊虫和属性进入战斗。
- 生命归零时按场景的致命或非致命标记结算。
- 取得机缘后更新当前世界事实。
- 死亡后不参与后续场景。

方源没有剧情保护。若其缺席，剧本使用通用替代角色或略过该句，不重置世界。

## 7. 地图交互

### 7.1 交互类型

靠近角色或物体后，可以出现：

- 对话。
- 偷盗。
- 交易。
- 训练。
- 调查环境。
- 进入建筑。
- 进入野外。
- 开始战斗。
- 查看机缘。

按钮只展示当前可执行的动作，不展示复杂条件公式。

### 7.2 对话

对话由背景、角色立绘、台词和最多三个简短选项组成。

选项可以改变当前场景、触发即时奖励或进入普通战斗，但不显示 AP、风险、锁定或二次确认。

### 7.3 偷盗

偷盗为单次地图交互：

1. 查看目标可偷物。
2. 选择一件。
3. 按运气、盗道熟练、境界差和固定物品难度结算。
4. 在地图交互层显示成功或失败。

成功后物品直接进入普通行囊，事件结束。失败也只结束本次交互；除非当前场景明确写了立即战斗，否则没有跨场景后果。

完整公式见：

- `systems/theft-system-design.md`

## 8. 机缘

### 8.1 机缘记录

每条机缘包含：

- 机缘 ID。
- 原著资料摘要。
- 原著时间范围。
- 原著地点。
- 原著关联人物。
- 当前世界状态。
- 当前地图入口。
- 解决方式。
- 即时奖励。

“原著归属者”是资料，不是所有权锁。

### 8.2 当前状态

机缘只使用：

- `inactive`。
- `available`。
- `contested`。
- `resolved`。
- `gone`。

这套状态来自 `opportunity-status.enum.json`，不复用任务状态，也不使用
`open` 或 `unknown`。

`resolved` 可以记录取得者角色 ID，但这只是当前世界事实，不产生追查或归还
规则。其他状态禁止记录取得者；`gone` 明确表示无人取得。

### 8.3 争夺

机缘争夺可以通过：

- 先到达。
- 追踪或捕捉小游戏。
- 交易。
- 地图偷盗。
- `8 x 6` 战斗。
- 简短对话选择。

解决后立即写入世界事实。其他角色依据新事实继续行动，不执行原著补偿路线。

### 8.4 MVP 五条机缘

1. 酒虫。
2. 花酒行者遗藏。
3. 商队资源机会。
4. 九叶生机草。
5. 青书命运事件。

它们全部可选，不阻断主线。

## 9. 蛊虫获取与成长

### 9.1 低阶获取

低阶蛊的野外获取不是普通刷怪掉落。

使用：

- 痕迹观察。
- 路线选择。
- 诱饵判断。
- 时机判断。
- 容器选择。
- 必要时的前置战斗。

小游戏完整规则见：

- `docs/superpowers/specs/2026-07-26-low-rank-gu-acquisition-and-care-design.md`

### 9.2 高阶预留

三转以上蛊可以在未来要求战斗压制、阵法、环境、配方或原著复杂条件。

MVP 不定义高阶掉落表。战斗胜利只能进入未来的捕捉或炼化接口，不能直接获得高阶蛊。

### 9.3 修为

战斗是修为进度主要来源。训练和首次危险探索提供小额进度；夜间修炼可选。

当前境界进度满后直接突破，无地点、元石、关系或随机门槛。

## 10. 战斗

战斗使用现有 `8 x 6` 网格：

- 默认 `1v1`。
- 少量 `1v2`。
- 上下左右移动。
- 移动后执行一个动作。
- 技能按格子射程和范围生效。
- 直到胜利、失败或边缘撤退。

空窍中的蛊提供主动技能和被动。玩家始终可以普通肉搏。

不存在中断条件、反应窗口或复杂预判队列。

## 11. 主线与自由行动

### 11.1 主线

主线按步骤推进：

- 当前步骤。
- 下一步骤。
- 完成状态。

完成触发器发生后直接前进。不存在好感、功绩、证据、属性阈值或补救路线门槛。

### 11.2 章节日

“第 0 日”到“第 30 日”是叙事章节编号。

自由探索、训练、夜间修炼和休息不会消耗主线期限，也不会错过最终离山选择。

### 11.3 离山

达到最终步骤后直接选择离山路线。玩家携带当前行囊、蛊虫、装备、境界和已发生的世界事实进入下一篇章。

## 12. 原著查询

查询支持人物、时间、地点、蛊虫、势力和机缘。

结果区分：

- 原著资料。
- 当前世界已确认。
- 当前世界未知。

查询不消耗资源，不改变世界，也不创建强制任务。

## 13. 状态与存档

### 13.1 活动世界状态

只保存：

- 当前场景。
- 主线步骤。
- 玩家活动状态。
- 行囊、装备与蛊虫。
- 人物存活状态。
- 机缘状态。
- 地点开放状态。
- 关系谱类别。
- 当前远征与战斗。
- 确定性随机游标。

精确字段、默认值、旧 `{ state, journal }` 包装迁移和幂等规则见
`contracts/game-state-v3.md`。

### 13.2 普通存读档

提供清晰的存档槽、时间、地点和缩略状态。

读档恢复已保存世界，不重掷野外、偷盗或战斗结果。没有回溯修正或世界纠偏。

### 13.3 兼容

旧存档字段可无损保留，但活动系统禁止读取旧的数值关系、证据、警觉、行动点和原轨字段。

## 14. MVP 验收

- 原著数据能够初始化地点、势力、人物、关系和机缘。
- 游戏开始后，方源和其他角色按同一规则竞争。
- 方源死亡时流程可继续。
- 玩家通过地图靠近角色完成对话与偷盗。
- 野外只能通过相对方向旅行，不点击目的地传送。
- 五条可选机缘均不阻断主线。
- 低阶蛊通过互动和小游戏获取，不作为普通刷怪掉落。
- 修为满后可直接突破。
- `8 x 6` 战斗可胜利、失败和撤退。
- 最终步骤直接显示离山选择。

## 15. 后续扩展

后续地图继续沿用同一结构：

1. 从原著提取地点、势力、人物和机缘。
2. 写入只读资料层。
3. 为新区域制作有限地图和方向路线。
4. 为机缘制作交互、小游戏或战斗。
5. 把实际结果写入当前世界事实。

不需要增加原轨纠正系统即可扩大世界。
