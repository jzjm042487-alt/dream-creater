# 《蛊真人：天外盗剧本》青茅山 MVP 完整剧本与流程规格

版本：`1.0-rc1`

状态：完整剧本已成稿并通过独立规格复审，现交玩家审阅。

## 1. 文档目标

本文定义青茅山 MVP 的完整可玩剧本，供后续任务数据、角色数据、事件脚本、UI 和测试计划直接使用。

MVP 必须包含：

- 一个现实玩家通过“新世界游戏生成器”进入小说生成世界。
- 一个固定男性古月旁支角色，允许自定义姓名，不做捏脸。
- 一条从身份生成、开窍、学堂、狼潮到永久离山的主线。
- 五条可错过、可失败、有补救分支的完整支线。
- 三十个可操作关键日，章节之间允许数周或数月的时间跳转。
- 方源独立行动，但只在利益冲突时反制玩家。
- 角色对白、选择条件、状态变化、奖励、失败结果和读档状态全部可确定。

本文对白均为游戏原创文本，只使用原作人物、设定和事件事实，不复刻原文段落。

可直接拆分为事件数据的逐场台词、选项回应和跳转位于
[`docs/game-design/qing-mao-mvp-script/`](../../game-design/qing-mao-mvp-script/README.md)。
本文负责规则与状态契约，生产剧本负责逐句演出；两者共同构成完整交付。

## 2. 已锁定设计

### 2.1 玩家身份

玩家不是穿越者，也不被要求假装自己生活在蛊世界。

现实中的玩家把小说交给“新世界游戏生成器”，生成器据此构建世界、人物、原作节点和可偏移事件。玩家始终清楚自己正在玩游戏，可以使用存档、任务日志、原文索引和状态面板。

世界内的 NPC 只看见一个合法存在的古月旁支少年。生成器为该身份补全族谱、旧屋、过去经历和 NPC 记忆。NPC 不知道小说、生成器或现实玩家。

玩家在 UI 中可以选择“利用原作情报”，角色在世界内会自动执行合理行动或说出合理措辞，不会直接对 NPC 说“你是小说人物”。

### 2.2 MVP 边界

- 玩家角色固定为男性，与方源、方正同届参加开窍大典。
- 姓氏固定为“古月”，玩家输入一至两个字的名字。
- 使用一套固定半身立绘和一套 Q 版地图角色。
- 立绘只做正常、警觉、受伤、重伤四种状态。
- 不做恋爱、成人关系和未成年角色成人内容。
- 原作大节点发生，但具体参与者、物品归属和配角命运可以改变。
- 离开青茅山后不能返回。

### 2.3 主线与支线

主线名称：`《剧本之外》`

五条正式支线：

1. `Q01 月下酒虫`
2. `Q02 花酒遗藏`
3. `Q03 贾金生遗案`
4. `Q04 九叶生机草`
5. `Q05 青书的死局`

古月赤城资质秘密是学堂隐藏事件，不占正式支线名额。

## 3. 剧本标记规范

脚本使用以下标记：

- `[SYS]`：游戏生成器或系统信息。
- `[NAR]`：场景旁白。
- `[NPC:name]`：NPC 台词。
- `[CHOICE]`：玩家 UI 选项；允许使用游戏和原作术语。
- `[ACT]`：角色实际说出的话或执行的动作。
- `[CHECK]`：属性、物品、线索或状态判定。
- `[EFFECT]`：状态变化。
- `[GOTO]`：跳转到其他场景。
- `[LOCK]`：永久关闭选项、任务或奖励。

示例：

```text
[CHOICE] 利用原作情报，指出酒虫会被酒香吸引。
[ACT] 你捻起酒坛封泥闻了闻：“这种气味能引来嗜酒的野虫。”
[CHECK] 心性 + 剧本解析，对抗难度 75。
[EFFECT] 成功：获得 clue_wine_lure；失败：fang_yuan_alert +5。
```

## 4. 角色创建

### 4.1 创建顺序

1. 输入名字。
2. 查看固定男性角色立绘。
3. 生成旁支身份细节。
4. Roll 属性、资质、命格、天赋与缺陷。
5. 查看开局优势和风险。
6. 整卡接受或整卡重 Roll。
7. 确认后创建“进入世界前”永久存档。

玩家可无限整卡重 Roll，但不能锁定单项继续刷其他项目。

每次重 Roll 令 `reroll_index +1`，再分别以 `hash(world.seed, reroll_index, "character")` 和 `hash(world.seed, reroll_index, "identity")` 生成两类种子。确认后种子与整张卡一起锁定。

### 4.2 身份细节

所有存档共享以下身份框架：

- 年龄与方源同届。
- 父母不在山寨权力核心。
- 拥有合法族谱和开窍资格。
- 名下有一间破旧旁支竹楼。
- 初始拥有八块完整元石、三日干粮、一套学堂衣物和一枚旧屋钥匙。

每个存档随机生成：

- `old_acquaintance`：一名认识玩家过去的同届旁支。
- `creditor`：一名持有债据或人情账的成年族人。
- `initial_rival`：一名对玩家抱有成见的同窗。
- `family_secret`：失踪亲人、旧任务遗物、错误账目或未兑现承诺之一。

这些随机项只按下表改变入口、台词和固定资源，不改变主线可达性。

身份随机使用独立的 `identity_seed`，四类结果等概率抽取且在整卡确认后锁定：

| 随机项 | 固定候选与结果 |
| --- | --- |
| `old_acquaintance` | 古月青石以 50% 成为旧友、50% 成为旧日竞争者 |
| `creditor` | 古月禾娘持真债、涂改债、人情账或误记账之一，各 25% |
| `initial_rival` | 赤城、漠北、青石或一名无派系同窗，各 25% |
| `family_secret` | 失踪亲人、旧任务遗物、错误账目、未兑现承诺，各 25% |

`family_secret` 的入口和固定收益如下：

| 秘密 | 第 9 日事件 | 结算 |
| --- | --- | --- |
| 失踪亲人 | 禾娘交出最后一次任务地点 | Q05 狼群路线证据准备 +10，青书初见额外对白 |
| 旧任务遗物 | 旧屋墙内发现任务牌 | `qing_shu.warning_evidence` 不直接增加；调查任务牌 1 AP 后取得第一类证据 |
| 错误账目 | 证明债据与内务堂副本冲突 | 债务关闭，Q04 所有权证据 `parent_ledger` |
| 未兑现承诺 | 禾娘承认父母曾替商队护货 | Q03 合法路线进度 +1，取得一张只能用于交涉的旧凭条 |

### 4.3 属性

| 属性 | 稳定 ID | 用途 |
| --- | --- | --- |
| 根骨 | `physique` | 生命、负伤、恢复、肉身强化 |
| 悟性 | `insight` | 学习、推演、传承机关、修炼效率 |
| 神魂 | `soul` | 抗恐惧、抗幻象、承受回溯冲击 |
| 身法 | `agility` | 潜行、跟踪、先手、逃跑 |
| 魅力 | `charisma` | 交涉、伪装、交易、建立关系 |
| 心性 | `resolve` | 撒谎、威慑、承压、不露破绽 |
| 气运 | `luck` | 随机事件权重、意外收获、灾祸偏移 |
| 盗道 | `theft` | 偷物、偷情报、偷身份、处理赃物 |
| 炼道 | `refinement` | 炼化、合炼、判断蛊材、降低损耗 |

七项基础属性在 `30–70` 之间，总和固定为 `350`。生成算法固定为：

1. 七项属性各从 30 起步。
2. 将 28 枚、每枚价值 5 点的属性筹码逐枚随机分配。
3. 某项达到 70 后不再进入候选池。
4. 由 `character_seed` 决定分配序列，同一张角色卡重复查看不会变化。

盗道与炼道总和固定为 `100`。盗道范围 `45–70`，炼道范围 `30–55`。

盗道从 `45/50/55/60/65/70` 中等概率抽取，炼道取 `100 - 盗道`。

属性表保存“基础值”和“有效值”两列。天赋、缺陷和临时状态只修改有效值；有效值统一限制在 `20–85`，不会反向改变七项基础属性总和。盗道与炼道的有效值也使用 `20–85` 上限。

### 4.4 空窍资质

空窍资质在创建时生成，但在第 2 日开窍大典才揭示。

| 资质 | 概率 | 空窍容量 | 修炼倍率 | 真元恢复倍率 | 平衡补偿 |
| --- | ---: | ---: | ---: | ---: | --- |
| 甲等 | 10% | 80–99 | 1.6 | 1.5 | 缺陷只从严重池抽取 |
| 乙等 | 30% | 60–79 | 1.3 | 1.2 | 无额外修正 |
| 丙等 | 45% | 40–59 | 1.0 | 1.0 | 两项普通天赋的数值修正各 +5 |
| 丁等 | 15% | 20–39 | 0.7 | 0.8 | 额外获得一个混合命格 |

任何资质都能通关。低资质更依赖酒虫、元石和偷取资源，高资质更容易受到家族关注和任务征调。

### 4.5 命格、天赋和缺陷

每个角色获得：

- 一个核心命格。
- 两个普通天赋。
- 一个缺陷。

首批词条：

| 词条 | 类型 | 效果 |
| --- | --- | --- |
| 酒虫亲和 | 核心命格 | 提前获得酒虫异动提示，炼化酒虫所需行动 -1 |
| 善藏气息 | 核心命格 | 潜行准备 +10，因现场痕迹增加的方源警觉减少 20% |
| 盗门余脉 | 核心命格 | 盗道 +10，家族初始信任 -5 |
| 商道敏感 | 普通天赋 | 账册和价格判定 +10 |
| 早慧 | 普通天赋 | 悟性 +10，根骨 -5 |
| 山林熟路 | 普通天赋 | 竹林和野外移动不消耗首次额外行动 |
| 狠辣心性 | 混合天赋 | 威慑 +10，安抚和温和说服 -10 |
| 空窍残缺 | 缺陷 | 真元上限 -15%，偷取蛊虫判定 +10 |
| 命薄福浅 | 缺陷 | 气运 -10，每章一次将致命失败降为重伤 |
| 易留痕迹 | 缺陷 | 潜入失败时 exposure 额外 +5 |
| 血道暗缘 | 混合命格 | 第 28–30 日解锁血道选项，血道污染获取翻倍 |

抽取顺序与权重：

| 池 | 抽取数 | 权重 |
| --- | ---: | --- |
| 核心命格 | 1 | 酒虫亲和 30%、善藏气息 35%、盗门余脉 35% |
| 普通天赋 | 2，不放回 | 商道敏感 30、早慧 25、山林熟路 25、狠辣心性 20 |
| 普通缺陷 | 1 | 空窍残缺 35%、命薄福浅 35%、易留痕迹 30% |
| 甲等严重缺陷 | 取代普通缺陷 | 空窍残缺 55%、易留痕迹 45% |
| 丁等额外混合命格 | 1 | 血道暗缘 60%、狠辣心性 40% |

兼容与数值规则：

- 同名词条不能重复；丁等已经抽到狠辣心性时，额外混合命格固定为血道暗缘。
- 早慧修改后的悟性与根骨仍受 `20–85` 有效值限制。
- 盗门余脉只提高盗道有效值，不改变“盗道 + 炼道 = 100”的基础值。
- 空窍残缺在空窍容量生成后乘以 `0.85` 并向下取整，最低容量为 15。
- 命薄福浅的保命效果每章一次，不能与青藤护符在同一次伤害上重复触发；先消耗青藤护符。
- 丙等的“数值修正 +5”使商道、早慧、狠辣心性等原本的 `+10` 变为 `+15`；山林熟路没有常驻数值时，改为每幕第一次山林判定额外 +5。
- 所有概率只用于整卡生成。确认角色后，资质、词条和基础属性永久锁定。

## 5. 时间与行动

### 5.1 关键行动日

MVP 有三十个可操作关键日。它们不是连续自然日。每五个关键日组成一幕，幕间由生成器进行时间跳转。

每个关键日包含：

- 三个自由行动点。
- 一个不消耗行动点的必定世界事件。
- 当日结束时的 NPC、方源、任务期限和蛊虫喂养结算。

常规交谈、查看界面和读取已有日志不消耗行动点。调查、修炼、移动到危险区域和任务执行通常消耗一个行动点。长时间炼化、战斗准备和深度潜入消耗两个行动点。

### 5.2 幕间计划

第 5、10、15、20、25 日结束后，玩家选择一个幕间重点：

- 修炼：在自然修炼之外获得 15 点基础修炼进度。
- 谋生：获得 15 元石。
- 练盗：下一幕第一次盗道判定获得行动准备 +20。
- 经营关系：选择一名存活且可接触的 NPC，信任 +10，并播放一段未读的状态对白。
- 养蛊：选择一只蛊，免除其下一幕全部食料消耗。

未解决的限时任务在幕间不会停住，会按其失败分支继续发展。

每次幕间无论选择什么重点，都会先获得 5 点基础修炼进度；重伤时减半并向下取整。谋生不会再额外扣减关系，经营关系以外的计划也不会自动增加信任。

### 5.3 修炼、位阶与真元

第 2 日开窍后，玩家状态变为：

```text
player.rank = rank1
player.cultivation_progress = 0
player.aperture_capacity = 资质生成值
player.primeval_essence = player.aperture_capacity
```

每一转使用 `0–100` 修炼进度，阶段由进度派生：

| 进度 | 小境界 |
| ---: | --- |
| 0–24 | 初阶 |
| 25–49 | 中阶 |
| 50–74 | 高阶 |
| 75–99 | 巅峰 |
| 100 | 等待突破 |

主动修炼消耗 `1 AP` 和 20 点真元，基础进度为 6。玩家可额外消耗最多两块元石，每块使本次基础进度 +2。

实际增加值：

```text
floor(基础进度 × 资质修炼倍率 × 伤势修正)
```

伤势修正：无伤 `1.0`、轻伤 `0.8`、重伤 `0.5`。酒虫提高真元质量，不直接乘算修炼进度。

修炼进度达到 100 后：

- 第 20 日以前锁在 100，不允许提前进入二转。
- 第 20 日起可消耗 `2 AP` 和当前空窍容量 50% 的真元执行突破。
- 无重伤且没有空窍封锁时必定成功；成功后 `rank +1`，溢出进度清零。
- 重伤或空窍封锁时选项置灰，明确显示阻塞条件。
- 青茅山 MVP 最高为二转巅峰；三转只保留后续数据字段。

真元以实际点数记录，上限等于空窍容量：

- 第 1–25 日正常睡眠后恢复至上限；重伤只恢复至上限的 50%，疲惫 3 只恢复至 75%，取两者较低。
- 第 26–30 日为连续灾变，每次日终恢复 `空窍容量 × 30% × 真元恢复倍率`，不直接回满。
- “休息治疗”消耗 1 AP，恢复空窍容量的 35% 真元并降低疲惫 1。
- 吸收一块元石恢复 20 点真元，不消耗 AP；战斗中使用则占用一回合。
- 真元不足时，相关蛊虫选项置灰，不允许先产生负数再结算。

疲惫为 `0–3`：

- 长时间炼化、连续两场战斗或一日内第三次危险行动使疲惫 +1。
- 疲惫 2 时所有判定 -5。
- 疲惫 3 时所有判定 -10，不能选择 2 AP 的长行动。
- 正常日终休息降低 1，幕间时间跳转清零；狼潮期间不会自动清零。

### 5.4 行动点结算

强制世界事件的“进入、观看和第一个必要回应”固定为 `0 AP`。世界事件中的可选追查、炼化、护送或潜入仍按选项标注扣除 AP；因此“事件免费”不等于事件内所有选择免费。

标准成本：

| 行为 | AP |
| --- | ---: |
| 交谈、交易、查看、提交已有物品或证据 | 0 |
| 同区域调查、一次修炼、一次准备、常规采集 | 1 |
| 危险区域往返、护送、长时间炼化、复杂潜入 | 2 |
| 强制世界事件中的战斗 | 0 |
| 玩家主动发起的战斗或狩猎 | 1 |

- 事件数据必须显式保存 `ap_cost = 0/1/2`，不能只依赖标准成本推断。
- 同一行动同时推进两条任务时只扣一次 AP，并把两个状态变化写入同一结算。
- AP 不足时选项置灰；不会允许透支到负数。
- 一次 2 AP 行动被剧情打断时，若尚未执行判定只扣 1 AP；已经执行判定则扣满 2 AP。
- 第 29 日回溯后的修正行动使用独立资源 `rollback.revision_actions`，不与普通 AP 混用。

## 6. 判定系统

### 6.1 公式

```text
判定总值 =
主属性
+ 副属性修正
+ 专长修正
+ 蛊虫修正
+ 情报准备
+ 行动准备
+ 状态修正
+ 1d20
```

修正项：

```text
副属性修正 = 无副属性时为 0，否则 floor((副属性 - 30) / 4)
专长修正 = 无专长时为 0，否则 floor(盗道或炼道有效值 / 4)
蛊虫修正 = 0 / 5 / 10 / 15 / 20，同名效果不叠加，取最高值
情报准备 = 0 / 10 / 20
行动准备 = 0 / 10 / 20
状态修正 = 伤势、疲惫、环境和临时效果之和，限制在 -30 至 +20
```

事件明确写有“某角色信任判定”时，关系修正计入状态修正：`clamp(floor(该角色信任 / 10), -10, +10)`。没有明确写出时，关系不参与数值判定。

每个判定必须在事件数据中指定一个主属性、零或一个副属性，以及零或一个专长。显示文本中的“根骨 + 心性”表示根骨为主属性、心性为副属性，不是两项属性直接相加。

常用映射：

| 行动 | 主属性 | 副属性 | 专长 |
| --- | --- | --- | --- |
| 月刃命中、机关推演 | 悟性 | 身法 | 无 |
| 近身压制、承伤 | 根骨 | 身法或心性 | 无 |
| 追踪、逃跑 | 身法 | 悟性或根骨 | 无 |
| 说服、安抚 | 魅力 | 心性 | 无 |
| 撒谎、威慑 | 心性 | 魅力 | 无 |
| 抗恐惧、抗回溯冲击 | 神魂 | 心性 | 无 |
| 随机机缘 | 气运 | 无 | 无 |
| 偷物、藏赃、伪造现场 | 身法 | 心性 | 盗道 |
| 炼化、合炼、辨认蛊材 | 悟性 | 神魂 | 炼道 |

难度：

| 难度 | 目标值 |
| --- | ---: |
| 简单 | 60 |
| 中等 | 75 |
| 困难 | 90 |
| 极难 | 105 |

结果：

- `总值 >= 目标值 +15`：完美成功。
- `总值 >= 目标值`：成功。
- `总值 >= 目标值 -10`：部分成功。
- `总值 < 目标值 -10`：失败。

情报准备和行动准备各分为 `0/10/20` 三档。玩家若已满足必胜条件，脚本直接成功，不再随机。

对抗判定时双方分别按同一公式计算，数值高者获胜；相同数值时防守方获胜。NPC 没有完整属性表时，事件直接提供其对抗总值 `60/75/90/105`。

### 6.2 失败原则

- 普通失败不能直接断主线。
- 部分成功必须推进信息或改变局面。
- 关键物品错过后允许低效率替代或高风险追回。
- 只有玩家角色死亡会进入读档界面。
- 第 29 日第一次灾变中的死亡由方源回溯事件接管，不立即显示普通死亡界面。

### 6.3 回合制战斗

战斗由一个遭遇难度、回合上限和一至三个场景目标组成。默认上限为三回合；Q05 对白凝冰为五回合。整场战斗只在进入时结算一次 AP，不按回合扣 AP。

每回合玩家选择一项：

| 行动 | 判定 | 作用 |
| --- | --- | --- |
| 月刃攻击 | 悟性 + 身法，对抗遭遇难度 | 消耗月光蛊 10 真元，造成伤害 |
| 近身攻击 | 根骨 + 身法，对抗遭遇难度 | 不耗真元，重伤时 -10 |
| 防御 | 根骨 + 心性，对抗遭遇难度 | 降低本回合来袭伤害 |
| 机动 | 身法 + 悟性 | 改变距离、保护退路或推进场景目标 |
| 使用蛊虫 | 由蛊虫数据指定 | 消耗真元并应用效果 |
| 使用物品 | 无判定或物品指定判定 | 治疗、恢复真元、布置道具 |
| 撤退 | 身法 + 根骨 | 成功结束战斗并进入撤退结果 |

攻击结果：

| 结果 | 敌方生命/目标进度 | 玩家承受 |
| --- | --- | --- |
| 完美成功 | 35 伤害或目标进度 +2 | 0 |
| 成功 | 25 伤害或目标进度 +1 | 0 |
| 部分成功 | 12 伤害或目标进度 +1 | 12 反击伤害 |
| 失败 | 0 | 20 反击伤害 |

防御结果：

| 结果 | 本回合来袭伤害 |
| --- | ---: |
| 完美成功 | 0，并获得下一回合行动准备 +10 |
| 成功 | 降低 20 |
| 部分成功 | 降低 10 |
| 失败 | 不降低 |

伤害最低为 0。敌人脚本可以把基础反击伤害改为 `10/20/35`，但必须在遭遇数据中显式声明。伤害、真元和目标进度在回合结束时同时结算，避免先后顺序改变结果。

遭遇难度基准：

| 对手 | 难度 |
| --- | ---: |
| 学堂普通同窗、普通野兽 | 60 |
| 一转成熟蛊师、狼群精英 | 75 |
| 一转巅峰或二转普通蛊师 | 90 |
| 白凝冰试招、极端灾变节点 | 105 |

战斗结束条件按优先级检查：

1. 玩家完成全部必要场景目标。
2. 敌人生命归零或按剧情撤离。
3. 玩家撤退成功。
4. 玩家生命归零。
5. 达到回合上限，进入遭遇脚本的超时结果。

Q05 等目标战不要求击败白凝冰；只按退路、队员和撤退信号结算。

### 6.4 生命、伤势与战败

`player.health` 范围为 `0–100`。战斗结束后按生命派生伤势，剧情指定了更严重伤势时取更严重者：

| 生命 | 伤势 |
| ---: | --- |
| 61–100 | 无 |
| 26–60 | 轻伤 |
| 1–25 | 重伤 |
| 0 | 濒死 |

伤势效果：

- 轻伤：根骨和身法相关判定 -5。
- 重伤：所有判定 -10，不能发起 2 AP 长行动。
- 濒死：停止行动并进入遭遇结算。

非致命遭遇中生命归零时，生命固定为 1，结算为战败；默认损失 `min(5, 当前元石)` 和本遭遇行动准备，场景另有明确战败代价时使用场景值且不叠加默认损失。致命遭遇中生命归零时依次检查青藤护符和命薄福浅，均不可用才进入读档。每个遭遇数据必须声明 `lethality = nonlethal / lethal / rollback`。

治疗不会自动消除更高一级剧情伤势：生命恢复到阈值以上后，还需一片生机叶、一天正常休息或治疗场景解除伤势标记。

考核后方源根据已知事实形成第一项认知。前十日的事件只能向
`npc.fang_yuan.cognition_weights` 中五个固定类别加权，不能写入

`npc.fang_yuan.cognition_weights` 只保存剧本事件直接写入的基础权重，归类时不得把
未来事实与幸运收益的派生增量回写到该映射。每次调用都从基础权重重新生成局部变量：

```text
effective_weights = copy(npc.fang_yuan.cognition_weights)
effective_weights.ordinary = max(1, effective_weights.ordinary)
effective_weights.informed =
    effective_weights.informed + npc.fang_yuan.future_fact_exposure * 2
if player.lucky_gain_value >= 20:  effective_weights.lucky += 1
if player.lucky_gain_value >= 100: effective_weights.lucky += 1
if player.lucky_gain_value >= 300: effective_weights.lucky += 1

其余事件只向持久化的基础权重写入 competitor / informed / lucky。
从 effective_weights 取最高权重写入 cognition。
平局优先级：competitor > informed > lucky > ordinary。
丢弃 effective_weights，不回写派生增量。
```

`unknown_variable` 不参加第 10 日自动归类，只能在后续出现无法同时由
`competitor` 或 `informed` 解释的可验证行为时由专门场景直接写入；一旦写入，
普通权重重算不能把它降回其他类别。第 10 日对话选项写入新基础权重后，再执行一次
同样的纯计算归类函数并保存最终值；无论调用多少次，同一存档状态都必须得到同一结果。

### 10.3.1 目标与窗口

### 10.3.3 四条路线

| 路线 | 核心行为 | 主要收益 | 主要风险 |
| --- | --- | --- | --- |

| 栽赃夺利 | 制造假证据或杀人夺物 | 快速获得赃物 | 极高证据与追捕风险 |

第 14 日按以下优先级确定贾金生命运：

1. 玩家直接杀人或在致命护送战中弃置他：`dead`。
2. 合法路线且护送成功：`alive`，随第 15 日商队离开。
3. 玩家准备藏身点且贾金生服从：`missing`；第 15 日食物和藏身点都有效时转为 `alive`，否则被发现并转为 `disgraced`。
4. 玩家在事件前公开私货：`disgraced`。
5. 其余情况走原作结果：`dead`，尸体或死亡证据在第 15 日被发现。

`quest.q03.player_framed=true` 是玩家案件状态，不是贾金生的命运，可以与上述任一命运和路线同时存在。

### 10.3.5 场景 Q03-S2：警告

玩家使用原作信息警告贾金生：

```text
[ACT] “今晚别跟方源单独走。他不是来和你谈酒虫价格的。”
[NPC:贾金生] “你怎么知道他约我？”
```

选择：

- 说自己偷听到：必须先取得地点、时间和一名目击者中的两项；不足两项时选项置灰。
- 说方源委托自己传话：方源警觉 +10，贾金生恐惧 +10。
- 展示一项可验证证据：贾金生恐惧 +20。
- 拒绝解释，只给他逃生路线：贾金生依赖 +10；`fear >= greed +20` 时照路线行动，否则拒绝并继续原定行程。

保护是否成功：

```text
保护强度 =
贾金生恐惧
+ 玩家提供的可验证证据 * 15
+ 护送准备
- 贾金生贪欲
```

护送准备按已完成的藏身点和不在场证明计算：都没有为 0，一项为 10，两项为 20。

- `>=40`：贾金生接受保护。
- `10–39`：他表面答应，仍私自赴约。
- `<10`：他把警告卖给方源或贾富。

### 10.3.7 场景 Q03-S4：案件结果

- 一片恢复 25 生命；恢复后生命达到 26 以上时可同时解除重伤标记，达到 61 以上时可解除轻伤标记。
- 第 1–25 日每片按 5 元石出售；第 26 日后药堂按 8 元石收购，每出售一片使 `quest.q04.medicine_suspicion +5`。
- 幕间选择“养蛊”时自动获得三片叶，不降低修炼收益。

它是一项持续资源，不是无限免费治疗。

### 10.4.9 失败与替代

- 方源取得：玩家可建立共同经营或在药堂征集时再截胡。
- 药堂取得：玩家可用 5 点家族功绩兑换一片生机叶，但不能再得到蛊虫。
- 伪造继承失败：玩家公开暴露 +15，仍可直接盗取。
- 第 24 日未取得：实物永久关闭，保留已获得生机叶。

### 10.4.10 结算

玩家取得并洗去标记：

- 获得九叶生机草。
- 解锁治疗和生机叶经济。
- `source_sync -8`。
- 方源若确认归属，警觉 +12。

共同经营：

- 每幕稳定获得三片生机叶。
- 不占蛊虫喂养位。
- 方源保有最终处置权。

上缴药堂：

- 家族功绩 +25。
- 获得一次 `ITEM_MEDICINE_PROTECTION`，可将第 26–28 日一次家族扣押或征用判定降一级，使用后销毁。
- 获得三片生机叶。
- 永久失去蛊虫。

## 10.5 Q05《青书的死局》

### 10.5.1 目标与窗口

目标：在古月青书迎战白凝冰前建立足够信任、取得可信预警并准备撤退手段，最终选择救他、替代他、利用他或旁观原作结果。

窗口：

- 第 9 日：`family_secret=旧任务遗物` 时，调查任务牌提供第一个入口。
- 第 20 日：青书招募，正式开启。
- 第 21–24 日：信任、证据和物资准备。
- 第 25 日：最终结算。

建议成本：`6–8` 行动。

### 10.5.2 状态

```text
quest.q05.state
    locked / recruited / warning / prepared / final_mission / completed / failed
quest.q05.evidence_flags
quest.q05.preparation_flags
quest.q05.evacuated_members
quest.q05.casualty_records
quest.q05.betrayal_trace

qing_shu.warning_evidence       0–3
qing_shu.retreat_preparation    0–3
qing_shu.fate
    original / warned / saved_stable / saved_costly / replaced / betrayed / dead
```

三项有效预警：

1. 狼群路线：证明原定任务区已受狼群影响。
2. 白凝冰战力与十绝体线索：证明普通任务配置无法应对。
3. 任务路线泄露：证明白家寨或其他人已知晓青书小组路线。

未经验证的原作提示只算“担忧”，不算证据。

### 10.5.3 路线

| 路线 | 前置 | 结果 |
| --- | --- | --- |
| 救下青书 | 信任 40、证据 2、撤退准备 2 | 青书重伤生还，提供离山掩护 |
| 顶替任务 | 证据 2 或家族功绩 20 | 玩家承受白凝冰试招，青书留寨 |
| 共同赴险 | 信任 10、战斗准备 | 高风险合作战，可现场救援 |
| 利用死局 | 掌握路线 | 卖情报、抢战功或取遗物 |
| 保留原作 | 无 | 青书按原路线死亡 |

### 10.5.4 场景 Q05-S1：外勤招募

```text
[NPC:古月青书] “你的手段不太像家族教出来的，但你知道什么时候该停。狼越来越多，我需要能活着把消息带回来的人。”
```

选择：

- `[ACT] “我加入，但我要先看完整路线。”`
  - 青书信任 +3，获得任务地图。
- `[ACT] “每次任务三块元石。”`
  - 获得固定报酬，信任不变。
- `[ACT] “你最后会死在白凝冰手里。”`
  - 没有证据时青书怀疑 +10。
  - 有一项证据时开启预警对话。
- `[ACT] 拒绝。`
  - 可在第 24 日通过白凝冰事件重新开启，但少一次建立信任的机会。

第一次任务后：

```text
[NPC:古月青书] “你撤得很快。”
[ACT] “活着才能把消息带回来，这是你说的。”
[NPC:古月青书] “记得就好。只是有些时候，消息和带消息的人，只能回来一个。”
```

### 10.5.5 场景 Q05-S2：狼群路线

第 21 日侦察退路：

```text
[NAR] 狼群没有朝食物和水源移动，而是在避让一条更强大的气息。原定任务路线恰好穿过它们让出的空白。
[SYS] 获得预警证据：异常狼群路线。
```

选择：

- 立即传信青书：写入 `quest.q05.evidence_flags.wolf_route`，信任 +5。
- 修改地图后交给家族：家族功绩 +5，但不写入青书的有效证据。
- 把安全路线留给自己：逃生准备 +1，不增加青书证据。
- 卖给白家寨联系人：写入 `betrayal_trace=true`，开启背叛路线。

第三类证据“任务路线泄露”可在第 23–24 日花 1 AP 检查任务地图副本：盗道困难；成功取得带白家暗记的副本并写入 `quest.q05.evidence_flags.route_leak`，部分成功只确认副本数量异常并获得下次准备 +10，失败公开暴露 +5。玩家亲自卖出路线时，交易回执也可作为该证据，但会保留背叛痕迹。

### 10.5.6 场景 Q05-S3：白凝冰证据

第 24 日与白凝冰接触后：

```text
[ACT] “白凝冰不是普通二转。他在压制自己的修为，也在找能让他认真出手的人。”
[NPC:古月青书] “你从哪里知道？”
```

玩家必须选择证据形式：

- 展示战斗伤痕和冰道残留：有效证据。
- 交出生成器摘要的世界内转写：悟性困难；成功写入 `quest.q05.evidence_flags.bai_power`，部分成功只增加青书怀疑 +5，失败怀疑 +10。
- 说出北冥冰魄体：若无现场证据，只增加青书怀疑；若已有狼群证据，则计为有效。
- 隐瞒来源：信任不变。

青书有两项证据后：

```text
[NPC:古月青书] “我信你说的危险。可任务不会因为危险消失。你若要我不去，就告诉我谁去，或者让家族相信这条路本身就是错的。”
```

### 10.5.7 撤退准备

每项准备消耗一个行动，最多三项：

- 在路线中藏一片生机叶：消耗一片，写入 `quest.q05.preparation_flags.life_leaf`。
- 设置传信蛊中继：消耗 10 元石或一份青书信任 20 的借用权，写入 `relay`。
- 清理一条避开狼群的退路：身法中等；成功或部分成功写入 `clear_retreat`，部分成功当日疲惫 +1。
- 借来防御蛊：消耗家族功绩 10，或青书信任至少 30 时免费借用，写入 `defense_gu`。
- 安排一支延迟到场的支援队：魅力困难且家族功绩至少 20；成功写入 `support_team`，部分成功队伍迟一回合到场，失败不写入。
- 在白凝冰必经处放置错误任务标记：盗道困难；成功写入 `false_marker`，部分成功同时使白凝冰兴趣 +10，失败不写入。

`qing_shu.retreat_preparation` 是上述不重复旗标数，最高为 3。达到两项才满足稳定救援条件。只有证据没有退路时，青书会更谨慎地赴死，而不是自动生还。

### 10.5.9 场景 Q05-S5：青书对白凝冰

战斗开始：

```text
[NPC:白凝冰] “原来是你。古月青书，他们说你最像一棵树，站在哪里就不肯动。”
[NPC:古月青书] “树也会倒。倒之前挡住什么，由不得风选。”
```

玩家的战斗目标不是击败白凝冰，而是完成三项中的两项：

- 保持退路未被冰封。
- 将两名普通队员撤出。
- 在青书使用木魅蛊前让其接受撤退信号。

战斗最多五回合，难度 105，致命性由白凝冰杀意决定。每回合白凝冰兴趣 +10；兴趣达到 80 时，他会放弃普通队员，专门追击玩家或青书。

目标结算：

- 保持退路：执行一次身法 + 悟性困难机动；有 `clear_retreat` 时难度降为 75。
- 撤出两名队员：固定成员 ID 为 `qing_shi` 与 `xiao_lan`。每次成功机动由玩家明确选择撤出一人，完美成功一次撤出两人；`support_team` 到场时，若两人均受困则优先撤出小兰，只有一人受困时撤出该人。每次都向 `quest.q05.evacuated_members` 写入具体 ID。
- 接受撤退信号：青书信任至少 40 时进行魅力 + 心性困难判定；有 `relay` 时自动成功。

救援关键：

```text
[NPC:古月青书] “走！”
[SYS] 青书即将催动木魅蛊至不可逆阶段。
```

- 使用生机叶并强行拖离：消耗一片生机叶，根骨 + 心性困难，青书信任按 6.1 作为关系修正；成功救下，部分成功玩家与青书都重伤，失败只能改救队员。
- 启动预设传信，引来支援：需要 `relay`，自动完成撤退信号；同时有 `support_team` 时按逐人规则把具体成员 ID 写入 `evacuated_members`，两人都受困时优先小兰，只有一人受困时撤出该人。
- 挑衅白凝冰转移目标：白凝冰兴趣 60 以上可用，玩家进入两回合、难度 105 的追逐战；撑满即完成“保持退路”。
- 听从命令撤离：青书按原结果死亡，其他人稳定生还。

共同赴险但准备不足：

- 玩家可以救青书或救两名普通队员，不能两者兼得。
- 气运完美成功不会绕过这个选择。

普通队员在战斗开始时写入：

```text
quest.q05.evacuated_members = {}
quest.q05.casualty_records.qing_shi = active
quest.q05.casualty_records.xiao_lan = active
```

战斗结果只允许执行一次逐人原子结算：

- ID 已在 `evacuated_members`：对应记录写为 `safe`，NPC 保持生还。
- 玩家最终改救普通队员或听令撤离：把青石、小兰都写为 `safe`，两人保持生还。
- 玩家优先拖走青书时，仍为 `active` 的青石因维持传信蛊留在冰壁内，写为 `dead`、`npc.qing_shi.alive=false`、`availability=dead`；仍为 `active` 的小兰以止血草蛊护住心脉，写为 `heavy`、`npc.xiao_lan.alive=true`、`injury=heavy`、`availability=medicine_hall`。
- `quest.q05.casualties` 是 `casualty_records` 中 `heavy/dead` 的条目数，禁止再由模糊的“已撤出人数”单独反推。
- 第 26 日快照保存两人的 NPC 状态、`evacuated_members` 与 `casualty_records`；回溯时逐字段恢复，不能只恢复伤亡总数。

顶替路线使用三回合白凝冰试招，难度 105。玩家只需撑满三回合、成功撤退或完成两次机动，不必击败白凝冰；成功进入“玩家顶替并生还”，濒死按致命战处理。保留原作路线直接进入“青书死亡并回收遗物”，不额外进行玩家判定。

[NPC:古月青书] “你把我带回来了。”
[ACT] “你听起来不太高兴。”

代价救援生还：

获得：

- 青书信物。

- 写入 `quest.q05.green_vine_route=true`，在青书生还、信任至少 60 且信物有效时开放 E04；本结果当场不发青藤护符。

- 青书死亡。
- `betrayal_trace=true` 时第 27 日证据被发现，公开暴露 +30。
- 白凝冰兴趣 +10，但不会因此信任玩家。

### 10.5.11 第 29 日回溯修正

若青书第一次灾变中因救援他人再次死亡，玩家可以将其设为唯一改写目标：

- 提前告诉他血湖位置。
- 转移他负责的东墙区域。
- 使用第一次灾变记录指出坍塌时间。

回溯只能修正狼潮中的第二次死亡，不能在玩家此前完全没有完成 Q05 的情况下凭空把原作死亡结果改成生还。

## 11. 奖励、物品与经济平衡

### 11.1 奖励设计原则

青茅山奖励分为四类：

1. **构筑核心**：酒虫、白豕蛊、玉皮蛊、隐石蛊和九叶生机草。它们改变修炼、战斗、探索或经济循环。
2. **路线权限**：贾家通行商令、黑市名册、花酒密道和青书接应。它们改变第 30 日及下一篇章的可用路线。
3. **保命资源**：生机叶、青藤护符和狼潮材料。它们降低失败损失，但不能代替任务条件。
4. **叙事筹码**：账页、影壁记录、青书信物和铁家证据。它们不直接增加伤害，却能改变人物行为和结算。

所有“新手村限定”物品遵守以下规则：

- 第 30 日离开青茅山后，原始取得地点永久关闭。
- 后续篇章可以获得升级材料，不能重新生成已经错过的基础蛊虫、信物或通行权。
- 强奖励解决资源和构筑问题，不代替信任、证据、行动点或人物核心动机。
- 优化玩家可以取得五条支线的主要奖励，但必须承担喂养、暴露、关系和路线选择成本。
- 只有贾案的两项顶级奖励是硬性互斥；其他冲突由行动点、资金和人物反应形成软限制。

### 11.2 携带与喂养

- 玩家有八个普通行囊格；同类消耗品最多十件一格。
- 任务证据不占格，但带有“赃物”标记的证据会增加搜查风险。
- 已炼化蛊虫收在空窍中，不占普通行囊格。
- 每只蛊按“每日”“每幕”或“特定触发”消耗食料。
- 幕间没有满足喂养条件的蛊进入 `dormant`，不会死亡；补足一次食料后恢复。
- 幕间计划“养蛊”可免除一只蛊下一幕的食料消耗。
- 袖囊蛊额外提供四个行囊格，并允许隐藏一件带赃物标记的物品。

### 11.4 合炼与重复收益

**白玉蛊**

- 前置：已炼化白豕蛊和玉皮蛊、炼道 45，或支付商队蛊师 30 元石。
- 合炼结果：二转防御蛊，保留一猪之力，将玉皮防御效果提高至每场两次。
- 失败：两只蛊进入 `dormant` 一个关键日，不销毁限定奖励。

**隐鳞蛊**

- 前置：隐石蛊、第 23 日商队材料、炼道 50 或 40 元石代炼费用。
- 效果：非战斗潜行 +20；第一次脱离战斗判定 +15。
- 限制：移动、攻击或强光照射会解除隐匿。

**四味酒虫路线**

- 前置：酒虫、第 23 日收集四种酒、二转修为、炼道 55，或支付商队蛊师 50 元石代炼。
- 成功：获得四味酒虫，二转期间真元质量提高一个小层次。
- 失败：损失四种酒材，酒虫保留；材料不足或尚未二转时，配方与已取得材料继承到下一篇章。
- 错过基础酒虫者不能只凭配方补出四味酒虫，必须走其他修炼构筑。

重复取得同类奖励时：

- 同名唯一蛊不能生成第二只。
- 重复的蛊虫奖励改为该蛊一幕食料；重复的路线凭据改为 20 元石；重复的 NPC 信物改为对应 NPC 信任 +10；重复证据只给下一次相关判定情报准备 +10。
- 回溯恢复的是第 26 日快照，不以“再次发奖”的方式恢复物品。

### 11.5 财富不会跳过的门槛

出售癞土蛤蟆后，玩家可以显著减轻修炼和喂养压力，但下列内容不可直接用元石购买：

- 方正、青书、方源或铁若男的信任。
- 贾案有效证据的真实性。
- Q05 的两类证据与两项撤退准备。
- 已被其他人炼化的唯一蛊。
- 已关闭的时间窗和第 30 日后的青茅山入口。

商队一次交易超过 100 元石时记录 `player.merchant_source_check +1`。达到 2 时，贾富或护卫要求解释来源；玩家可用紫金石凭据、合法账目、关系或一次判定解决。失败只冻结高价采购，不没收已经合法取得的元石。

必要资源不足时只提供三项固定兜底：

- 第 25 日前可向禾娘借最多 10 元石，章节内归还 12；未还时写入 `player.heliang_debt=12`，商队合法身份判定 +10 难度。
- 执行通用谋生，1 AP 获得 3 元石。
- 对目标商店执行一次盗道困难判定；结果按第 23 日偷取规则。

兜底不会免费生成限定物、证据或任务关系。

## 13. 对话、选项与状态解析规则

### 13.1 场景解析顺序

每个场景按以下固定顺序解析：

1. 检查角色是否存活、可用且位于当前场景。
2. 检查日期、任务阶段和一次性事件标记。
3. 检查硬条件：物品、证据、修为、已知事实和路线。
4. 读取角色当前目标，再读取信任、怀疑、警觉和认知。
5. 生成可见选项和带条件的灰色选项。
6. 玩家确认行动后扣除行动点或资源。
7. 执行必胜条件或一次固定种子的判定。
8. 原子写入对白结果、状态变化、物品和下一节点。

同一场景读档后的随机种子保持不变。玩家改变装备、情报、同伴或行动准备后，种子才重新生成，避免无成本反复读档刷点数。

### 13.2 选项可见性

- 普通行动直接显示。
- 玩家知道目标但条件不足时，显示灰色选项和缺失条件。
- 只有深度查询、人物已知事实或对应天赋才能发现的行动，在条件满足前完全隐藏。
- 元叙事标签只出现在 UI，例如“截胡酒虫”；世界内执行文本必须改写为合理行为。
- 选择一旦进入判定或播出第一句承诺性对白，就视为已提交，退出场景不能返还行动点。

### 13.3 结果文本顺序

每次选择的反馈顺序固定为：

```text
[ACT] 玩家在世界内的实际行为或对白。
[NPC] 角色即时回应。
[NAR] 可观察结果。
[CHECK] 判定与关键修正来源。
[EFFECT] 数值、物品、关系和任务状态。
[SYS] 仅玩家可见的原作偏移或新节点。
```

部分成功必须同时给出“已经得到什么”和“因此付出什么”。失败不能只显示“失败”，至少提供新信息、替代入口、关系变化或可追回状态中的一项。

## 14. 第 30 日结局与存档继承

第 30 日先检查玩家拥有的全部逃生路线，再由玩家主动选择。路线判定失败时可以改选尚未使用的路线；只有全部路线不可用或失败后才进入紧急流亡。

继承：贾家委托、价格优惠和合法身份；若铁家证据过高，下一篇章增加一次身份复核。

#### E02《帐外之人》

前置：黑市名册、袖囊蛊或仍有效的走私货箱。

```text
[NAR] 货车没有停。车底垂下一条绳，你抓住它，被尘土和夜色一同拖出山口。
[NPC:黑市接头人] “别问车去哪里。能在天亮前离开这里，就是第一笔买卖。”
[SYS] 章节身份：灰色商路。
```

继承：黑市渠道和藏匿能力；贾家关系 -20，铁家案件保留追查标记。

#### E03《花酒余路》

前置：花酒密道图且入口未在修正行动中被封死。

```text
[NAR] 身后的石门被震塌，酒香、血腥味和山寨的火一起隔在岩层另一侧。密道尽头第一次吹来不属于青茅山的风。
[SYS] 已携带行囊上限：普通路线 +2。
[SYS] 章节身份：遗藏继承者。
```

继承：额外带走两格物品、花酒行者外部线索；密道永久坍塌，不能回头取物。

#### E04《青藤余脉》

前置：`quest.q05.green_vine_route=true`、青书生还、信任至少 60、青书信物有效。

```text
[NPC:古月青书] “西坡还有一队人。送他们过界碑后，我们各自散开。”
[ACT] “你还把这当任务？”
[NPC:古月青书] “山寨没了，答应过要带回去的人还在。”
[SYS] 章节身份：古月遗民。
```

继承：古月遗民关系、一次安全接应和最多一枚青藤护符；稳定救援路线沿用已经取得的护符，不重复发放；顶替路线此前未取得时在本结算补发。青书重伤，下一篇章前半段不可入队。

#### E05《同路不同行》

前置：掌握方源路线、其警觉低于 80，且玩家没有携带其必须争夺的逃生资源。

```text
[NPC:方源] “同行到山外第一处分岔。”
[ACT] “然后呢？”
[NPC:方源] “然后你最好已经想好，什么东西值得让我回头。”
[NAR] 你们一前一后离开火光，没有人把后背真正交给另一个人。
[SYS] 章节身份：无登记流亡者。
```

继承：获得方源下一阶段路线情报；双方不成为队友，警觉和认知完整保留。

#### E06《负伤出山》

前置：无。这是主线兜底。

```text
[NAR] 你沿着没有标记的山涧向下。身后是狼群，脚下是碎石，行囊在第三次跌倒时裂开。
[SYS] 选择两件非绑定物品遗失。
[SYS] 伤势：重伤。
[NAR] 天亮时，青茅山已经被云遮住。地图没有出现返回箭头。
[SYS] 章节身份：孤身流亡者。
```

继承：保留绑定物、蛊虫和主线资格；失去两件由玩家选择的非绑定物品，并以重伤开始下一篇章。

### 14.3 结局修饰卡

每条已接触的支线生成一张结算卡：

| 支线 | 最佳卡 | 普通卡 | 失败卡 |
| --- | --- | --- | --- |
| Q01 | `杯中异虫`：玩家持有酒虫 | `各取所需`：与方源交易或共享线索 | `酒香已散`：酒虫归方源或家族 |
| Q02 | `遗藏后来者`：深层遗藏与密道 | `一室之得`：取得至少一项蛊或记录 | `山门合拢`：入口坍塌、无实物 |
| Q03 | `商路有名` 或 `帐外有名` | `未结之案`：保留证据或人情 | `证据指向你`：下一篇章追查 |
| Q04 | `生机自养`：持有九叶生机草 | `三叶之约`：共同经营或药堂兑换 | `药田易主`：只保留已得生机叶 |
| Q05 | `青藤未折`：青书生还 | `替他走完`：玩家顶替并生还 | `木魅残蜕`：青书死亡或背叛 |

人物卡至少包括：方源认知、方正关系、青书生死、贾金生生死、铁家追查、白凝冰兴趣。没有发生过有效互动的人物不强行生成评价。

### 14.4 永久继承

永久章节存档保留：

- 姓名、固定外观 ID、Roll 结果、资质、属性、天赋和缺陷。
- 修为、修炼进度、伤势、元石、蛊虫、食料和允许带出的物品。
- 五条支线结果、NPC 生死、关系、证据和方源认知。
- 生成器偏移日志、第一次灾变记录和回溯成就。
- 选择的章节身份与后续委托入口。

章节结束时清除：

- 青茅山本地行动点、临时准备、未完成委托和无效地点标记。
- 已经坍塌地点的导航入口。
- `combat_interest_delta`、临时仇恨和只在单场战斗生效的增益；`bai_ning_bing.interest` 等持久人物状态保留。

下一篇章的原作同步率为：

```text
next_source_sync = min(90, current_source_sync + 15)
```

恢复值来自生成器重新索引后续原文；已经确认的偏移和人物记忆不会因此撤销。

### 14.5 不可返回规则

写入 `world.village_destroyed=true` 后：

- 青茅山地图变灰，不再接受快速旅行、任务追踪或存档传送。
- 所有未取得的青茅山限定奖励写入 `missed_permanently`。
- 任务日志保留失败原因和最后可取得日期。
- 任何后续剧情只能访问遗民、废墟消息或外部线索，不能重新开放完整新手村。

### 15.3 原子结算

一次选择的资源扣除、判定、对白标记、任务迁移和发奖必须在同一事务中完成。任一步骤失败时回到选择提交前，不能出现：

- 行动点扣除但场景未推进。
- 奖励已发放但任务仍可重复结算。
- NPC 已死亡却继续占用后续对白。
- 合法商令和黑市顶级奖励同时存在。

### 15.4 NPC 缺席替代

关键功能与具体人物分离：

| 缺席人物 | 原功能 | 替代者或替代方式 |
| --- | --- | --- |
| 贾金生死亡或未接触 | Q03 私货入口 | 酒帐伙计、未登记货箱或贾富调查 |
| 贾富不可用 | Q03 初次结算 | 商队账房；只发临时凭据，第 27 日再正式结算 |
| 青书在第 25 日前死亡 | Q05 外勤队长 | 青书副手接手队伍，但“青书生还”奖励关闭 |
| 方正拒绝交谈 | 学堂与家族内部信息 | 同窗流言或学堂档案，成本更高 |
| 方源避开玩家 | 原作节点观察 | 现场痕迹、生成器索引或第三方目击 |

替代路径保证主线信息可获得，不保证原人物的关系奖励和唯一信物。

### 15.5 回溯数据

第 26 日清晨创建完整世界快照，包括：

- 玩家物品、蛊虫、元石、伤势和位置。
- 所有 NPC 生死、关系、目标和知识。
- 五条支线状态及奖励互斥锁。
- 场景损坏、狼潮路线、证据归属和逃生准备。

第一次灾变期间另写入不回溯层：

```text
rollback.external_memory.observed_events
rollback.external_memory.death_records
rollback.external_memory.lost_items
rollback.external_memory.fang_yuan_actions
rollback.external_memory.evidence_tamper_trace
rollback.external_memory.action_records.day26
rollback.external_memory.action_records.day27
rollback.external_memory.action_records.day28
rollback.first_disaster_seen = true
```

回溯执行顺序：

1. 冻结第一次灾变操作。
2. 提取外部记忆与成就。
3. 恢复第 26 日完整快照。
4. 重新附加外部记忆。
5. 锁定一个修正目标。
6. 自动重演第一次记录中的普通行动，为第 26、27、28 日各提供一次替换或插入修正。
7. 按修改后的状态重新运行第 29–30 日。

不回溯层只能提供情报和修正权限，不能直接携带第一次灾变获得的元石、物品、关系或案件矛盾，防止复制奖励。第一次灾变的证物开封痕迹不会注入第二轮第 27 日；若玩家把证据设为唯一修正目标，该记录只为第 26–28 日消证判定提供日志修正。第二轮实际留下的新痕迹在产生当刻直接改变证据，不再回填已经锁定的第 27 日矛盾集合。

## 16. 失败、冲突与异常兜底

### 16.1 主线不可断

- 当日自由行动点用完后，强制世界事件照常发生。
- 玩家没有炼化月光蛊时，第 4 日由学堂提供一次强制辅导，获得疲惫和功绩惩罚后继续。
- 玩家错过酒虫时，Q02 仍可通过尾随方源、调查酒香落点或家族封锁记录开启。
- 玩家没有元石时，必要消耗提供谋生、抵押、欠债或高风险偷取路径。
- 五条支线全部失败时，第 30 日仍可使用紧急流亡。
- 任何逃生路线判定失败都先回到路线选择，全部耗尽后才进入 E06。

### 16.2 唯一物品冲突

- 唯一蛊同一时刻只能有一个世界持有者。
- 转移物品时先移除原持有者，再写入新持有者。
- NPC 已炼化的蛊不能仅靠偷窃判定直接转移，必须先满足解除炼化、交易或击败条件。
- 贾家通行商令与黑市顶级奖励使用同一互斥键 `quest.q03.final_reward`。
- 选择合法商令前必须交回袖囊蛊、未登记货物和黑市名册原本；不愿交回时合法选项保持锁定。
- 选择黑市顶级奖励会销毁临时路签并使尚未正式发放的商令失效；已经写入永久互斥键后不能改选。
- 章节存档只保存当前分支选择；不同手动存档可以各自拥有不同结局，不视为同一存档兼得。

### 16.3 方源行为约束

即使 `fang_yuan.alert=100`，也不能自动发生：

- 无条件偷取玩家无关物品。
- 为泄愤破坏玩家与其他 NPC 的任务。
- 在没有生存收益时公开玩家秘密。
- 放弃自身当前目标长期追杀玩家。

若脚本要求方源反制，日志必须记录至少一个触发原因：`goal_conflict`、`survival_threat`、`direct_attack`、`frame_attempt` 或 `escape_competition`。没有原因时只允许观察、试探、隐瞒和拒绝合作。

### 16.4 青书救援硬条件

稳定救下青书必须同时满足：

```text
qing_shu.trust >= 40
qing_shu.warning_evidence >= 2
qing_shu.retreat_preparation >= 2
```

此外，战斗中必须完成三项目标中的两项：

- 退路未被冰封。
- 两名普通队员撤出。
- 青书接受撤退信号。

随机判定只能决定代价和执行质量，不能绕过任何一组硬条件。条件不足时，即便判定完美，也只能在“救青书”与“救普通队员”之间选择。

### 16.5 低同步率

- 同步率下降只减少未来预测，不删除已经确认的事实。
- 强制世界事件、已开放任务和玩家已知选项不会因同步率下降而消失。
- 生成器不得在低同步率时提供错误事实冒充原文；所有推测必须标注“推演”。
- 同步率为 0 时，玩家仍能依靠现场调查、关系和外部回溯记忆通关。

### 16.6 死亡与读档

- 普通日期生命降至 0：进入玩家读档界面。
- 第 29 日第一次灾变生命降至 0：先播放死亡记录，再由非玩家回溯接管。
- 青藤护符只对一次物理致命伤自动触发，不在普通伤害上浪费。
- 没有可用存档时，系统保留当日清晨自动存档。
- 第 30 日成功离山后创建永久章节存档；读取第 30 日前存档仍可重玩，但不能覆盖已经选定的永久存档，除非玩家明确确认。

### 16.7 文本和输入异常

- 姓名为空时使用默认名“古月砚”。
- 姓名只改变称呼，不改变固定男性立绘、同届身份和角色代词。
- 角色死亡、失踪或关系断绝后，系统不得播放其普通问候对白。
- 同一句状态对白一个幕内只播放一次；重复交互改用短句或直接进入功能菜单。
- 所有灰色选项必须给出真实缺失条件，不得用“剧情尚未开放”掩盖可理解的门槛。

## 17. 验收标准与测试矩阵

### 17.1 内容验收

- 30 个关键日全部有强制世界事件、自由行动入口和日终状态。
- 主线从身份生成连续到永久离山，不依赖任一支线成功。
- 五条支线均有开放、进行、成功、失败、过期和至少一种补救。
- 所有核心角色都有动机、状态变量、关系变体和结局去向。
- 所有关键选择都有世界内行动文本、结果和状态效果。
- 文档内不存在未完成标记、空白对白或未定义规则。
- 新增对白为原创，不复制小说原文段落。

### 17.2 规则验收

- 每个关键日第一次经历时恰有三个自由行动点，强制世界事件不扣点；第 29 日后的压缩重演只使用三次修正行动。
- 普通失败不会让主线死锁。
- 酒虫和紫金石活蛊只有一个持有者。
- 同一存档不能兼得贾家通行商令与黑市顶级奖励。
- 方源高警觉时仍只在五类明确触发原因下主动反制。
- Q05 不能靠一次高点数绕过信任、证据和撤退准备。
- 第 29 日只保留外部记忆，不复制第一次灾变的物品和数值。
- 第 30 日至少存在紧急流亡路线。
- 离山后新手村和全部未取限定奖励永久关闭。

### 17.3 建议验证存档

| 存档 | 玩法目的 | 必须验证 |
| --- | --- | --- |
| A：首次保守玩家 | 少查攻略，优先主线与关系 | 3–4 条支线自然完成；约 3–4 小时；可合法或紧急离山 |
| B：全收集优化 | 精确安排全部行动与幕间 | 五条支线主要结算均可完成；硬互斥仍生效 |
| C：方源竞争者 | 抢酒虫、遗藏和逃生资源 | 警觉快速上升；只在目标重叠时遭到反制 |
| D：黑市玩家 | 走私、伪证和灰色商路 | 袖囊蛊、名册、铁家证据与黑市结局正确联动 |
| E：青书救援 | 集齐两类证据和两项准备 | 青书生还；缺任一硬条件时不能被幸运点数救下 |
| F：全面失败 | 浪费行动、错过所有限定物 | 主线仍推进；E06 可用；日志明确列出永久错过内容 |
| G：回溯校验 | 第一次灾变收集物品并死亡 | 快照恢复、外部记忆保留、物品不复制、仅一项结果可修正 |
| H：低同步率 | 大量截胡使同步率降至 0 | 不再预测具体原作行动，但调查和主线仍可完成 |

### 17.4 时长目标

- 强制主线阅读与选择：约 70–90 分钟。
- 三条常规支线：约 60–75 分钟。
- 战斗、探索、养成与幕间：约 50–75 分钟。
- 首次通关目标：3–4 小时。
- 全支线优化通关可超过 4 小时，但不得要求重复刷取随机掉落。

## 18. MVP 边界与制作交接

### 18.1 本版明确不做

- 性别、脸型、发型、肤色、身高或立绘模板选择。
- 恋爱线、成人内容和后宫关系。
- 独立的方源敌意条或无条件追杀 AI。
- 青茅山之外的完整可玩地图。
- 第三章及以后蛊虫体系、交易所和长期阵营模拟。
- 无限返回新手村、周目继承限定物或付费补领。

### 18.2 美术与表现需求

本节是最终集成验收，不扩大第一份实现计划的资产制作范围。第一份实现计划使用现有角色状态图和现有通用资源，不新生成整套 NPC 立绘或音频。

- 玩家角色：一套固定男性半身立绘、一套 Q 版地图角色。
- 立绘状态：常态、警觉、轻伤、重伤。
- 核心 NPC 至少提供常态、戒备、受伤三个表情或状态。
- 第 29 日回溯必须使用声音先消失、画面褪色、物体逆向复原的统一演出语言。
- 第 30 日地图节点变灰后不再显示可点击高亮。

### 18.3 内容来源边界

本规格保留青茅山篇的原作功能节点、人物动机和已知事件次序，在其间加入玩家身份、可交互分支、原创对白、回溯记忆与替代结果。所有新增对白均为游戏原创，不应在制作时替换成小说长段原文。

原作事实与生成内容在数据中分别标记：

```text
origin = source_anchor
origin = generated_branch
origin = player_caused_divergence
```

当实现内容与本规格冲突时，以本规格的硬条件、互斥关系、主线兜底和不可返回规则为准；对白可以在不改变人物动机与状态效果的前提下润色。

### 18.4 完成定义

青茅山 MVP 只有在以下内容同时可用时才算完成：

- 角色创建与 Roll。
- 30 日主线。
- 5 条支线。
- 全部核心对白和状态变体。
- 判定、行动点、幕间、物品、喂养与关系系统。
- 第 29 日非玩家回溯。
- 6 条离山结局和永久章节存档。
- 新手村限定奖励永久锁定。
- 本章验收矩阵全部通过。

### 18.5 实施里程碑与边界

本规格是一份完整内容基线，后续实施计划必须按依赖顺序拆成五个可独立验收的里程碑，不能把它们混成一个无法验证的大提交：

| 里程碑 | 范围 | 明确产物 | 验收出口 |
| --- | --- | --- | --- |
| M1 核心运行时 | Roll、状态字典、判定、AP、修炼、战斗、物品与关系 | 可用测试事件驱动全部核心规则 | 规则单元测试通过，不含正式剧情 |
| M2 前半篇剧情 | 序章、第 1–15 日、Q01、Q03 第一轮 | 数据化事件、对白、存档点 | 可从新游戏玩到贾富封市 |
| M3 后半篇剧情 | 第 16–25 日、Q02、Q04、Q05 | 遗藏、九叶、青书完整分支 | 五支线成功/失败路径均可达 |
| M4 覆灭与持久化 | 第 26–30 日、回溯、六结局、章节存档 | 快照、外部记忆、结局卡 | 无复制漏洞，永久离村生效 |
| M5 表现与验收 | 现有立绘接入、回溯表现、地图锁定、完整矩阵 | 可发布的青茅山 MVP | 17 章全部验收通过 |

第一份实施计划覆盖 M1–M5，但每个里程碑必须分别验收后再进入下一个。M5 只接入已有资产并完成表现，不包含重新绘制全部 NPC 或制作正式配音；新的资产生产需另立规格。

“下一篇章继承”在本 MVP 中只写出一份版本化存档数据，不实现青茅山之外的地图、任务或角色 AI。后续篇章读取该数据属于下一份规格。
