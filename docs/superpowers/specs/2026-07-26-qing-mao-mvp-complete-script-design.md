## 1. 文档职责

本文定义青茅山精简 MVP 的剧本结构、场景格式、章节顺序、角色替代、即时结算与验收。

规则冲突时依次服从：

1. 唯一规则源；
2. 本规格；
3. 单个生产场景。

本版完整替换旧剧本规格。

停用项集中列在生产包 `README.md` 包头，正文与场景不再引用。

本文不修改运行时代码、JSON Schema 或隐藏路径算法。

## 2. 一句话体验

玩家作为古月山寨同届少年开窍、养蛊、探索青茅山，在方向旅行中发现地点和机缘，在 `8×6` 棋盘争夺资源，并于狼潮终局直接选择离山方向。

原著资料负责初始化世界和提供查询。

当前世界只接受已经发生的游戏行动。

玩家可以随时：

- 探索；
- 休息；
- 训练；
- 夜间修炼；
- 整理空窍；
- 整理行囊；
- 炼制；
- 查看原著资料；
- 处理可选机缘。

这些活动不会让主线章节失效。

## 3. 制作规模

MVP 制作：

- 一条 `Day 0..30` 主线；
- 三十一个连续主场景；
- 五条以内可选机缘；
- 十三个可选机缘场景；
- 一组常驻短对白；
- `1v1` 为主、少量 `1v2` 的格子战斗；
- 三个直接可选的离山方向。

MVP 不制作多队伍战术、四转及以上蛊虫取得流程、长篇分支结局树、自动运行的 NPC 日程、章节截止时间或强制完成的可选内容。

## 4. 章节标签

`Day 0` 到 `Day 30` 只表示章节顺序。

标签不读取现实时间、游戏内昼夜次数、休息次数、野外步数或可选内容完成数量。

章节只在当前主场景完成后增加一位。

自由活动保持当前章节。

读档恢复保存时的章节。

已经结算的场景不重复发放奖励。

## 5. 主线任务

主线实例只需要：

```text
status
currentStepId
nextStepId
```

`status` 只取：

- `inactive`
- `active`
- `completed`

进入 `D00-S01`：

```text
status = active
currentStepId = D00-S01
nextStepId = D01-S01
```

完成一个主场景时：

1. 发放即时奖励。
2. 标记当前场景完成。
3. 把当前 ID 切换为原下一 ID。
4. 写入新的下一 ID。
5. 保存。

完成 `D30-S01`：

```text
status = completed
currentStepId = D30-S01
省略 nextStepId
```

任务 UI 只显示：

- 当前步骤标题；
- 下一步骤标题；
- 是否完成。

## 6. 场景字段

每个场景只按以下顺序书写：

```text
场景 ID
地点
角色
当前目标
简短对白
选项
地图/旅行/8×6 战斗交互
即时奖励
下一场景
```

### 6.1 场景 ID

主线：

```text
D00-S01 .. D30-S01
```

主线场景 ID 同时就是注册后的主线 `questStepId`，不再维护第二套
`step_qm_*` 别名。

可选机缘：

```text
Q01-S01 .. Q05-S03
```

常驻对白：

```text
R-{角色缩写}-{两位序号}
```

ID 进入制作后不得复用。

### 6.2 地点

只写当前镜头可见区域。

方向旅行写入口和抵达地点。

地点名称不能代替旅行交互。

### 6.3 角色

只列实际出镜角色。

主角统一写“玩家”。

方源出场时，在同一行写通用缺席替代。

不出镜角色不写幕后行动。

### 6.4 当前目标

目标只用一句可操作文本。

推荐动词：

- 前往；
- 交谈；
- 选择；
- 击败；
- 撤离；
- 捕捉；
- 领取；
- 离山。

一个场景只有一个当前目标。

### 6.5 简短对白

主场景写两到六句。

可选场景写两到八句。

单句尽量不超过三十个汉字。

对白只表达当前直接意图。

所有台词必须为项目原创。

### 6.6 选项

一个场景使用零到三个选项。

选项文本只写玩家要做的事。

选择后立即得到结果。

主场景中的多个选项汇合到同一下一场景。

### 6.7 交互

只写本场实际使用的交互：

- 地图靠近；
- 前、后、左、右旅行；
- 追踪小游戏；
- 捕捉小游戏；
- 危险探索；
- `8×6` 战斗；
- 无。

交互描述必须足以让关卡和战斗制作直接落地。

### 6.8 即时奖励

场景结束时一次发放。

允许：

- 生命或真元变化；
- 元石；
- 修为进度；
- 普通物品；
- 蛊材；
- 蛊虫；
- 装备；
- Buff 或 Debuff；
- 角色公开状态；
- 地点发现；
- 可选机缘开放或结算。

同一奖励不在后续章节再次确认。

### 6.9 下一场景

主场景指向下一主场景。

可选场景指向本机缘下一场景或返回地图。

`D30-S01` 指向 `END-QINGMAO`。

## 7. 对话

界面只显示：

- 场景背景；
- 当前角色立绘；
- 角色名；
- 台词；
- 最多三个短选项。

选项可以：

- 播放下一句；
- 结束对话；
- 打开商店；
- 打开天骄名册；
- 打开原著资料查询；
- 进入地图；
- 进入战斗；
- 立即获得物品或地点标记。

对话不展示幕后数值。

普通信息对白不消耗资源。

重复对白不重复发放元石、修为或物品。

## 8. 山寨地图

山寨使用近距离交互。

玩家靠近角色后可以看到：

- 交谈；
- 偷盗；
- 交易；
- 切磋；
- 离开。

角色没有某项功能时，不显示对应按钮。

结果在当前地图覆盖层立即显示。

成人角色可以使用直接指定的服装与情绪立绘标签。

地图 Q 版角色只使用基础行走与交互动作。

## 9. 偷盗场景

剧本只调用统一地图流程：

1. 靠近角色。
2. 选择偷盗。
3. 查看当前可取物。
4. 选择一件物品。
5. 进行一次成功或失败判定。
6. 在地图覆盖层显示结果。

成功时：

- 物品进入普通行囊；
- 播放当前场景反应；
- 本次交互结束。

失败时：

- 物品不移动；
- 播放当前场景反应；
- 本次交互结束。

只有场景明确写“失败后立刻开战”时才进入普通战斗。

剧本不显示判定数值。

## 10. 野外旅行

进入野外后只调用隐藏路径系统。

剧本可以指定：

- 起点；
- 初始朝向；
- 目标地点；
- 可用事件槽；
- 抵达后的场景 ID。

剧本不计算：

- 绝对方位转换；
- 可逆历史栈；
- 连续后退；
- 时间收费；
- 第 20 步保底；
- 战斗返回节点；
- 随机游标；
- 事件生命周期。

玩家通过前、后、左、右移动。

方向旅行可以开放机缘入口。

方向旅行不能直接授予机缘最终奖励。

## 11. `8×6` 战斗

### 11.1 棋盘

- 宽 `8` 格，高 `6` 格。
- 左上角为 `(0,0)`。
- 右下角为 `(7,5)`。
- 单位不能重叠。
- 移动只走上下左右。
- 射程使用曼哈顿距离。

### 11.2 玩家回合

每回合：

1. 移动零到一次。
2. 执行一个动作。
3. 结算回合末 Buff 与 Debuff。
4. 敌方按固定顺序行动。

动作可以是：

- 肉搏；
- 已装入空窍的蛊虫主动技能；
- 已组装杀招；
- 防御；
- 使用道具；
- 撤退。

### 11.3 剧本战斗块

每场写明：

```text
battleId
mode
playerSpawn
enemySpawn
obstacles
enemySet
victoryResult
defeatResult
retreatResult
```

`mode` 只取：

- `1v1`
- `1v2`

主线的胜利、失败和撤退都进入下一主场景。

可选机缘可以在失败或撤退后结算为错过。

### 11.4 默认出生点

未特别说明时：

```text
playerSpawn = (1,3)
enemySpawn = (6,3)
enemySpawn2 = (6,1)
obstacles = [(3,2), (3,4)]
```

### 11.5 战斗奖励

| 结果 | 修为进度 |
| --- | ---: |
| 普通战斗胜利 | `+8` |
| 精英或首领战斗胜利 | `+12` |
| 失败或撤退但存活 | `+2` |

一个战斗实例只结算一次。

主线不能用战斗结果决定是否继续。

## 12. 成长与突破

战斗是主要修为来源。

其他来源：

| 内容 | 修为进度 |
| --- | ---: |
| 首次完成危险探索 | `+4` |
| 完成一次训练 | `+3` |
| 选择夜间修炼 | `+2` |

同一主线步骤的训练只结算一次。

夜间修炼完全可选。

修为进度达到 `100` 时出现突破按钮。

点击后直接完成当前境界突破。

三转是本篇上限。

剧本只播放短演出，不增加额外消耗。

## 13. 空窍与蛊虫

主线保证获得月光蛊。

酒虫、九叶生机草等来自可选机缘。

花酒遗藏只提供三转以下蛊虫或蛊材。

战斗前可以整理空窍。

战斗开始后不能从储备换装。

每只低阶蛊最多提供：

- 一个标志性主动技能；
- 一个被动或探索功能；
- 已登记的配方标签。

复杂战斗效果由已登记杀招组合产生。

剧本只引用现有技能与射程模板。

## 14. 世界与原著资料

原著资料初始化：

- 人物；
- 势力；
- 地点；
- 血脉与亲朋关系；
- 主修方向；
- 公开能力；
- 机缘记录。

查询可以检索：

- 人物；
- 时间段；
- 地点；
- 蛊虫或物品；
- 机缘。

查询不消耗玩家资源。

结果标明“原著资料”或“当前世界已确认”。

游戏开始后，当前世界只由已发生行动决定。

角色死亡后保持死亡。

机缘被他人取得后保持已经结算。

## 15. 天骄名册

初始包含：

- 玩家；
- 古月方源；
- 古月方正；
- 古月漠北；
- 古月赤城；
- 白凝冰。

古月青书显示在前辈页。

名册只展示玩家已知的：

- 境界；
- 公开蛊虫；
- 最近公开战绩；
- 当前公开状态。

公开状态只取：

- 活跃；
- 受伤；
- 失踪；
- 离山；
- 死亡。

方源与其他角色使用同一套字段。

## 17. 方源缺席

方源使用普通角色规则。

他可以：

- 受伤；
- 失败；
- 离开；
- 死亡。

场景不得为台词让他重新出现。

通用替代：

| 场景功能 | 替代角色 |
| --- | --- |
| 同届对话 | 同届竞争者 |
| 抢先进入野外 | 无名寻宝者 |
| 提供山路观察 | 巡山蛊师 |
| 商队附近现身 | 商队伙计 |
| 终局远景 | 删除该镜头 |

## 19. 五条可选机缘

可选机缘只记录：

- `inactive`
- `available`
- `resolved`

`resolved` 只表示该内容已经结算。

### 19.1 Q01 月下酒虫

开放锚点：`D05-S01`

场景：

1. `Q01-S01` 酒香指路；
2. `Q01-S02` 三段香痕；
3. `Q01-S03` 花丛捕捉。

玩法：

- 气味方向追踪；
- `3×3` 花格捕捉；
- 一次最终选格。

结果：

- 选对获得酒虫；
- 选错酒虫逃走；
- 主动让出时当前竞争者取得；
- 主动惊散时无人取得。

主线影响：无。

## 20. 可重复对白

常驻对白只提供：

- 当前章节近况；
- 公开战绩；
- 地点方向；
- 训练入口；
- 商店入口；
- 切磋入口；
- 原著资料查询入口。

同一对白可以重复播放。

重复播放不发放成长或物品奖励。

角色死亡、失踪或离山后移除入口。

方源移除后，两个常驻入口由同届竞争者承担。

## 21. 即时结算

生产场景只允许以下简单结果：

```text
addItem
removeItem
addCurrency
addCultivation
addStatusEffect
setCharacterPublicStatus
discoverLocation
openOpportunity
resolveOpportunity
advanceMainStep
save
```

一个场景按书写顺序结算。

同一物品不能重复添加。

同一战斗实例不能重复发放修为。

角色死亡后，后续场景按缺席规则处理。

## 22. 失败与继续

主线对战斗结果采用统一处理：

| 结果 | 场景处理 |
| --- | --- |
| 胜利 | 发放胜利奖励并进入下一主场景 |
| 失败但存活 | 返回入口、发放修为 `+2` 并进入下一主场景 |
| 撤退 | 返回入口、发放修为 `+2` 并进入下一主场景 |

可选机缘失败或撤退可以直接设为 `resolved`。

已经取得的普通物品保持在行囊。

角色存亡结果立即成为当前世界事实。

## 24. 验收

### 24.1 主线

- `D00-S01` 到 `D30-S01` 连续可达。
- 三十一场都写明下一场景。
- 自由活动不改变章节顺序。
- 主线战斗三种结果都继续。
- 最终三个离山方向全部直接可选。

### 24.2 可选机缘

- 总数不超过五条。
- 每条独立结算。
- 每条可以跳过。
- 任一条未完成都不影响主线。
- 方源缺席时相关场景仍可运行。

### 24.3 文本

- 每场最多三个选项。
- 对白为原创短句。
- 每场只使用规定字段。
- 不长篇复述原著。
- 停用项只在生产包包头出现。

### 24.4 系统引用

- 战斗只使用 `8×6` 规则。
- 野外只调用隐藏路径规则。
- 成长奖励采用统一数值。
- 偷盗在当前地图结算。
- 读档不重复发放即时奖励。
