# 《蛊真人：天外盗剧本》群侠传式可玩 Demo 设计

## 1. 已确认方向

首个可玩 Demo 从“地点卡片 + 行动按钮”的文字原型，改为接近原版《金庸群侠传》的 2D 开放式 RPG：

- 玩家在青茅山大地图上自由行走和寻找地点。
- 进入古月山寨后，切换到可行走的局部场景。
- 靠近 NPC、物件和门口后主动交互。
- 任务线索藏在对话、环境、时间窗口和人物行动中。
- 战斗使用小型回合制战棋。
- 文字只用于对话、记忆、调查结果和选择，不再把任务做成一排显式按钮。

地图结构采用“大地图 + 局部场景”。美术采用已确认的第一种复古像素风，视觉参考为：

`assets/concepts/retro-pixel-tavern-reference.png`

## 2. Demo 目标

玩家在 15-25 分钟内完成一个可重复游玩的酒虫争夺闭环，并感受到以下四件事：

1. 这是一款能走动和探索的 RPG，不是网页任务面板。
2. 酒虫不是沿固定按钮顺序领取，而是需要自己发现并拼接线索。
3. 同一目标存在多条路线，失败会改变局势但不会卡关。
4. 方源会随时间行动，玩家截胡酒虫后还要藏匿、炼化并面对试探。

### 2.1 初始状态

| 状态 | 初始值 |
| --- | --- |
| 日期与时间 | 第一日，时间点 `0`（清晨） |
| 玩家位置 | 青茅山大地图，古月山寨外 |
| 生命 / 上限 | `40 / 40` |
| 真元 / 上限 | `20 / 20` |
| 元石 | `6` |
| 修炼进度 | `0 / 100` |
| 盗道等级 | `1`（梁上手） |
| 敏捷 / 洞察 / 谨慎 | `3 / 3 / 2` |
| 方源警觉 | `8` |
| 酒虫归属 | 卖酒商贩 |
| 原著记忆 | 只有“酒香与修炼蛊虫有关”的模糊提示 |

## 3. 可玩范围

### 3.1 地图

Demo 包含六张可行走地图：

1. 青茅山大地图
   - 古月山寨入口。
   - 山林岔路。
   - 隐藏洞口轮廓。
   - 一处蛊兽遭遇点。
   - 自由行走不消耗时间；进入一个命名地点固定推进 `1` 点。

2. 古月山寨街区
   - 通往学堂、酒馆和住处。
   - 卖酒商贩在特定时段出现。
   - 方源会按自己的日程经过。

3. 学堂
   - 学堂执事、同窗和排班木柜。
   - 正常修炼、询问消息、观察守卫、偷取排班。

4. 酒馆
   - 老板、酒客、卖酒商贩、酒坛和后院入口。
   - 酒虫的主要调查与争夺场景。

5. 玩家住处
   - 睡眠推进日期。
   - 藏赃夹层。
   - 炼化蒲团。
   - 存档与整理战利品。

6. 山林战斗场
   - 回合制战棋教学。
   - 用于蛊兽遭遇或酒虫争夺失败后的脱身战。

### 3.2 角色

Demo 使用五个主要角色：

- 玩家：天外盗种，初始掌握实物盗取和原著记忆。
- 方源：独立行动的竞争者。
- 酒馆老板：提供表层消息，可被套话。
- 卖酒商贩：酒虫当前持有者，也是交易与偷盗目标。
- 学堂执事：掌握排班和山寨内部时刻。

另有少量无名同窗、酒客和守卫作为环境 NPC。

## 4. 操作与镜头

- `WASD` 或方向键：八方向移动。
- `E` 或空格：与面前 NPC、物件、门和拾取物交互。
- `J`：打开或关闭记忆簿。
- `I`：打开或关闭行囊。
- `Esc`：暂停、重开或返回。
- 鼠标可点击对话选项和战斗指令。

镜头跟随玩家，在地图边缘停止。场景按固定比例缩放，保持像素边缘清晰。桌椅、墙体、柜台和山石有碰撞，角色不能穿越。

玩家可以八方向移动，但首版只制作上、下、左、右四组行走动画。斜向移动时沿用最后一个主要方向的动画，移动速度归一化，避免斜向更快。

### 4.1 时间规则

时间采用事件驱动的 `12` 点制，不按现实秒数流逝：

- `0-2`：清晨。
- `3-5`：午后。
- `6-8`：傍晚。
- `9-11`：夜晚。

玩家发呆、暂停、在局部地图普通走动和重复阅读已看过的闲聊都不消耗时间。

以下行为固定消耗时间点：

- 从青茅山大地图进入一个命名地点：`1` 点。
- 首次获得有效线索的对话或调查：`1` 点。
- 潜入、跟踪、偷盗、修炼或炼化：`2` 点。
- 完成一场战斗，无论胜负或逃脱：`2` 点。
- 睡眠：直接进入下一日 `0` 点。

关键行动结算：

| 行动 | 时间 | 资源与结果 |
| --- | ---: | --- |
| 首次有效调查 | `1` | 获得一条事实线索 |
| 学堂修炼 | `2` | 真元 `-4`，修炼 `+8`；每日第一次额外领取补贴 `4` 元石 |
| 街区普通妙手 | `2` | 每日最多一次，成功获得 `4` 元石，方源警觉 `+3` |
| 藏匿酒虫 | `1` | 酒虫改为“已藏匿” |
| 炼化酒虫 | `2` | 真元 `-8`，修炼 `+30` |
| 睡眠 | 到次日 `0` | 生命与真元恢复至上限 |

时间到达 `12` 后，除返回住处、查看界面和睡眠外，不再允许开始新行动。游戏不会强制传送玩家。每次时间点变化后，方源和其他日程 NPC 立即刷新位置与目标。

行动与时间按以下顺序结算：

1. 在行动开始时间检查地点、时段、资源和归属条件。
2. 条件满足后先结算玩家行动结果。
3. 再把时钟逐点推进；每经过一个时间点，依次执行 NPC 日程。
4. 截止事件在进入对应时间点后执行。若玩家的行动恰好结束在截止点，并已取得酒虫，截止事件不会再改变归属。
5. 花费 `2` 点的行动必须在当前时间不高于 `10` 时开始。

酒虫争夺截止事件在第二日时钟进入 `8` 后执行。取得酒虫的行动必须在时间点 `8` 之前开始；恰好结束于 `8` 仍算玩家先手。

## 5. 核心循环

1. 在大地图或局部场景中自由行走。
2. 观察人物日程，调查物件并获得事实线索。
3. 线索进入记忆簿，但不显示完整解法或导航箭头。
4. 玩家根据时间、位置和资源选择行动路线。
5. 偷盗、交易、欺骗或战斗产生结果。
6. 时间推进，方源执行自己的行动。
7. 世界记录归属、证据、警觉、人物位置和替代路线。

## 6. 酒虫任务网络

### 6.1 初始状态

玩家只知道一段模糊原著记忆：

“青茅山早期有一只能够改善修炼效率的蛊，似乎与酒香有关。”

游戏不会显示“前往学堂偷排班”之类的目标。

### 6.2 可发现线索

- 学堂木柜：时间点 `4-5`，后巷巡逻会去学堂交接。
- 学堂同窗：卖酒商贩最近频繁出入山寨。
- 酒馆老板：旧酒坛出现过异常酒香。
- 酒馆后院：一只酒坛有轻微移动痕迹。
- 路遇方源：他也在观察卖酒商贩。
- 商贩对话：他急需元石，愿意卖掉一坛“怪酒”。

### 6.3 三条完整路线

#### 路线 A：潜入偷取

1. 观察或偷取学堂行政柜中的“山寨巡逻交接表”。
2. 得知午后 `4-5` 点，负责酒馆后巷的巡逻队会去学堂交接。
3. 在该窗口进入酒馆后院，调查正确酒坛。
4. 触发一次基于准备、盗道和目标戒备的实物盗取检定。

特点：

- 消耗元石最少。
- 盗道熟练度收益最高。
- 留下证据，方源警觉显著上升。

#### 路线 B：跟踪截胡

1. 在午后 `3` 点的街区发现方源观察商贩。
2. 玩家在时间点 `3` 启动跟踪。跟踪过程中时钟暂停结算，玩家依次经过街区、酒馆门口和后巷三个触发区。
3. 若进入触发区时与方源距离小于 `64` 像素，方源警觉 `+8`，本次跟踪中断。
4. 三个触发区、酒客干扰和最终盗取检定共同构成一个完整行动。无论成功或失败，总计只消耗 `2` 个时间点，时钟从 `3` 变为 `5`，不会再次扣时。
5. 成功经过三个触发区后，玩家从方源的停留位置反推出目标酒坛。
6. 玩家花费 `2` 元石雇酒客在前厅打碎一坛酒，获得最终盗取检定的 `+2` 准备加成。

特点：

- 最符合“偷方源剧本”的体验。
- 需要潜行和谨慎。
- 一旦失误，方源会直接确认玩家不是普通同辈。

Demo 不制作通用视野锥、噪声传播或复杂实时潜行系统。路线 A 的潜入使用条件检定；路线 B 先使用三个跟踪触发区和距离判断取得准备，再执行表中的确定性盗取检定。

#### 路线 C：筹资交易

1. 从老板处确认商贩急需元石，并得知怪酒价格为 `18` 元石。
2. 通过每日首次学堂修炼补贴 `4` 元石、山林战斗 `8` 元石或普通妙手偷窃 `4` 元石筹资。
3. 在第二日傍晚时间点 `8` 的截止前支付 `18` 元石购买怪酒。

特点：

- 警觉增长最低。
- 需要时间和资源。
- 太慢时，方源会先买走或偷走酒虫，但玩家仍可追踪方源开启高风险夺回路线。

### 6.4 盗取检定

非战斗偷盗采用确定性公式，不掷随机数：

```text
盗取结果 = 盗道等级 * 2 + 敏捷 + 洞察 + 谨慎 + 准备加成 - 难度
```

- 结果 `>= 3`：成功。
- 结果 `0-2`：部分成功，目标未取得但保留额外情报。
- 结果 `< 0`：失败并触发追查。

关键难度与准备加成：

| 行动 | 难度 | 可用准备 |
| --- | ---: | --- |
| 偷巡逻交接表 | `8` | 观察执事离开 `+2` |
| 后院偷酒虫 | `9` | 巡逻表 `+2`，确认正确酒坛 `+2` |
| 跟踪路线截胡 | `11` | 完成三个跟踪区 `+3`，酒客干扰 `+2` |
| 客房二次潜入 | `10` | 取得房门钥匙 `+3`，或贿赂老板 `+2` |
| 酒馆冲突夺取 | `9` | 酒客干扰 `+2` |
| 夜间偷方源酒虫 | `12` | 偷听取得行动窗口 `+5` |

### 6.5 失败与替代

- “酒虫争夺失败次数”只统计直接取得酒虫的检定失败。偷排班失败、跟踪时靠得过近和普通战斗失败不计入。
- 第一次争夺失败后，酒虫仍由商贩持有；商贩在下一时间点移动到酒馆客房，交易价从 `18` 提高到 `22`，后巷入口关闭。
- 第一次争夺得到部分成功时，玩家顺手取得客房钥匙；完整失败时，可花费 `3` 元石贿赂老板获得客房位置与 `+2` 准备。
- 客房二次潜入消耗 `2` 时间点并执行难度 `10` 的检定。
- 酒馆冲突路线花费 `2` 元石雇酒客闹事，消耗 `2` 时间点并执行难度 `9` 的检定。
- 客房潜入或酒馆冲突再次失败即算第二次争夺失败，酒虫立刻转为方源持有。
- 第一次失败后仍可在截止前支付提高后的 `22` 元石直接购买。
- 跟踪失败：方源留下假线索，玩家仍可改走交易或调查路线。
- 元石不足：可以修炼、战斗或进行普通偷盗筹资。
- 卖酒商贩从第一日午后 `3` 点停留到第二日傍晚 `8` 点。到截止点仍未取得酒虫，或玩家二次争夺失败：酒虫转为方源持有。
- 方源持有酒虫后，每个夜晚 `9-10` 点会出现在山林岔路修炼。玩家可偷听取得行动窗口，然后选择高难度扒窃或主动挑战。
- 从方源处扒窃成功会直接取得酒虫；部分成功会触发方源战且保留行动窗口；完整失败会触发方源战但不保留行动窗口。战斗结束后的归属按第 7.1 节结算。
- 夜间夺回失败后，酒虫仍由方源持有；窗口以后每天重复，不永久关闭。
- 战斗失败：玩家在住处于次日清晨醒来，损失 `25%` 元石，酒虫保持当前归属，世界继续推进。

各检定的部分成功信息固定如下：

| 行动 | 部分成功结果 |
| --- | --- |
| 偷巡逻交接表 | 获得口头交接时段，准备加成只有 `+1` |
| 后院偷酒虫 | 未取得酒虫，但取得客房钥匙，计第一次争夺失败 |
| 跟踪路线截胡 | 未取得酒虫，但确认正确酒坛并取得客房钥匙，计第一次争夺失败 |
| 客房或冲突夺取 | 未取得酒虫，计第二次争夺失败，酒虫转给方源 |
| 夜间偷方源 | 进入方源战并保留“行动窗口” |

## 7. 酒虫到手后的闭环

拿到酒虫不是任务终点。

1. 酒虫在行囊中带有“气息未处理”状态。
2. 玩家需要返回住处，与藏赃夹层交互；藏匿消耗 `1` 个时间点。
3. 未及时藏匿就睡眠，方源警觉增加并可能在次日试探玩家。
4. 藏匿后可在炼化蒲团消耗 `2` 个时间点和 `8` 点真元进行炼化。
5. 只要酒虫归属为玩家、已经藏匿且真元不少于 `8`，炼化必定成功；成功后修炼进度 `+30`，酒虫状态改为“已炼化”。
6. 方源改走备用资源路线，并根据警觉值选择无视、观察或试探。

Demo 完成条件是“酒虫已炼化”，而不是“物品已拾取”。

生命与真元只在睡眠后恢复至上限。战斗失败也会进入次日清晨，并恢复至上限。首版不制作药品或场外即时恢复。

### 7.1 酒虫归属状态

| 触发 | 归属与状态 |
| --- | --- |
| 初始 | 商贩，随身携带 |
| 路线 A / B / C 成功 | 玩家，气息未处理 |
| 首次偷盗失败 | 商贩，转移到酒馆客房 |
| 截止时间到达或二次失败 | 方源，已炼化前 |
| 方源战中妙手成功 | 暂时争夺中 |
| 妙手后胜利或逃脱 | 玩家，气息未处理 |
| 妙手后战败 | 方源重新取得 |
| 战胜方源但未使用妙手 | 战后拾取，归玩家 |
| 玩家藏匿 | 玩家，已藏匿 |
| 玩家炼化 | 玩家，已炼化 |

## 8. 方源行动

方源拥有简化日程和目标优先级：

- 清晨 `0-2`：学堂或住处附近。
- 午后 `3-5`：调查当前最高价值机缘；未受干扰时从街区前往酒馆后巷。
- 傍晚 `6-8`：压榨资源、观察玩家，或在截止点取得酒虫。
- 夜晚 `9-11`：修炼、转移或设置假线索；持有酒虫时固定出现在山林岔路。

方源在每次时间点变化后执行一次日程决策。暂停、打开行囊或停在原地不会推进方源行动。

方源警觉分三档用于 Demo：

- 0-19：无视。
- 20-39：观察。
- 40 以上：试探。

警觉范围为 `0-100`，达到上限后不再增长。

各档行为：

- 无视：只按固定日程争夺酒虫，不主动接近玩家。
- 观察：每日傍晚在玩家当前场景附近出现一次，并在酒馆放出一条错误酒坛线索。
- 试探：次日清晨出现在玩家住处外；酒虫炼化后，在山寨出口触发一次试探对话。

警觉变化：

| 行动 | 警觉变化 |
| --- | ---: |
| 普通调查、修炼、战斗 | `0` |
| 偷巡逻交接表成功 / 失败 | `+4 / +6` |
| 跟踪时靠得过近 | `+8` |
| 路线 A 偷得酒虫 | `+18` |
| 路线 A 首次失败 | `+10` |
| 路线 B 截胡成功 | `+24` |
| 路线 C 买得酒虫 | `+10` |
| 携带未藏酒虫睡眠 | `+8` |
| 偷听方源取得窗口 | `+6` |
| 从方源处偷取成功 / 失败 | `+30 / +15` |
| 正面战胜方源 | `+35` |

## 9. 回合制战斗

战斗使用 `8 x 6` 小型网格。

战斗为确定性规则，不使用随机伤害。

基础数值：

- 玩家：生命 `40`，真元 `20`，移动 `3` 格。
- 山林蛊兽或商贩守卫：生命 `28`，移动 `2` 格。
- 方源夺回战：生命 `42`，移动 `3` 格，首版使用同一套基础 AI，但伤害提高。

玩家每回合先移动一次，再执行一个动作：

- 普通攻击：相邻一格，造成 `8` 点伤害。
- 防御：本回合结束，下次受到的伤害减半。
- 妙手：相邻一格，消耗 `3` 真元；普通敌人固定偷取 `4` 元石，特殊夺回战在已取得行动窗口时可偷走酒虫；同一目标只能成功一次。
- 偷元：两格范围，消耗 `4` 真元，造成 `6` 点伤害并恢复 `3` 真元，冷却 `2` 回合。
- 逃脱：玩家到达任一边缘格后选择逃脱，立即结束战斗。

玩家结束动作后轮到敌人。敌人沿最短可行路径向玩家移动，若最终与玩家相邻则攻击：普通敌人造成 `6` 点伤害，方源造成 `9` 点伤害。无法接近时，敌人移动到与玩家曼哈顿距离最小的格子。

敌人生命归零为胜利；玩家生命归零为失败；逃脱不结算胜利奖励。普通战斗胜利奖励 `8` 元石，守卫战胜利保留继续争夺酒虫的机会。战斗失败按第 6.5 节恢复。

在方源夺回战中，妙手成功后酒虫进入“暂时争夺中”，战斗不会自动结束。玩家随后胜利或从边缘逃脱才正式取得酒虫；若玩家生命归零，方源重新取得酒虫。玩家直接战胜方源而未使用妙手时，战后自动拾取酒虫。

防御减伤向下取整，因此方源的 `9` 点伤害减半后为 `4`。战败损失的元石也向下取整；玩家有元石但计算结果为 `0` 时至少损失 `1`。敌人寻路使用广度优先搜索，候选邻格顺序固定为上、左、右、下，确保测试结果一致。

战斗只验证移动、攻击、盗道技能和失败恢复，不扩展复杂蛊虫组合。

## 10. 界面

游戏第一屏直接进入可玩场景，不使用营销式首页。

常驻界面保持克制：

- 左上：日期、时段、生命、真元。
- 右上：小地图与当前地点。
- 下方：仅在对话、调查和选择时出现的文本框。
- 方源状态只显示玩家能判断出的“无视、观察、试探”，不常驻显示精确行动计划。
- 记忆簿记录原著记忆、事实线索和玩家推测，但不提供导航箭头。

靠近可交互对象时，只显示一个小型交互图标和对象名称。

## 11. 美术资产

统一采用复古像素风：

- 三分之四俯视角。
- 清晰的瓦片比例和可行走通路。
- 木、石、竹、旧纸、酒坛和山雾具有可辨识材质。
- 主色使用旧木、岩灰、苔绿、暗红和纸窗暖黄，不做单一棕色画面。
- 环境保持明暗氛围，但可交互区域必须可读。

Demo 需要的首批真实资产：

- 青茅山大地图背景。
- 古月山寨街区背景。
- 学堂、酒馆、住处和战斗场背景。
- 玩家四方向行走精灵。
- 方源与三个主要 NPC 精灵。
- 酒虫、酒坛、排班册、元石和交互图标。
- 对话框、记忆簿和战斗指令界面。

生成图只作为资产基础。用于实际地图的图需要经过裁切、碰撞标注和统一缩放，不能只把概念图作为不可交互壁纸。

## 12. 技术结构

### 12.1 引擎

使用 Phaser 3 构建浏览器 2D 游戏：

- 成熟的场景、输入、镜头、精灵、碰撞和音频支持。
- 适合大地图与局部场景切换。
- 可在现有网页项目中运行。
- 后续可以逐步替换背景图为标准瓦片地图。

使用 Vite 作为开发和构建工具。

### 12.2 模块

- `GameStateStore`
  - 保存日期、时段、玩家、方源、线索、酒虫归属和世界状态。
  - 采用纯状态转换，便于单元测试。

- `WorldScene`
  - 青茅山大地图移动、地点入口和固定遭遇点。

- `LocationScene`
  - 复用局部场景加载、碰撞、出口和 NPC 交互。

- `InteractionSystem`
  - 选择玩家面前最近的交互目标。
  - 管理对话、调查、偷盗和门口切换。

- `QuestGraph`
  - 以条件和效果描述酒虫路线。
  - 不依赖线性步骤编号。

- `TimeSystem`
  - 处理时段推进、NPC 日程和方源行动。

- `BattleScene`
  - 管理网格、回合、技能、胜负和逃脱。

- `UIScene`
  - 常驻 HUD、对话、记忆簿、行囊和暂停菜单。

### 12.3 数据流

玩家输入先进入当前 Phaser 场景。场景调用交互或战斗系统，系统产生状态事件，再由 `GameStateStore` 统一更新。时间系统订阅有效行动并推进 NPC 日程。UI 只读取状态并显示，不直接修改任务条件。

场景切换时只传递入口 ID，所有持久状态保存在 `GameStateStore`。当前静态文字原型由 Phaser/Vite 主入口替换，但已有纯状态转换逻辑会迁移进 `GameStateStore`，已有行为测试会改写后保留。

### 12.4 存档策略

- 使用 `localStorage` 键 `tianwai-demo-save-v2`。
- 每次状态变化和场景切换后自动存档；睡眠后再做一次明确存档。
- 浏览器刷新时恢复最近一次自动存档和当前场景入口。
- 战斗中不保存逐回合状态；进入战斗前保存，刷新后回到遭遇前的位置。
- 旧文字原型没有正式兼容要求，不迁移 `v1` 状态。
- 存档损坏或版本不匹配时显示说明并创建新档。
- “重开”需要二次确认，只删除本 Demo 的存档键。

战斗中的生命、真元、位置、冷却和临时归属属于瞬时状态，明确不适用“每次状态变化后自动存档”。只在战斗开始前和战斗结算后保存持久状态。

## 13. 容错与防卡关

- 存档按第 12.4 节校验或重建，不静默丢弃。
- 场景资源加载失败时显示错误覆盖层和重试，不进入黑屏。
- 玩家卡在碰撞体内时，可从暂停菜单返回当前地图入口。
- 关键物品不能被丢弃或重复获得。
- 每个酒虫路线都有替代入口。
- 战斗失败不会删除存档或终止世界。
- 方源先取得酒虫后，每个夜晚重复开放山林夺回窗口。

山林蛊兽不是随机遭遇。玩家踏入固定林间空地时触发，每个游戏日最多触发一次；胜利奖励 `8` 元石，逃脱或战败没有奖励。次日睡醒后遭遇点重新激活，不能在同一天反复刷取。

## 14. 测试

### 14.1 单元测试

- 日期与时段推进。
- 三条酒虫路线均可完成。
- 方源先手后仍可夺回。
- 藏匿与炼化前置条件。
- 警觉档位与方源行为。
- 战斗失败后的恢复状态。
- 损坏或版本不匹配存档重建与确认重开。

### 14.2 浏览器测试

使用 Playwright 验证：

- 玩家能移动、碰撞并进入六张地图。
- 靠近 NPC 或物件后出现交互提示。
- 至少两条酒虫路线可从头走到炼化完成。
- 战斗能胜利、失败和逃脱。
- 日期不会停在第二日。
- 刷新页面后存档恢复。

### 14.3 视觉测试

- 桌面视口下场景非空、人物可见、镜头正确。
- 画面缩放后保持像素清晰。
- HUD、对话框和交互提示不遮挡玩家。
- 地图入口、可行走通路和关键交互物具有足够辨识度。

## 15. Demo 验收标准

Demo 完成时，玩家应能够：

1. 用键盘在青茅山和古月山寨自由走动。
2. 进入学堂、酒馆和住处并与人物或物件交互。
3. 不依赖显式任务按钮发现酒虫线索。
4. 通过至少三条路线之一取得酒虫。
5. 完成一次回合制战斗或主动避开战斗。
6. 藏匿并炼化酒虫。
7. 看见方源因玩家行为改变日程和态度。
8. 失败后继续游戏而不被卡死。

- 队友系统。
- 成年角色缘线。
- 身份、记忆、因果和时间盗取。
- 完整炼蛊与蛊虫养成。
- 手机触控操作。
