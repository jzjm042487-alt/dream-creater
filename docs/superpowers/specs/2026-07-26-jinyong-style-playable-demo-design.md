# 《蛊真人：天外盗剧本》群侠传式可玩 Demo 设计

## 1. 已确认方向

Demo 是直接可玩的青茅山 RPG，不是面板陈列或纯文字选项页。

核心表现：

- 复古俯视地图。
- Q 版角色自由移动。
- 靠近角色或物体后交互。
- 场景背景、成人立绘和简短对白。
- 前、后、左、右的隐形路径旅行。
- 低阶蛊虫追踪与捕捉小游戏。
- `8 x 6` 格子战斗。
- 空窍负载与蛊虫搭配。
- 独立于蛊虫的偷盗技能。

唯一规则源：

- `docs/superpowers/specs/2026-07-27-qing-mao-simplified-mvp-design.md`

## 2. Demo 目标

玩家在一个可反复游玩的短流程中完成：

1. 开窍与初始蛊选择。
2. 在山寨中移动、对话、训练和偷盗。
3. 查询酒虫的原著资料。
4. 进入野外，以方向旅行寻找机缘。
5. 完成一次低阶蛊捕捉或机缘争夺。
6. 完成至少一场格子战斗。
7. 调整空窍构筑。
8. 推进主线步骤并保存。

目标游玩时长约 `35..60` 分钟。自由探索不会触发倒计时失败。

## 3. 初始状态

### 3.1 玩家

```text
生命：40 / 40
真元：20 / 20
元石：8
境界：一转
修为进度：0 / 100
力量：20
身法：20
感知：20
运气：50
意志：20
盗道熟练：20
空窍容量：6
```

玩家始终拥有普通肉搏。

### 3.2 初始蛊

开窍流程给予月光蛊，作为第一个可装入空窍的主动攻击蛊。

月光蛊 Demo 能力：

- 负载：`1`。
- 主动：月刃。
- 真元消耗：`3`。
- 射程：`line3`。
- 基础伤害：`8`。
- 被动：无。

### 3.3 主线显示

任务 HUD 只显示：

```text
当前：完成开窍并领取月光蛊
下一步：前往学堂训练场
状态：进行中
```

不显示百分比和条件清单。

## 4. 可玩地图

### 4.1 山寨地图

首批地图：

- 古月山寨广场。
- 学堂。
- 酒肆与集市。
- 居住区。
- 山林入口。
- 商队驻地。
- 狼潮防线。
- 离山出口。

玩家使用键盘或屏幕方向控制移动。相机跟随玩家，交互目标进入范围后出现图标按钮。

### 4.2 野外地图

青茅山野外不显示完整路网。

进入后只显示：

- 前。
- 后。
- 左。
- 右。

每次选择可能移动到环境节点、战斗、小游戏、普通出口或隐藏地点。

绝对方向、历史栈、连续后退、时间收费和第 20 步保底见：

- `docs/superpowers/specs/2026-07-26-wilderness-hidden-route-design.md`

### 4.3 不使用地点按钮传送

未进入野外时，玩家通过实际走到地图出口换场景。

野外中的普通目的地只在到达或第 20 步保底时选择。已发现隐藏地点可以作为当前远征的直接返回点。

## 5. 地图角色

首批 Q 版角色：

- 玩家。
- 方源。
- 方正。
- 漠北。
- 赤城。
- 白凝冰。
- 学堂家老。
- 酒肆伙计。
- 卖酒商人。
- 商队管事。
- 守卫。

方源只是其中一名竞争者。地图和战斗不为其增加专属状态。

成人角色在对话中使用独立立绘。Q 版地图角色不随衣物或情绪标签换图。

## 6. 地图交互

### 6.1 交互按钮

靠近目标后，根据类型显示图标：

- 对话。
- 偷盗。
- 交易。
- 调查。
- 训练。
- 进入。
- 战斗。

只有明确命令使用文字按钮；图标必须有悬停或长按提示。

### 6.2 对话

对话画面：

- 当前场景背景全幅显示。
- 成人角色立绘站在背景前。
- 底部台词框。
- 最多三个简短选项。

选项不显示 AP、风险、公式、锁定和确认弹窗。

### 6.3 训练

每个主线步骤可以完成一次训练：

- 立即获得 `+3` 修为。
- 可以进入一场教学战斗。
- 不消耗主线期限。

## 7. 偷盗

### 7.1 操作

1. 靠近角色。
2. 选择偷盗。
3. 查看当前可偷清单。
4. 选择一件。
5. 一次判定。

结果直接显示在地图交互层。

### 7.2 内容

Demo 目标可以提供：

- 元石袋。
- 普通道具。
- 蛊材。
- 装备。
- 成年角色外衣。
- 成年角色贴身物品。

### 7.3 判定

成功率使用总契约中的固定公式：

- 运气。
- 盗道熟练。
- 双方境界差。
- 物品固定难度。
- 最低 `15%`，最高 `95%`。

同境界、运气 `50`、熟练 `50`、普通物品为 `65%`。

### 7.4 成功

- 所选物品从目标清单移除。
- 物品进入普通行囊。
- 必要时切换成人立绘 presentation tag。
- 必要时应用一个当前场景或下一战斗状态。
- 显示结果并保存。
- 事件结束。

不记录原主人、赃物、非法状态或后续追查。

### 7.5 失败

- 不转移物品。
- 目标播放即时反应。
- 本次地图访问不能再次偷该目标。
- 显示结果并保存。

失败不创建跨场景状态。个别敌对场景可立即进入普通战斗。

## 8. 酒虫机缘

### 8.1 定位

酒虫是首个完整机缘教学，不是普通任务网络。

它教学：

- 查询原著资料。
- 在地图获得当前世界线索。
- 方向旅行。
- 观察与捕捉小游戏。
- 与其他天骄竞争。
- 机缘结果改变当前世界。

### 8.2 开始

玩家在原著查询中查看酒虫：

```text
原著资料：酒虫与花酒行者遗藏相关。
原著地点：青茅山。
当前世界：具体位置尚未确认。
```

查询不消耗资源，不自动创建强制任务。

### 8.3 获取当前线索

任意完成一个交互即可获得“山林酒香”：

- 与酒肆伙计对话。
- 调查酒肆后门酒坛。
- 在野外发现酒香环境提示。

线索只让捕捉入口出现，不需要累计数量。

### 8.4 野外追踪

玩家进入青茅山野外，使用相对方向移动。

到达酒虫节点后进入追踪小游戏：

1. 观察四种痕迹，选出酒香与爬行痕迹。
2. 选择青竹酒作为诱饵。
3. 选择雨后清晨的捕捉时机。
4. 选择带塞酒坛作为容器。

每一步立即给出环境反馈。错误选择增加一个小游戏回合，但不消耗主线期限，也不永久失去酒虫。

### 8.5 竞争

若另一名天骄同时到达，玩家可以：

- 先完成最后一个捕捉步骤。
- 交易。
- 撤离并寻找其他机缘。
- 进入 `8 x 6` 普通争夺战。

没有方源专属逻辑。参与者由当前世界事实决定。

### 8.6 结果

取得酒虫后：

- 创建酒虫实例。
- 放入 reserve。
- 当前机缘标记 `resolved`。
- 记录取得者。
- 获得首次低阶蛊机缘修为奖励。
- 回到野外节点。

记录取得者只是世界事实，不产生归还或追查规则。

## 9. 空窍与蛊虫

### 9.1 负载

一转空窍容量 `6`。

- 一转蛊负载 `1`。
- 二转蛊负载 `2`。
- 三转蛊负载 `4`。

战斗前可在角色页将蛊虫从 reserve 放入 aperture。

### 9.2 蛊虫卡

卡片显示：

- 名称和阶位。
- 负载。
- 一个标志主动技能。
- 至多一个被动或探索功能。
- 真元消耗。
- 格子射程模板。
- 喂养摘要。
- 配方标签。

### 9.3 重复蛊

每只蛊声明自己的 stackRule。没有通用百分比递减。

### 9.4 杀招

Demo 最多提供一个教学杀招：

```text
核心蛊 + 必需辅助蛊 + 最多一个可选修饰
```

缺少组件时按钮不显示。

## 10. `8 x 6` 战斗

### 10.1 战场

- `8` 列、`6` 行。
- 上下左右移动。
- 单位不能重叠。
- 曼哈顿距离。
- 默认 `1v1`，一个教学事件可 `1v2`。

### 10.2 玩家回合

1. 移动 `0..move` 格。
2. 执行一个动作。

动作：

- 普通肉搏。
- 月光蛊月刃。
- 其他已装入蛊的主动技能。
- 杀招。
- 防御。
- 使用道具。
- 边缘撤退。

没有行动点池、中断条件或反应窗口。

### 10.3 普通肉搏

- 射程：相邻一格。
- 基础伤害：`6 + floor(力量 / 20)`。
- 真元消耗：`0`。

因此无蛊或真元不足时仍能战斗。

### 10.4 敌方

敌方按固定顺序：

1. 射程内使用最高优先技能。
2. 沿最短路线接近。
3. 进入攻击范围后攻击。

同长路径按上、左、右、下选择。

### 10.5 结束

- 敌人全灭：胜利。
- 玩家生命归零：失败。
- 玩家从边缘撤退：撤退。

胜利是主要修为来源。失败不丢物品、蛊虫、元石或修为。

## 11. 修为与突破

修为进度：

- 普通胜利 `+8`。
- 精英胜利 `+12`。
- 存活失败或撤退 `+2`。
- 首次危险探索 `+4`。
- 训练 `+3`。
- 可选夜间修炼 `+2`。

达到 `100` 后突破按钮立即可用。突破无其他门槛并确定成功。

## 12. 界面

Demo 活动界面：

1. 地图与 HUD。
2. 对话。
3. 角色与空窍。
4. 行囊、装备与炼制。
5. 当前任务。
6. 天骄名册。
7. 原著查询。
8. 战斗。
9. 暂停、存档与读档。
10. 地图交互结果。

任务页只显示当前步骤、下一步骤和完成状态。

## 13. 存读档

存档保存：

- 当前地图与位置。
- 玩家活动状态。
- 当前任务步骤。
- 行囊和装备。
- 蛊虫实例与空窍装配。
- 人物存活状态。
- 机缘结果。
- 野外路径状态。
- 偷盗和野外随机游标。
- 当前战斗。

读档不重掷结果，不重复奖励。

旧 v2 key 保持可读，迁移规则见 `contracts/game-state-v3.md`。

## 14. 容错

- 任何可选机缘都不阻断主线。
- 酒虫被其他人取得后，玩家仍可继续训练、探索和离山。
- 方源死亡后由通用缺席规则继续场景。
- 战斗失败后回到入口并保留资源。
- 第 20 个野外移动必定提供普通目的地选择。
- 最终步骤直接显示离山选择。

## 15. 验收

- 玩家能在地图中自由移动并靠近交互。
- 野外没有地点传送按钮。
- 酒虫通过线索、方向旅行和小游戏获取。
- 偷盗在地图层一次结算，成功后直接获得物品。
- 空窍负载阻止超容量装配。
- 玩家可以用肉搏或蛊虫技能完成 `8 x 6` 战斗。
- 战斗可以胜利、失败或撤退。
- 修为满后可立即突破。
- 任务不显示百分比。
- 天骄名册同时展示方源和其他竞争者。
- 原著查询不改变世界状态。

## 16. 本次不做

- 四转及以上蛊的完整获取。
- 半神级偷盗。
- 多队伍战术战斗。
- NPC 全日程模拟。
- 数值关系和任务关系门槛。
- 证据、追查和破案。
- 原轨同步与纠正。
- 回溯修正。
